# 下注决策核心：逐步教学实施备忘录

日期：2026-10-18。只研究，不修改代码。依据 Nevir 笔记2.1—2.3、2.5—2.7，以及当前从原表提取的 B/D/E 单元格。本文供总实施文档整合；数学实验与课程规定分别标注，不把实验最优当成扑克GTO解。

## 一、这部分真正要建立的关系

不能只训练“下注/过牌”按钮；也不能要求用户在每手牌里填完整分析表。初学阶段要把一次决定中的五个必要步骤单独变得可见，之后把已经会的步骤收起：

1. **我若不下注，会发生什么？** 后行动且对手已经过牌，过牌可以关闭本街；先行动过牌只是把行动交给对手。河牌直接摊牌，翻牌/转牌还会发牌，二者不能共用同一个收益值。
2. **这次下注希望改变谁的结果？** 较差牌付钱、较好牌退出、尚落后的牌失去反超机会，分别是什么；同一手牌可能同时有几种效果，不强迫每手牌只有一个永久标签。
3. **我的这手牌在本局面承担什么任务？** 牌型相同不等于任务相同；中等牌的过牌价值、听牌的改善机会、强牌从谁取值，都依具体条件。
4. **尺寸改变谁继续、付多少、我输时多付多少？** 被跟后权益降低只是一个结果，不能单独证明下注不好；必须把弃牌收益与投入成本也计入。
5. **对手行动改变了什么？** “更差牌会跟”不等于“更差牌会加注”；我价值下注后遭加注，要重新分析加注分支，不能自动沿用刚才的理由。

这五步是内部组织，不应变成五张固定表单。用户独立熟练时只点最终动作；只有学习、诊断或指定练习才展开中间步骤。

## 三、单元A：先看清不下注的结果

**要掌握：** 过牌不是“啥也不发生”，更不是弃牌；它是一个应与下注比较的候选行动。位置先教行动顺序，再教策略差别，避免换座位同时换范围却把全部变化归因于位置。

### 逐屏脚本

| 步骤 | 屏幕与操作 | 软件给出的反馈与判分 |
|---|---|---|
| A1示范 | 只显示河牌、双方明牌、对手已过牌。点“我也过牌” | 双方摊牌，圈出最佳五张；只解释当前赢家。示范不计一次独立掌握 |
| A2补一步 | 换成翻牌。保持同样的“对手已过牌→轮到你”，选“过牌后下一件事” | 正确是发转牌；不能写直接赢底池。先不问策略优劣 |
| A3只换顺序 | 固定牌、固定教学候选牌集合；让你先行动。你点X后对手仍有按钮 | 用户先预测“直接发牌/仍等对手”；答后播放对手X或B的给定分支。这里改变的只有行动顺序 |
| A4连接课程 | I12的356两同花，显示前序CO跟3bet、翻牌X；用户选择课程的先整体X | 答后先发一张牌作为过程示意，不判未记录转牌策略。解释保留改善机会不是免费承诺必赢 |
| A5另一个真实场景 | P06的SB–BB T83，用户按课程X，BTN不在此局，BB仍可行动 | 先核对角色，再选谁行动；题目止于资料支持处，不要求猜BB会下多大 |

**生成：** A1—A3可枚举合法牌张、在flop/turn/river切换、在同一候选集合上切换行动顺序；答案只来自规则。策略题A4/A5只换全局花色映射或使用另一个有出处节点。不要把随机新牌面赋上I12/P06的策略。

**错题分流：** 谁赢错→最佳五张补练；X当弃牌→重放对手X后摊牌；先X即发牌→保留对手未完成的行动灯；策略错但规则对→回课程条件，无需重复教牌型。

**无提示验收：** 新的牌与前序，判断X后是否关闭本街；另给河牌，避免沿用“发转牌”。一个真实课程新例只检验已有来源动作。答对顺序但不会选策略，不应判定位置学习失败，也不能反过来宣称策略已学会。

## 四、单元B：下注的效果，要落在具体对象和筹码上

**要掌握：** 一手牌的“强”不是下注理由本身；需要指出相对过牌多获得了什么、承担了什么。初学先用河牌去掉未来街；翻牌再添加“现在差的牌以后仍可反超”。

### 逐屏脚本

1. **先只看一个较差对手牌。** 沿用R01的AK两对与AQ代表牌；明说是用于解释的对照，非完整范围。对手按给定条件跟注。先看X摊牌，再看B被跟，用户点“新增收入来自哪一方”。圈出的应是对手新增筹码，不是把自己退回的下注当利润。
2. **只换成击败你的牌。** 合法三条对手牌，被跟后输掉新增投入；用户点出多损失的钱。此处仍不问“整个范围最优策略”。
3. **较差牌不跟。** 给定它弃牌。与X本来就能赢比较：河牌中没有新增跟注收入。练“赢了这手”与“下注增加了价值”并不相同。
4. **较好牌肯弃。** 用完整有限实验明确折叠概率；先显示成功拿底池、失败损失本次下注，再让用户预测提高弃牌比例对结果的影响。
5. **再合并完整模型。** 只有当所有候选、权重、回应齐全，才比较X和下注的平均结果。先逐个情形展示钱，软件合计，再收起合计让用户判断方向；详细算术可选。
6. **添加未来牌这一项。** 在翻牌明牌对照中，高张目前落后但某些合法转/河牌能反超。用户点击具体改善牌，看到对手弃牌会消除这些后续分支；随即说明这只证明存在剥夺权益效果，没证明任意下注额划算。
7. **回资料区分任务。** R02的QQ在K7239面，按“较差对子不跟、Kx不弃”的明确原理条件选X；R03的87黑桃错过听牌、题设不会弃更好牌，选放弃。这些是原理补充，不宣称解决所有真实河牌。

**可严格计算的部分：** 在无加注、无后街的河牌有限模型中，当前底池P，下注b，对手组i权重wᵢ、跟注率cᵢ、你对该组的摊牌权益eᵢ：

```text
EV(X) = Σ wᵢ eᵢ P
EV(B) = Σ wᵢ [(1-cᵢ)P + cᵢ(eᵢ(P+2b)-b)]
```

权益包括平分的一半；同一组必须足够细，使其回应与权益关系定义完整。若只是一个宽组，不能把组平均权益与组平均跟注率当独立变量随便相乘，必须按具体组合或条件权益展开。

在河牌、具体对手牌胜负确定时：赢它且它跟注，新增收益是b；赢它但它弃牌，新增收益为0；输它但它弃牌，新增收益是P；输它且它跟注，新增收益是−b。这比先塞一个EV公式更适合作为第一轮解释。纯诈唬无摊牌胜率时，在只有弃/跟的模型中，盈亏平衡弃牌率为b/(P+b)。该门槛不提供现实对手弃牌率，也不证明该尺寸最佳。

**生成/判分：** 从合法牌张生成“我赢/输/平”关系，算出事实，再生成明确的有限回应条件；先筛出确有唯一最优或声明并列可选的实验。不能用固定文案“有差牌跟所以小注最好”覆盖所有权重。原理对象题判具体哪一组、哪笔筹码、哪条改善分支；策略题仅在信息齐全时判最终动作。

**错题分流：** 分不清谁好→读牌；把赢底池当新增价值→X/B筹码对照；纯诈唬只盯成功→补失败分支；未来反超没看见→单牌变化；对象都对而选错额→进入完整比较，无需重教“价值”的定义。

**验收：** 同一个牌型在两套回应中改变行动；当前更强但不该增加投入；目前更弱但在充分给定弃牌条件下下注有利。另有信息不足题，正确选“还缺哪些牌会继续/频率”，与弃答按钮“我不知道”严格区分。

## 五、单元C：把手牌任务、下注频率与下注尺寸拆开

**要掌握：** “B67”只说明下注时的主尺寸；“约40%下注”描述整个范围如何分配；“KQ可进入下注端”只是明确条件下的候选资格。三者不能互相换算。

### 逐屏脚本

| 步骤 | 用户操作 | 依据与边界 |
|---|---|---|
| C1 | I11同一842面依次看AA、77；先指出各自已经组成什么，再点任务 | AA进入课程B67价值端；77更多X。不要先显露牌型标签替用户读牌 |
| C2 | 保持同一牌面，把AK作为资料解释中的高张，点击真实改善点/潜在弃牌对象 | 说明高张可以作为候选；原表未给AK精确频率，不把它按100%必下判分 |
| C3 | 同一个面同时只摆AA与77两个已明确例子，分别点“下注端/更多过牌” | 这是两个例子的分工，不能画成50%范围下注 |
| C4 | S05 QT5两同花依次出现AQ、55、J♠9♠、JJ | 前三者分别看成牌/听牌，再对应表中B75；JJ更多X。J♠9♠既有直接花听又有两头顺听，不能强迫只选“一个类型” |
| C5 | S07 T85：KQ与77；S08 J95：AJ与KQ/KT | 区分价值、候选改善、保留摊牌。手牌分类题采用原表精度，不问未给出的逐手频率 |
| C6 | S09的“B50、约40%下注”，或P05的“约55%过牌” | 用户把两个数字分别对应“下注大小/行动频率”；不要求从未给出的完整范围反推数字 |

**显示：** 原表写“更多过牌”就显示这个答案；不能换成“永远过牌”。写“候选”时答案是“可进入下注端”，而非“本次必须下注”。如果后续要练某次实战按钮，必须另有明确选择约定；当前资料没有就不开放该层。用户拒绝随机数练习，不应偷偷把候选概率转成掷骰子任务。

**生成：** 课程手牌白名单×课程节点×合法花色映射。阻断/听牌会变时必须整体保留花色关系，不能独立换单张花色；有特定同花手牌的节点同时变换牌面与手牌。数学牌型事实可生成全新牌，但不继承课程动作。包含多个类别的牌必须允许多标签，避免将“成牌/听牌”错误设计成互斥全集。

**频率的数学边界：** 完整范围动作频率为Σw(h)p(B|h)/Σw(h)。如果只有AA、KK、77、66四个例子，既没有完整w也没有各p，就不能由“两手打、两手过”得出50%。约80%X的范围基准也不表示每一手都80%X。显示原表约值与固定训练取值的区别。

**错题分流：** TT当中等牌→牌型事实错误；把67%当频率→只做数字含义对照；所有对子都下注→同面AA/77对照；把候选当必选→阅读任务精度；高张全当垃圾→给实际可改善的牌，不用一句术语劝说。

**验收：** 未示范但表中有明确任务的手牌（例如I11的KK/66）检验同一节点内迁移；S05与S07/S08检验不同任务关系。必须承认这仍是受资料约束的迁移，不能把换花色称为未知战略问题。

## 六、单元D：尺寸通过“谁继续、付多少”影响结果

**要掌握：** 大注不只是“小注多一点”。它同时改变对手继续条件、你向较差牌收钱的金额、输给较强牌的金额以及后续行动。只看到对手继续范围变强，不能断言EV变低；只看到弃牌更多，也不能断言EV变高。

### 逐屏脚本

1. **用完整河牌模型控制变量。** 保持牌与权重，较差组跟小弃大，较强组两个都跟。先让用户点小注独有的付款组，再点大注新增的损失组；最后比较总量。
2. **只改较差组也跟大。** 用同一组对象逐格表现新增收入；程序重新算最优动作。不要口头宣布所有这类改动都一定反转，生成器须确认所选权重确实反转。
3. **只改强牌占比。** 有的模型即使较差牌跟大注，强牌太多也会改变结果；让用户看到“愿意付钱”不是充分条件。教学给定权重明确，不假装来自翻前图。
4. **接I08/I09。** 展示T♠7♥2♦→T♠7♥2♠，暂时只问A♠Q♠从后门花变成什么。让用户点击多出的直接花听，程序核对；这一步只证明听牌结构变了。
5. **补完整边界。** 明说这手AQ是说明变化的例子，不能代表全部继续范围。资料没有给双方完整范围及响应树，因此不显示伪造的“整体EV证明”。
6. **显示课程动作的来处。** 资料在该位置/底池/纹理下规定I08 B67、I09 B40。用户先找到是哪一行适用，再选择数值；解释是课程尺度，非上一屏单手枚举计算出来。
7. **再给不同变化。** I08→I13：T72→T82，同为彩虹，J9由卡顺变两头；让用户指出改的是点数连接关系。课程I13 B40。两个40%的来源相似但不意味着只看“有听牌”就统一40%。
8. **防止跨底池照搬。** S05 QT5两同花明确B75，与“有同花听牌就一律小注”冲突；显示它的SRP背景、手牌进攻端。任务是找出原口诀漏了哪些条件，再调用S05，不能假装只改变花色。

**可算与不可算：** 牌张枚举能精确计算已知两手牌的摊牌权益或改善概率；完整有限范围和响应树能计算模型EV。它们都不能独立恢复真实对手范围、精确求解课程40/67/75。若未来用权益演示，必须给全部实体花色，不能照抄笔记“AA对T9约55%”为通用常数。

**生成/判分：** 因果模型题按重新计算结果判分，允许并列最优或过滤并列；课程题的前序和场景必须完整。新牌面只能考“哪个关系变了/需要重估什么”，不能给未授权精确动作。显著改变权重、回应、自己手牌才算结构变化；仅改变底池的同比例金额并不改变最佳动作，适合比例理解，不能冒充策略迁移。

**错题分流：** 听牌未看见→读牌；误把示例牌当全范围→显示缺失组合与权重的位置；只盯弃牌率→补被跟成本；把“被跟范围强”当必亏→一个弃牌收益足以补偿的完整反例；机制正确数值错→课程记忆快练。

**验收：** 一题同关系不同牌；一题只变回应使动作反转；一题只变权重导致原口诀失效；一题课程同花但不等同小注；一题信息不完整、不能求精确尺寸。评价这些能力分别是什么，不合并成一个总正确率掩盖缺口。

## 七、单元E：面对下注和加注，问题已经改变

**要掌握：** 价格是行动的一个条件，不是完整答案。价值下注的理由针对对手跟注部分；对手加注后必须重新看加注部分。对手下小/大注的课程行为倾向有条件，不是一个尺寸永远对应强/弱。

### 逐屏脚本

1. **读清前序。** 用O07同一T83画面依次播放SB 3bet、BTN跟、SB X、BTN小B；用户点当前行动者。先保证不会把自己误当成后行动方。
2. **看课程条件。** 明确提供“BTN会用弱牌小注、面对X/R过弃”的行为设定，用户点出支持调整的两项证据，再按O07选X/R方向。这不是软件根据标签猜对手。
3. **只撤掉证据。** 同一牌面但未知对手，不能判无条件X/R；题目只要求指出缺失条件。若要返回基准，只能按原节点已记载的基准方向，不补手牌表。
4. **只改对手下注尺寸/行为。** 资料2.5 §3.2、2.7 §3.3—3.5提示大注和再加注的范围不同；训练识别“小注漏洞路线不再直接适用”，不是训练所有大注都弃牌。没有完整范围时不出最终跟/弃题。
5. **R04价格层。** 明确P为目前底池且已含对手下注、C为还要跟的金额。用户先点还需付的钱，再看跟后总底池P+C，最后算门槛C/(P+C)。小数按界面精度容差判分。给价格后仍不自动亮“跟注”。
6. **完整模型才能回答跟不跟。** 若额外明确给定全部对手组合、权重且河牌无后续加注，可枚举权益e并算e(P+C)−C，与弃牌0比较。此题标数学实验；现实未给对手诈唬率时停在缺信息。
7. **R05换问题。** AK两对价值下注、对手加注。屏幕先保留“可能用AQ跟注”的牌，再问它是否必然也是加注牌。把问题从“谁会跟”切到“谁会加”；正确操作是重新评估，不是统一弃牌或跟注。
8. **加注模型进阶。** 只有有完整假设树才继续计算；否则到此结束。若补树，明确加注总额、还需跟额、我方之后可用动作和相应概率，避免把原来已经投入的下注再次计算成本。

**严格公式与条件：** 在河牌、C跟完后无进一步投入、完整胜率已知、忽略抽水时，EV(call)=e(P+C)−C；门槛C/(P+C)。它回答call相对fold，不自动比较raise。翻牌的最终摊牌权益也不等于能无成本实现的实际收益；后续街要付钱或被迫弃牌时需更多树分支。

**生成/判分：** 价格题可随机合法P/C和下注前后账目，但不得随机数值后假定现实对手率；动作题只用O07明确条件和R05的信息任务。真实原表未给完整防守组合，不扩成通用防守训练。出现平分时算半权益；并列收益允许多个正确答案或明确题目问门槛。

**错题分流：** P重复加对手下注→筹码逐笔入池；把投入太多当必须跟→标出过去投入与本次追加；两对自动跟→较差跟注牌与更强加注牌分栏（代表例而非假完整范围）；小注万能X/R→撤除行为证据；信息都对但误解“重新评估”→让用户选下一项需要检查的内容。

**验收：** 新金额正确求价格；同价格换两个完整给定范围得到不同跟注选择；原始R05式缺范围信息时拒绝伪精确动作；O07条件被撤除时不机械套用X/R。能算门槛不等于掌握真实防守，必须分别报告。

## 八、题目与错误诊断的共用内部规格

每个步骤需要以下内部字段，用户界面只呈现当前需要的信息：

```text
source: 笔记章节/行号 + 工作表B/D/E单元格
authority: 牌张事实 / 完整数学实验 / 课程明确 / 教学取值 / 方向候选
scope: 位置、底池、100BB、街、前序、对手条件
known: 可见事实与题设；unknown: 本题未提供但不能私补的信息
target: 本屏唯一待观察的能力
answerPrecision: 精确动作 / 固定课程取值 / 候选资格 / 方向 / 信息是否足够
prerequisites: 本轮实际已观察到的前置能力
variation: 可换字段、必须保留的关系、禁止外推的字段
diagnostic: 已知错误→最小补练；仅最终动作错→一个轻量诊断问题
holdout: 与教学实例隔离的新关系/新条件ID，不只换花色
```

不要根据一次最终动作错误直接宣布“你不理解范围”。先问一个能区分的最小问题，例如“你现在赢哪一手？”事实对再问“它面对这个尺寸会怎样？”找到错的那一步再补。用户可跳过补教；所有记录只在当前会话内，不建立长期画像。

教学步骤答后停留；熟练练习答对自动下一题。答错先给正确结果和一处决定性差别，再提供“看这一步”展开，不把长解析全部压回屏幕。补练后用新例复验，随后隔几题再验同一关系；不要立刻原题重做一次就宣布掌握。

## 九、最终验收不应要求的伪能力

- 不要求用户从一张牌面“推导”课程67%等精确数值；资料和求解模型不足以支持。
- 不要求用户只凭一次跟注就精确知道范围权重；可以练识别保留可能性、条件证据与必要重估。
- 不要求所有牌严格归入互斥的“价值/诈唬/保护”之一；效果可能叠加。
- 不把原文“更多X”“候选”“高频”升级成100%、50%等未记载频率。
- 不把原表“约值”作为计算出的唯一最优点；课程复现与模型优化是不同目标。
- 不把选项语言排除能力当扑克理解：干扰项应对应另一组真实条件下会成立的判断，不能总是“永远”“任意”“自动”这种明显错误项。
- 不因没有完整策略答案就关闭所有相关认知练习：完整动作节点关闭，但事实识别、条件识别、价格计算、指出信息缺口仍可以有严格正确答案。

这部分的成功标准是：用户能在未提前标注原理的新题里找到决定性事实；条件改变时愿意并且能够重新判断；遇到课程精确规则能够执行；遇到未提供完整信息的情形不会把一个局部理由当成完整最优策略。
