# 后续街与连续执行：逐步骤原理及练习备忘录

研究日期：2026-10-18。用途：供主手册整合；未修改软件。

本备忘录以 Nevir 2.4—2.7 为课程依据，以现有 `src/rules.js` 与 `src/data/sources.json` 的 T01—T10、R01—R08 为实现核对。外部资料只核验基础数学与适用边界，不新增外部翻后策略表。

## 一、先把后街真正要学的事情说清楚

翻后每发生一次行动，都有两件事发生：一是钱和行动顺序变了；二是我们对双方可能持牌的判断变了。发出新牌又有第三件事：这些仍可能存在的牌，有的改善，有的相对变弱。

所以后续街的学习顺序应是：**保留上一街的信息 → 根据行动缩小可能性 → 看新牌改变了谁 → 再决定这次下注希望得到什么 → 被反击时再次更新。** 不能每换一街就用完整翻前范围重新抽一道独立题。

这直接来自 2.6 §3.4 第33—39行的连续问题：哪些牌跟、哪些弃、什么转牌继续、什么转牌放弃。2.4 第7—18行解释范围下注后双方范围不再一样；2.7 §3.6 第31—35行说明同样到河牌，走过的线路不同，后续倾向也不同。

## 二、步骤1：一声“跟注”之后，对手还可能有什么

### 用户先要理解什么

“范围变强”不是对手的牌偷偷换了，而是我们已经看见一次筛选。原来可能拿差牌也可能拿好牌；他跟注以后，原来会弃掉的那些情况不再解释当前行动。

但跟注也不等于排除最强牌。如果他有时用强牌跟注，强牌就必须保留；如果他用强牌更常加注，强牌在跟注范围里的份额才可能减少。过牌、跟注、加注都需要同样的条件推理，任何动作都不是一张确定底牌。

### 直观示范

先显示10张“可能持牌小卡片”，例如4份未成对、4份一对、2份强牌。它们是教师明确给定的等权教学样本，不是假装真实完整范围。

1. 对手类型A：4份未成对全部弃牌，4份一对全部跟注，2份强牌中1份跟注、1份加注。
2. 用户点击“他刚才跟注了”，动画只保留4份一对和1份强牌。强牌仍占1/5。
3. 只改一个条件：类型B的两份强牌都慢打跟注。跟注后留下4份一对和2份强牌，强牌占2/6。
4. 问“同样是一声跟注，哪一种对手保留更多强牌？”答案B。随后问“能否因此说A绝无强牌？”答案不能。

一开始不要求手算贝叶斯公式，先把被保留和被删除的具体牌摆在屏幕上。不能把10个展示样本误说成真实的组合频率；若要按组合权重教学，必须改用所有合法组合及其明确权重。

### 计算与生成

对每个合法组合 h，更新式为：

`新权重(h) = 原权重(h) × 该手牌采取已观察动作的概率 / 全部组合的同类权重总和`。

新公共牌出现后，先删除与英雄底牌或公共牌冲突的组合，再归一化；零概率动作分支不可被发成普通练习题。要模拟多人、加注、不同下注尺度，动作概率必须条件于对应局面，不能复用一个“对手跟注率”。

后续练习可以依次让用户：点掉确定弃掉的样本 → 保留可能慢打的强牌 → 比较两位对手 → 在给定概率下比较比例 → 最后只根据课程已知方向判断“能排除/不能排除”。资料没有动作概率时，不给伪精确的后验百分比。

### 判分及错误补教

- 把跟注当成无强牌：回到“有一手强牌选择跟注”的单张演示。
- 把加注当成必然坚果：明确给一手诈唬加注作为模型条件，展示加注范围也可能混合；不是凭空断言真实对手会诈唬。
- 按原来完整范围继续判断：让用户指出刚才已经弃掉的那张牌为什么不能重新出现。
- 不会比较比例：先用等权小卡片计数，再加入非等权组合，不能同时教牌力、概率和行动。

## 三、步骤2：转牌改变的是剩下的牌，不是抽象的“高牌/低牌”

### 每张新牌按这个顺序看

1. 我的最佳五张或听牌发生什么变化？
2. 上一街留下的对手组合，哪些改善？必须点出具体组合。
3. 即使我的牌没有变化，相对强弱是否变化？
4. 这是课程哪条前序线路？该线路有没有明确执行规则？

牌型变化可以精确计算；行动规则必须来自对应课程节点，不能只凭“对手改善”推导统一尺寸。

### 生成方式

事实练习可以先指定关系再生成合法牌，例如“顺子完成且英雄一对未改善”，用七张牌评估器核验。策略练习仍使用明确课程节点，只做保持结构与规则不变的等价变化；没有依据的新结构可以训练发现变化，不能附带自编的精确最优动作。

同一单元要有三类题：外观变了但关系不变；只改变一处关键事实而结论变化；看似相关却不满足前序条件的反例。不能把任何转牌都强行归为一个排他的类型：同一张牌可以同时完成同花、连接顺子并配对，生成器应保留多标签，再算实际组合变化。

### 错误补教

用户把“高牌”视为必打，就给同一高牌、不同前序/剩余范围对比；用户说“我还是超对所以没变”，就把对手新成的顺子摆到旁边；用户不会看顺子，暂停策略问题，先做最佳五张选牌；用户把75%当数学唯一解，回显源资料70%—100%与执行约定的不同身份。

## 四、步骤3：河牌先决定这笔钱想从哪里来

没有新牌要发，教学可以第一次把“结果分支”完全算清楚。先从IP、对手过牌、无加注、无抽水的有限模型开始；OOP过牌后对手还能下注，不能直接当免费摊牌。

### 价值：比过牌多得到什么

教学牌面 A♠7♥2♦K♦3♥，英雄 A♥K♣。给定对手范围中80%是英雄能赢的AQ/AJ等，20%是英雄输给的77/22等；具体权重由题目声明，不声称来自课程。底池P=20，拟下注B=10。

- 情况A：所有范围都跟注。过牌EV为0.8×20=16；下注EV为0.8×30−0.2×10=22；下注比过牌增加6。
- 情况B：原有80%的差牌中，70个百分点弃牌，仅10个百分点差牌跟；20%的好牌仍跟。过牌EV仍为16；下注EV为0.7×20+0.1×30−0.2×10=15；下注反而少1。

直观解释：让本来就输给我的牌弃牌，河牌并不会凭空多赚；赢的时候多得到B，输的时候也多损失B。应比较跟注者，而不是只数全部范围里我赢了多少。

在这个无加注、没有更好牌弃牌的模型里，被跟注后胜率超过50%才让下注比过牌更有利。该条件不能机械外推到可能被加注、存在更好牌弃牌、多人或还有未来街的情形。

练习依次为：点出会付钱的差牌 → 点出会让我多输的好牌 → 预测只改变一组跟注意愿后差异 → 最后选行动。算术放在展开层，不要求用户先算出22才能理解。

**笔记支撑：**2.6 §3.4“哪些牌跟/弃”；现有R01、R02为原理补充，没有给统一河牌尺寸。外部核验见下文E3。

### 诈唬：需要赶走多少更好的牌

在河牌、被跟必输、过牌也无价值、无加注的模型里，`EV(诈唬)=F×P−(1−F)×B`。保本弃牌率为 `F=B/(P+B)`。

P=20、B=10时，需超过1/3的弃牌率。F=40%时EV=2；F=20%时EV=−4。两道题只改变已明确给定的对手回应，不改底牌，用户就能看见“没中听牌”本身没有给出正确动作。

练习：先点要赶走的更好牌，再看这些牌是否会弃，随后比较成本；没有回应数据时，正确结果是“缺少决定性的跟弃信息”，不能硬给一个肯定诈唬答案。若过牌有摊牌价值，还必须比较下注和过牌的EV，不能只检查诈唬EV大于0。

**笔记支撑：**2.6第33—39行；2.7第31—35行。R03、R06、R08提供方向，未提供统一真实弃牌率。

### 跟注：便宜不等于应该跟，赔率不能替你估计诈唬

河牌底池原为P=20，对手下注B=10，跟注还要付C=10，跟后总底池40。若跟注终结行动，所需胜率为 `C/(当前底池+C)=10/40=25%`。

若明确给定我们只赢诈唬，对手范围8份价值、2份诈唬，则q=20%，跟注EV=0.2×30−0.8×10=−2；改为7份价值、3份诈唬，q=30%，EV=2。价格完全没变，正确决定因对手范围而变。

若对手加注：原底池20，我先下注10，对手加到总额40，当前底池70，我还需补30，跟后100，所需胜率30%。此时应估计的是“他加注的范围”，不能继续用“他会跟注的范围”。之前投进去的10已经不属于眼前补30的决策成本。

先练点击当前底池与待补金额，再练给定范围下胜率，最后才连接课程的少诈唬/强范围方向。只给赔率、不给范围时，只判所需胜率，不判具体跟弃。平局按赢得半个底池计入权益；有抽水或额外费用时需在模型中明确计入。

**笔记支撑：**2.7§3.3—3.6；R04明确只提供赔率而不自动跟弃，R05明确被加注后重估。赔率数学来自基础推导，外部核验见E1。

## 五、步骤4：把三条街串成同一手牌

### 最小连续界面

一直保留六人座位、英雄底牌、公共牌、底池、有效后手，以及一行历史：例如“翻牌你下注 → 对手跟；转牌……”。每次只展开当前需要的问题。

教学时可以显示对手可能持牌卡片；撤除提示时盖住卡片，但不删除此前已经公开的动作和金额。不能为了难度要求用户凭记忆复述动画，也不能把本来未知的真实底牌提前透露给行动题。

### 算账示例，不是下注处方

无抽水六人100BB局，示例到翻牌底池6BB、双方剩余97.25BB（例如BTN开到2.75、BB跟、SB投入0.5后弃牌）。翻牌双方投入2BB，转牌底池10BB、双方95.25BB；转牌双方投入7BB，河牌底池24BB、双方88.25BB；若河牌双方再投入18BB，最终底池60BB、双方70.25BB。

这个例子只用于验证底池与筹码状态持续更新。2、7、18不是自动正确路线，任何动作节点的策略仍需课程依据或完整明确的教学模型。

### 三条最有教学价值的路线

1. **小注→被跟→新牌变化→停止机械超池。** 986tt小注被跟，空白转牌满足T07条件可考虑超池；被跟后河牌7让牌面更连接，进入R07重估。最后只判“应重新检查哪些组合改善”，不能假装资料给了完整河牌动作。
2. **X/R获利→被跟→愿意停。** OOP 3bet T83r，对手小注且对X/R过弃；X/R被跟后空白转牌先更多X（T08）。让用户解释“前一枪有利为何不要求下一枪继续有利”，防止沉没成本式三枪。
3. **一次示弱线与连续跟注线对比。** 同类OOP SRP，线路A曾X–X且已知后街过弃（T10/R08）；线路B翻转都B–C且已知跟转后河牌少弃（R06）。保持英雄同样没中听牌，检查用户是否读取历史，而不是看到空气就诈唬。

学习阶段逐步问“现在留下谁→新牌改变谁→想得到什么→选动作”；独立阶段只让用户行动，错误后再展开最早出错的那一步，避免每手都填四道表。

### 路线生成与判分

状态至少包含：场景/位置、街、唯一牌集合、各方本街投入、累计底池、剩余筹码、行动顺序、前序动作、范围权重或来源、对手回应模型、策略节点ID和条件。

每一步都要检查合法加注额、可跟金额、筹码上限、范围归一化、牌张冲突，以及进入下一课程节点的条件。不要从不同来源各抽一条局部答案拼成“完整GTO线路”。如果用户选择了课程未覆盖的动作，教学可回到有依据的分支；不能暗中用原本另一条分支的答案继续评分。

## 六、步骤5：偏差调整必须教成条件句

笔记的大量建议来自特定线路的人群数据。可学的是“已知某种回应偏差，何种调整方向有理由”；不能学成“给对手贴标签后，所有牌局都这样做”。

例如同一0权益河牌诈唬，P=20、B=10：明确F=40%可算正EV；只说“对手是常规玩家”无法据此把F设为40%。如果只知道F在20%—40%，EV在−4到2之间，正负号会变，答案只能是信息不足。若F在40%—50%，该给定模型内下注EV为2—5，方向稳定，但仍需比较真实的过牌价值与其他行动。

这比让用户盲猜一个精确频率更接近实际：先区分观察事实、课程人群倾向、题目人为给定，再看哪项是决定当前动作的关键条件。

不得由一两次跟弃推出稳定人群参数；本软件没有数据库，也不承担自动建立对手画像。外部数据只能用于说明原理，未验证到当前用户场景的统计不变成精确判分基准。

## 七、共同教学标准与错误分类

| 用户错误 | 应回到的最小教学 | 可观察的通过证据 |
|---|---|---|
| 读错顺子/同花/踢脚 | 只摆双方最佳五张并逐张比较 | 新牌面能选出正确五张 |
| 忘记跟注筛掉谁 | 保留上一街、重播一次动作并划掉不再相容的样本 | 不把已弃范围搬回下一街 |
| 把过牌/跟注当必然弱 | 展示同一强牌也可以慢打的明确分支 | 能说“减少可能性”而非“绝对没有” |
| “强牌就下注” | 保持英雄不变，只改变差牌的跟注意愿 | 能找出付钱对象，并在对象消失时重新比较 |
| “没中就诈唬” | 保持空气不变，只改变更好牌的弃牌率 | 能同时检查弃牌对象与成本 |
| “赔率够就跟” | 先算价格，再给不同下注范围 | 能分开所需胜率与实际胜率 |
| 前街打了必须继续 | 同一前街、两种后续筛选/新牌 | 能接受前街+EV而后街停止的线路 |
| 把执行约定当理论精度 | 对照原记录的方向/区间与软件取值 | 不凭空要求资料没有给出的频率和尺寸 |
