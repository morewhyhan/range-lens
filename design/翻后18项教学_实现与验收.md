> **实现快照边界：** 本文验收的是 v1.1 的 18 项专项运行版本；“目录可自由跳转”是当前专项功能的事实记录，不是最终首课设计。最终目标的用户首课必须沿唯一嵌套路线推进，不能把 18 项当作平铺首页。后续实现以 `research/nevir-system/170_低基础首课黄金路径与逐屏交接脚本.md`、`177_学习者可见七步路线与35项释放交叉合同.md` 和 `179_全项目文档一致性与当前实现边界合同.md` 为准。本文的技术通过不代表低基础学习者试读、迁移能力或 NL50 证据。

## 一、逐项教学覆盖

每项学习都有手动示范、补一步、两次条件对照和独立判断；根据能力接课程动作或事实应用。目录可自由跳转，不强迫每手牌依次完成18步。下表列出实质任务，完整变式见 `SKILLS` 与生成函数。

| 能力 | 用户实际观察或操作 | 对照与应用 |
|---|---|---|
| 01 局面 | 读六人桌、前序，判断行动者、底池类型和合法动作 | 更换先后行动、是否存在待跟金额；连接课程动作 |
| 02 最佳五张 | 从七张中点选五张、比较摊牌、按顺序点击九种牌型 | 踢脚改变胜负；等价花色不改变结果；随机合法新牌 |
| 03 听牌 | 点顺子补牌点数，辨认直接花听、后门、重复补张和无效补牌 | 改变连接关系；成花仍输葫芦的具体例子；枚举实际获胜补张 |
| 04 结构 | 六类入口、13组原表对照、具体牌型改善 | 变化发生在实际牌面；D05/D06等有明确来源的对照 |
| 05 范围 | 排除撞牌，区分合法、证据、权重和未知 | 替换冲突牌张；改变权重；缺依据时不假定完整范围 |
| 06 优势 | 逐组比较，再算加权结果，区分平均与强端 | 改变权重；同一局面分别判断一手领先与整体领先 |
| 07 过牌 | 预测过牌后交给对手、发牌或摊牌 | 先行动与后行动、河牌与前街对照；连接I12/P06 |
| 08 下注作用 | 找实际付款者、退出者，比较相对过牌的新增收益 | 差牌付款变为弃牌、好牌是否退出、未来反超；给定模型验证 |
| 09 手牌任务 | 区分价值、改善候选、摊牌保留，分开尺寸与频率 | 同一牌面换AA/77等；课程候选不判成必下 |
| 10 尺寸 | 切换动作看各组回应，先预测，再揭示完整收益 | 只改回应或权重；包含最优动作反转与不反转；对接课程尺寸 |
| 11 面对进攻 | 先辨认当前已是跟弃加问题，找待补与加到金额 | 给齐/撤掉对手条件；加注后不能继续沿用持续下注题 |
| 12 范围更新 | 选仍可能存在的组与更新后最多的组 | 按权重×响应重新归一；强牌慢打仍留下；候选名称随机化 |
| 13 转牌事实 | 看新牌让具体候选如何改善，比较相对牌力 | 顺子、四同花、剩余范围的实际成牌变化 |
| 14 转牌路线 | 把同一张转牌放回此前下注、跟注和尺寸 | 前序匹配、延迟下注；不套“高牌继续低牌停”口诀 |
| 15 河牌主动 | 找谁会用差牌付钱、好牌是否退出以及诈唬成本 | 改变回应；完整模型比过牌、小注、大注；阻挡只判实际移除 |
| 16 河牌防守 | 点击待补金额，先算价格，再结合给定范围 | 同价格不同范围、平分、加注待补；只有价格时承认不能定跟弃 |
| 17 条件调整 | 找支持偏离基准的证据，检查输入不确定性 | 撤掉条件、改变输入、变化尚不足以反转；保留课程调整前提 |
| 18 实际连接 | 在相容短片段里执行，或直接练课程动作 | 保持牌张、金额、前序、候选与权重，资料不足处结束 |

示范显示答案但不计分。学习作答后停留；自己练正确后约750毫秒自动继续，错误或不知道停留解析。多选、五张、排序和金额点击均由代码判定；同值最佳五张允许不同实体牌组合。

独立任务收起原理提示，必要的题设继续保留。实例按会话去重，花色等价和候选改名不当作新知识；有限课程复现显示巩固复习。生成题不宣称无限独立战略样本。

## 二、来源与答案精度

原表映射共71条：13个D分支、40个翻牌节点、10个转牌节点、8个河牌节点。58个策略节点中53个开放，按任务和手牌细分为75个课程案例身份。目录中全部71条可定位，待补条目可见但禁止启动精确策略。

关闭：O01、O02、S06、P01、P07。没有用外部策略填补这些缺口。相同牌面的事实题不因此禁用。

来源标签区分牌张规则、给定模型、课程、原理补充、训练约定和条件调整。R01—R05保留原资料“原理补充”身份；近似频率保留“约”；候选不升级为强制动作，更多过牌不升级为100%。

S09的77/88标注为超对兼顺听候选，不凭此断言纯价值下注；原动作“可进入50%下注端”保留。D01左板修正为A72，与AK2对照及原解释一致。

来源核验脚本检查原表标题、策略、解释及单元格索引，校验原工作簿未改动。它不等于重新验证全部嵌入图片，也不等于独立求解完整扑克策略。

## 三、计算与连续片段

牌张核心计算最佳五张、平分、顺子与补牌。有限模型必须给齐候选、权重、回应和计量终点，再计算权益、收益、价格及后验概率；不能把教学模型最优动作当成新增GTO答案。

收益统一从当前决策点计量，包含弃牌收益、被跟获胜与失败投入，不只看被跟后的权益。范围更新按先验权重乘相应响应概率再归一。无效输入、撞牌、缺少回应或不成立筛选明确报错。

| 片段 | 继承与终点 |
|---|---|
| KT5小注 → T01 | 同一翻牌加入转牌；底池20→33.2BB、双方后手90.75→84.15BB；33%与75%的具体执行值按训练约定说明 |
| T07 → R07 | 保留快打及过弃等前提；底池10→35BB、双方95.25→82.75BB；河牌重估，不编造最终跟弃 |
| O07 → T08 | 保留对手弱牌小注、面对过牌加注过弃的条件；21→61BB、双方90→70BB；先更多过牌不意味着后续必弃 |
| 完整给定模型 | 翻牌筛选后候选权重13.79%/68.97%/17.24%，转牌7让85成顺，河牌沿用候选、物理牌张与权重；河牌三动作收益约1.38/−2.93/−7.24BB |

模型片段的候选名称保持跨街稳定，避免随机改名破坏继承；普通题的候选改名则与答案同步，避免靠组名记忆。

## 四、界面、反馈与产品约束

- 中央显示牌张和当前任务，两侧放六人桌、前序、条件、候选及来源；必要信息可回看。
- 原条件/改变条件可切换，具体回应随动作更新；非示范题先预测再揭示收益。
- 未知按错计分；多次点击不会重复计分。实际单项、模式、子任务、来源节点、场景筛选及混合集合分别计算当前成绩。
- 错题显示可核对的最佳五张、补牌或条件。仅凭最终动作错误时先询问核对哪一步，不猜定心理原因，再进入对应补练。
- 原表快练和翻前保留；翻前边缘比例与池选择按各自职责处理，全范围模式忽略边缘设置。原SVG手牌格保留双层定位描边。
- React状态只在内存中维护。没有浏览器存储、数据库、账号、长期进度或对手画像；桌面临时会话退出清理。

## 六、实际试用时怎样检查是否学会

本轮无需增加保存机制。进入一个尚不熟悉的单元，完成示范和对照，再切自己练；检查能否在提示收起后：

1. 指出具体决定差异的牌、对象或金额。
2. 在关键条件改变时相应改变判断，在无关变化时保持判断。
3. 在未展示实例中独立完成，而不是记住组名或按钮位置。
4. 在支持的连续片段只点最终操作，并把前序带到下一步。

如果仍只会代入模型、不知道条件为何成立，应回到范围依据与条件单元；若读错顺子或五张牌，先补读牌。试用中发现的困难需要据此调整教学，不能用自动测试通过来否定用户反馈。

## 七、仍受原材料限制的内容

五个待补策略节点未开放；课程未提供完整范围或后续动作时不生成精确答案。连续练习只覆盖四种相容片段，不是任意牌局的完整三街求解器。课程题存在有限原例，重复时标明复习。未覆盖多人、任意深度或完整跟注方防守体系。

交付完成的是实现和技术验收；真实理解、保持与实战迁移仍待用户试用验证。
