# 产品定义与统一设计决策

上层：[阅读入口](../00_从这里开始.md)。下一层：[主线与首遍](../02_教学与课程/01_主线与首遍.md)。

## 1. 用户与结果

预设用户可能不会一眼识别顺子、不会比较最佳五张、不理解范围，也不愿先读长篇扑克术语。页面应支持慢读、慢算、大屏与键盘操作。年龄只是易理解程度的表达，不能作为是否会学会的测量指标。

结果分为四层：

| 结果 | 用户能做什么 | 怎样证明 |
|---|---|---|
| 首遍有结构 | 知道每步先看什么、交给下一步什么、卡住回哪里 | 隐去标题后还原路线，并定位新场景 |
| 单步能执行 | 在资料充分的陌生题中完成判断、动作和金额 | 未见题首答，分开检查事实与策略 |
| 能迁移和连续 | 条件改变后会重查，三街不丢范围与账本 | 独立对照题、未见连续路线 |
| 目标级能力 | 在冻结目标条件中稳定做出有依据的决策 | 匹配参考、独立复核和实际决策评估 |

“一次跟完”要求建立结构，不要求一次记住所有策略。完整训练保留NL50方向；本设计不把它替换为“能完成软件题目”，也不作未经验证的保证。

## 2. 固定范围

| 事项 | 最终规定 |
|---|---|
| 桌型与筹码 | 六人无限注德州现金桌，起始有效筹码100BB。进入翻后后的剩余筹码从历史计算，不能仍填写100BB |
| 活跃人数 | 首批精确翻后课包为两名仍在底池中的玩家。六人背景不等于六人同时求解。多人底池可教事实，缺多方策略就不开放精确动作题 |
| 翻前 | 只训练用户最后确认的简化开池、3bet相关防守、大盲防守图；不自行扩展挤压、4bet及其他范围 |
| 翻后 | 课程只帮助设计训练结构；正式策略题由固定配置求解结果生成。没有求解数据的策略节点暂不开放，不以课程文字代替 |
| 读牌 | 六类牌面、牌力顺序、最佳五张、顺子、听牌、后门、改善与反超 |
| 操作 | 常见动作按钮直接选择，保留“我不知道”；教学所需的点牌、排序、看变化属于当前题内短交互 |
| 记录 | 当前会话正确／错误计数；不登录，不建数据库，不自动保存进度、偏好或错题 |
| 运行 | React本地训练器，沿用现有Electron桌面路线，最终Windows EXE可离线练习已安装课包 |
| 风格 | 极简、圆润、克制，中心训练区，近似桌面应用；无宣传首页、仪表盘和满屏统计卡 |

抽水、参考行动树、精确3bet尺寸等属于课包配置，不能由“NL50”三个字符自动决定。研究课包可声明自己的配置，但不能冒充目标基准。

## 3. 入口与模式

翻后直接进入具体局面，在同一个界面自然提供“换手牌，练这里”和“继续这手牌”。前者保持决策点，后者保持实际底牌和历史继续。不得再以六种概念专项列表或强制连贯课程作为默认入口。

场景、双方位置、牌面与前序由“更换局面”逐层选择。当前只显示必要操作，概念分类作为后台出题与覆盖结构。

三种方式共用同一课包：

| 方式 | 用户体验 | 信息与推进 |
|---|---|---|
| 跟着学 | 看示范、做一个小操作、看变化、说出下一步 | 允许先展示示范答案；清楚标“示范，不计分”；关键解释后手动继续 |
| 专项练 | 当前原理下连续答题，支持边缘／内部等覆盖参数 | 首答后判分；答对短暂反馈后自动下一题，答错展开解释 |
| 连贯练 | 同一手牌中依次行动，跟随真实后继 | 对手动作与发牌来自课包；没有后继就停止，不能悄悄换手 |

综合练是专项的“在已选覆盖范围内混合”，不是第四套页面。是否随机出题与是否随机执行策略分开：题目顺序可变；混合策略题始终回答整组频率，不掷硬币指定本次动作。

## 4. 旧方案冲突的最终裁决

| 旧冲突 | 本套设计采用的规则 | 理由 |
|---|---|---|
| 多套阶段与路线编号并存 | 用户只见准备与七步；作者端用语义ID，不增加用户阶段菜单 | 防止学习导航重新混乱 |
| 所有答对都自动跳走 | 快练自动跳；示范／关键范围变化由“继续”推进 | 用户必须看见因果变化 |
| 错题必须不断重答才能继续 | 展示答案和局部解释后允许下一题；建议一题同构巩固，不强制困住用户 | 尊重用户要快速练习的要求 |
| 一次点击能诊断所有错误 | 错误原因默认未知；用户选择“牌／范围／价格／规则没懂”才回相应子层 | 不能从一个按钮推断心理过程 |
| 无保存却长期解锁 | 会话内推荐进阶；下次可自行选择起点，不声称记得上次水平 | 不引入隐含数据库 |
| 课程文字直接作策略答案 | 正式策略训练必须匹配求解数据；课程只作编排参考；确定性事实仍独立计算 | 遵守用户2026-11-01明确修订 |
| 0／50／100用于所有翻后 | 翻前严格照图；翻后仅在课程明确采用且有依据时量化 | 不擅自改写课程频率 |
| 只改一项就只变化一个字段 | 只改一个独立输入；所有派生字段重算并显示 | 改尺寸会合理影响价格、底池和后继 |
| 前后范围同一分母 | 固定质量视图用同一基准；相对构成视图各自归一化且明确标注 | 两种图表达的问题不同 |
| 手里有A就适合诈唬 | 先看它移除了对手哪些行动组合，再比较全部动作 | 阻挡事实不能单独决定策略 |

这些裁决取代旧研究中相冲突的表述；原始用户要求与原材料内容不因本次整理而被改写。

## 5. 内容身份必须在页面可辨认

每题有简短标签，默认只显示一个：

- **读牌事实**：牌力、金额、合法组合等可独立核算。
- **给定实验**：已明示对手范围与响应，用于看清一个机制。
- **课程打法**：按笔记明确规则作答，附适用局面。
- **参考策略**：按固定输入的求解结果学习频率与价值。
- **条件调整**：特定对手倾向下的课程／锁定模型，不当作通用基础。

缺资料的节点在专项选择里显示“暂未开放”；连续练到该处显示“本段到这里”，说明缺什么，可以回看或换下一段。系统题目自身缺证据不计用户错误。“我不知道”是用户作答，计错；两者不能混在一起。

## 6. 每个教学点都必须有可见的证据图层

用户要求的“看到动作以后范围怎样变”是策略教学的核心能力，不是解析页面的装饰。每个教学点先登记自己的证据身份，再决定页面显示什么图：

| 教学点身份 | 是否必须有GTO图 | 页面主图 | 可以回答什么 |
|---|---|---|---|
| 牌力、最佳五张、顺子、听牌、摊牌事实 | 不必须 | 牌面、最佳五张、补牌与结果图 | 眼前发生了什么 |
| 给定范围／赔率／EV实验 | 不自动称GTO | 实验范围、筹码路径、公式和前后质量图；有匹配求解时叠加对照 | 某个独立变量怎样改变结果 |
| 翻后课程动作 | 必须有匹配GTO或明确课程来源 | GTO策略矩阵＋课程简化覆盖＋动作后范围变化 | 为什么此动作在该配置下成立 |
| 阻挡牌、尺寸、范围筛选等策略原理 | 有策略结论时必须绑定 | 具体组合删除／变薄／变厚＋GTO动作频率和EV差 | 牌张事实怎样进入策略影响 |
| 情境识别、位置、读历史 | 不必须 | 六人桌、行动历史、合法动作和价格 | 当前处于什么局面 |

这里的“必须有GTO图”指必须能追到固定配置下的匹配求解节点，或者明确标记为“课程规则，尚未与GTO校准”并限制训练权限。不能把一张静态13×13图、一个案例方向或一段文字自动叫作GTO。

这里有两个需要同时避免的极端：所有内容都硬套求解器，会让牌力、听牌和金额这种确定性事实被无谓的策略噪音遮住，也会让低基础用户误以为求解器图本身就是原理；完全不接求解器，则会让阻挡、尺寸、范围筛选和下注频率变成没有可复核来源的口号。最稳妥的做法是按“结论类型”分配证据：事实用确定性计算，因果用给定模型，课程动作保留材料规则，策略主张再绑定同配置GTO，并在图上明确叠出课程如何覆盖或删减参考策略。

图表不是把所有信息同时铺满。首答只显示当前决策所需的状态；答题后按“策略 → 范围变化 → 后继”逐层展开，用户可以点具体格子和组合。这样既保留极简界面，也让每个结论有可检查的依据。

## 7. 本次改型的交付边界

课程数据、运行代码、学习者效果三项分别验收。系统有能力自动出题，不代表所有牌局已有正确答案；课包没覆盖的场景不能放进题池。当前所有旧研究数字只作历史证据，不把35项或某次审计次数当作产品完成比例。

用户约束与材料权限的依据见[来源与决策](../05_交付与依据/02_来源与决策.md)。
