# 翻后：按原理分类，按真实决策使用

上层：[七步主线](01_主线与首遍.md)。练法：[练习编排与教案](04_练习编排与教案.md)。公式：[状态、范围与公式](../03_数据与算法/01_状态范围与公式.md)。

## 1. 本质关系

翻后不能像翻前一样靠一张固定位置图完成所有决策，因为同一手底牌会随公共牌、前序行动、双方范围、价格、后手和对手回应而改变用途。但它仍然可以结构化：

> 先确定双方到这里可能有什么，再比较合法动作会让哪些牌留下、付出多少钱、进入什么后续，最后使用已核对的课程规则执行。

“原理”不等于用几个指标凭空推出全游戏最优。通用公式能核对事实和给定模型；真实动作频率仍来自课程明确规则或匹配参考。训练必须把事实、因果比较与行动处方接起来。

## 2. 一道题的定位坐标

| 坐标 | 必须区分 | 为什么影响结果 |
|---|---|---|
| 底池 | 单加注／3bet／其他未覆盖 | 起始范围与底池后手比不同 |
| 位置 | 有位置／无位置，实际先后行动者 | 权益实现、过牌的代价与后继不同 |
| 角色 | 翻前最后加注者／跟注者 | 高对、同花连张与强牌份量不同 |
| 街次 | 翻牌／转牌／河牌 | 未来改善机会不同 |
| 当前状态 | 无人下注／面对下注／面对加注／全下／终局 | 合法选择和价格不同 |
| 历史 | 哪一街谁用什么尺度、谁跟或加 | 当前范围由历史筛选而来 |
| 牌面与底牌 | 具体点数和花色 | 牌力、出路、阻挡均受影响 |
| 金额与对手条件 | 底池、后手、抽水；基础或条件调整 | 动作价值不能跨配置照搬 |

这些是后台选题坐标，用户只看到完成当前判断所需的摘要。不能先生成一块牌面，再随意贴“有位置3bet”标签。

## 3. 五种实际情况

### 3.1 现在没人下注：过牌还是下注

依次问：

1. 过牌会保留什么赢面与后续机会？
2. 下注时哪些更差的牌会付款？哪些更好的牌会退出？
3. 被跟后自己的权益和后续如何？被加注怎么办？
4. 哪个已核对尺寸与当前课程范围匹配？

教学重点是与过牌比较。强牌可能需要保护过牌范围，中等牌可能从小注中获益，弱牌可能既有弃牌收益又有改善权益；这些用途不互斥。不能先贴“价值／诈唬”标签就忽略其余效果。

### 3.2 面对下注：弃、跟还是加

先算待补金额，再看对手**下注后的范围**。分清自己能否赢一些正常取值牌、只能赢诈唬，还是主要依赖改善。加注是另一个独立选择：更差牌是否会付更多、更好牌是否会退出、遭再加时损失什么。

河牌最后跟注可以直接比较权益与价格；翻牌／转牌有后续行动，不能只用摊牌权益大于当前门槛就宣布必跟。改善会不会赢、赢时还能收多少钱、落后会不会付更多，都要在给定后续树里比较。

### 3.3 面对加注：重新识别局面

自己原本的价值下注牌，面对强加注范围可能只剩抓诈。先核对“对手加到多少”和“我还要补多少”，再使用**加注后的范围**比较弃、跟、再加。此前下注的钱属于沉没投入，不能成为继续跟注的理由。

有位置不保证最后行动；被再加后仍可能重新决策。短码全下、未达到最小加注幅度、是否重新开放加注权，交给合法动作引擎；不把每次加注都当成正常2.5倍。

### 3.4 对手回应：范围与账本更新

对手跟注以后，留下的是按其跟注频率加权的范围。自己若用全范围下注，自己在该动作后的单方质量可能不变，而对手跟注会显著改变双方的相对结构；带牌张相容性时也会影响双方边际范围。

双方过牌不等于双方都没有强牌。“跟注后封顶”“过牌后一定弱”只有在具体响应规则支持时才能用于课程。慢打仍有权重时，强牌不能被画成零。

### 3.5 新公共牌：继承后再重查

先继承此前行动后的范围，再移除与新牌冲突的组合，重算最佳五张、听牌、强端、行动权与后继。不要在转牌重新取完整翻前范围，也不要把“高牌利于加注者”“低牌利于跟注者”当自动策略。

一张转牌可同时配对、补花和改变顺子；“空白”必须相对双方留下的牌定义。在河牌，未来改善机会归零，未完成听牌可能成为诈唬候选，也可能阻挡对手应弃的牌，仍须比较。

## 4. 十二个必须教清的原理

| 原理 | 用户能看见的因果关系 | 学完要能做的操作 |
|---|---|---|
| 局面身份 | 换行动者或前序，合法选择可能不同 | 正确指出轮到谁、面对什么 |
| 价格与筹码 | 新投入改变跟后底池和未来后手 | 区分下注额、加到额、待补额 |
| 牌面结构 | 新牌给具体底牌提供成牌／听牌 | 指出相关组合而非只说干湿 |
| 当前牌力与未来 | 当前领先、可改善、最终获胜不同 | 点最佳五张与实际改善路径 |
| 起始范围 | 翻前历史限制哪些手牌可能出现 | 读取来源明确的双方范围 |
| 物理与行动过滤 | 占牌使组合不可能；行动改变其份量 | 分开指出删掉与变薄的格子 |
| 动作收益来源 | 差牌付款、好牌退出和未来权益同时变化 | 指出本次主要受影响对象 |
| 尺寸与回应 | 大小注会筛出不同继续范围 | 比较继续质量、付款与加注风险 |
| 执行账本 | 动作必须合法且钱守恒 | 给出新增投入和下一行动者 |
| 动作后范围 | 观察动作以后重新加权 | 看懂前后图与同一组合的变化 |
| 未来与后继 | 后街不是重开一题 | 沿真实分支继续或指出缺失 |
| 回看与迁移 | 结果不能改写当时信息 | 识别错层，在新题重用过程 |

## 5. 阻挡牌为什么必须教，又为什么不能独立背口诀

阻挡的第一层是物理事实：我手里有A♥，对手不能有任何含A♥的组合。第二层才是作用：这些被移除组合原本会下注、跟、弃还是加？第三层才比较这对我各动作的价值影响。

三种用途分别练：

| 我现在做什么 | 需要看哪些组合 | 不能直接推出什么 |
|---|---|---|
| 价值下注 | 愿意付款的较差牌、会压制自己的强牌 | 阻挡强牌不必然比阻挡付款牌更有利 |
| 诈唬下注 | 对手会继续的牌与会弃的目标 | 少了继续牌可能有利，但同时少了弃牌目标可能抵消 |
| 面对下注抓诈 | 对手下注价值部分、自己能赢的诈唬部分 | 有A不代表一定减少有效价值，更不能保证跟注盈利 |

示例采用原笔记讨论的T85关系，但具体花色由设计者指定为事实实验：T♥8♦5♣，自己A♥4♥。AT总实体组合由12降为9；ATs仍是3，因为A♥T♥早已被公共牌T♥排除。若对手只用ATs继续，“我有A所以少了AT跟注”就不成立。

同样在此牌面比较Q♥7♥与Q♠7♠：前者可连续两张红心成花，后者不能靠剩余两张公共牌凑五张黑桃。但换花色也改变阻挡对象，不能把全部动作差异归因给后门。该对照教物理与路径，精确动作仍须各自匹配规则。

依据：[Nevir2.1 §3.3](<C:/Users/why/Desktop/笔记 Nevir/2.1- 翻后策略导论_中文笔记.md>)；实体组合与后门复算详见[旧研究14](../../research/nevir-system/14_阻挡与后门怎样接到实际选择.md)。

## 6. 位置、底池和课程材料怎样接到原理

| 课程情境 | 主要教学问题 | 主要材料 | 数据边界 |
|---|---|---|---|
| 有位置3bet | 中部牌是否也愿下注？大小尺寸留下谁？ | Nevir2.2 | 不能把K高／低牌类别直接转为统一频率 |
| 有位置3bet的条件调整 | 对手少加注、多跟或多弃怎样改变收益？ | Nevir2.3 | 人群数字是笔记历史条件，不是当前NL50事实 |
| 3bet转牌 | 前街简化后双方范围怎样失衡？新牌怎么作用？ | Nevir2.4 | 文中高低牌口诀、不同前街尺寸不能合并为无条件规则 |
| 无位置3bet | 主动下注与过牌后响应如何比较？ | Nevir2.5 | 无位置不能单凭位置标签机械放大尺寸 |
| 有位置单加注 | 宽范围中如何组织价值、诈唬与摊牌？ | Nevir2.1、2.6 | “小注后封顶”需真实响应，不默认移除慢打 |
| 无位置单加注 | 盲对盲和开池后被按钮跟注为什么不同？ | Nevir2.7 | 不能把两组位置合并成同一范围与策略 |

跟注方的防守必须作为课程覆盖的一部分；资料不足时明确缺口。不能用只含最后加注者的题库宣称双向攻防完整。

## 7. 旧35项如何保留而不绑死设计

保留旧ID供迁移，用户只见白话。下面每行是一项能力关系，不是一条自动动作规则。新增／合并必须基于真实遗漏或重复，而非为凑数量。

| 旧ID | 当前情境中的关系 | 必需比较／输出 |
|---|---|---|
| 1.1 | 更差牌付款 | 小／大注和过牌的价值贡献 |
| 1.2 | 领先但会被反超 | 退出的权益与下注成本 |
| 1.3 | 赶走更好的牌 | 有效弃牌目标与失败分支 |
| 1.4 | 弱牌有改善 | 自身权益、被加注损失与后继 |
| 1.5 | 有摊牌价值 | 保留摊牌与转为下注的收益差 |
| 1.6 | 强牌先过牌 | 诱导、范围保护、错失价值 |
| 1.7 | 暂无合算进攻 | 为什么过牌优于已有下注选项 |
| 1.8 | 同目的换尺寸 | 各尺寸响应与完整收益 |
| 2.1 | 能赢部分取值牌 | 跟注对整个下注范围的权益 |
| 2.2 | 主要赢诈唬 | 价值／诈唬权重与价格 |
| 2.3 | 靠改善继续 | 真实出路与未来代价 |
| 2.4 | 现在能赢且能改善 | 当前权益与未来权益共同作用 |
| 2.5 | 加注多收价值 | 较差继续牌与再加分支 |
| 2.6 | 加注赶走更好牌 | 加注后的有效弃牌与风险 |
| 2.7 | 继续无足够收益 | 弃牌与跟／加的比较 |
| 3.1 | 重新算价格 | 加到额、已投入、待补额 |
| 3.2 | 原价值牌遭加注 | 牌的作用随对手范围改变 |
| 3.3 | 听牌遭加注 | 新价格、权益实现与再加 |
| 3.4 | 再加多收价值 | 对手继续与全下后继 |
| 3.5 | 再加诈唬 | 弃牌收益与被继续代价 |
| 3.6 | 后手／动作合法性 | 全下、短加注、未匹配投入 |
| 4.1 | 对手跟注 | 按跟注概率过滤的范围 |
| 4.2 | 双方过牌 | 保留慢打与弱牌，不自动清空强端 |
| 4.3 | 自己下注范围不同 | 课程简化如何影响自己到转牌的范围 |
| 4.4 | 早前尺寸／路线不同 | 继承不同响应而非只换标题 |
| 4.5 | 账本与行动顺序 | 同街继续、换街或终局 |
| 4.6 | 结果与决策分离 | 按当时信息回看 |
| 5.1 | 自己改善 | 新最佳五张与作用 |
| 5.2 | 对手范围改善 | 哪些留下的组合增强 |
| 5.3 | 听牌完成／新增 | 双方受益组合与权重 |
| 5.4 | 公共牌配对 | 强牌结构、踢脚、平分变化 |
| 5.5 | 出现更高牌 | 顶对变化与双方命中 |
| 5.6 | 相对空白 | 重新核对无变化与少量变化 |
| 5.7 | 新牌占用组合 | 物理移除和条件化 |
| 5.8 | 到河牌 | 取消未来改善，重评取值与诈唬 |

每项按翻牌／转牌／河牌、角色、位置等登记“适用／有数据／未覆盖”。不枚举所有坐标的笛卡尔积来凑题，也不把不适用格子计作已完成。

## 8. 学会之后在牌桌上怎么调用

慢想卡固定为：

> 谁行动、多少钱？ → 我现在是什么牌？ → 双方一路留下什么？ → 哪个动作让谁继续或退出？ → 按课程动作放多少钱？ → 回应／新牌后重新看。

用户不需要临场算完整求解树。训练负责先把规则和边界学到能够识别，范围图与实验负责解释为什么。未覆盖的节点不能被这张卡伪装成“必定找到最优动作”；它能保证检查顺序，行动质量仍由已学范围与策略证据决定。

## 9. 本轮翻后前置条件封闭结果

现有翻后工作簿实际抽取出58个带身份的策略节点，已经全部进入唯一登记表[src/postflop-registry.js](../../src/postflop-registry.js)：

| 登记状态 | 数量 | 用户能做什么 |
|---|---:|---|
| 课程规则 | 41 | 按来源明确的动作、尺寸、频率或具体手牌任务作答 |
| 条件规则 | 12 | 先看到对手偏差／线路前提，再按该条件作答 |
| 已关闭 | 5 | 不能进入策略题；只能等补充可靠来源后重新登记 |

已关闭节点是O01（三同花OOP 3bet）、O02（对子OOP 3bet）、S06（孤立K高IP单加注）、P01（三同花OOP单加注）、P07（低连OOP单加注）。它们不是“默认过牌”，也不是“答案缺失但仍让用户猜”；系统直接把它们标为资料待补。

每个节点现在同时登记三件事：

1. 答案权限：`course`、`conditional`或`closed`。
2. 范围契约：必须从继承的到达范围出发，用逐组合策略和对手回应更新；当前来源没有完整逐组合策略的节点，范围变化视图保持关闭。
3. 后继状态：已登记教学路线进入下一个具体节点；没有完整后继的节点在来源边界收束，不把单个翻牌方向拼成虚假的三街路线。

这一步把“全部局面”变成了可检查的全集，把不能可靠回答的地方变成明确停止点。它完成的是前置条件和开放边界；后续若要开放精确范围变化或连续策略，必须给该节点补齐逐组合政策、对手响应、合法新牌和后继快照，再通过同一登记测试。
