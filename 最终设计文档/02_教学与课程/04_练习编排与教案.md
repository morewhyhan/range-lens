# 练习编排与可直接制作的教案

上层：[原理分类](03_翻后原理与分类.md)。计算：[公式](../03_数据与算法/01_状态范围与公式.md)。生成：[自动出题](../03_数据与算法/03_自动出题与判分.md)。

## 1. 一项原理怎样从看懂走到会用

每项原理采用同一结构，但内容必须真实填写：

1. **看清具体局面**：牌、历史、范围与金额齐全。
2. **做一次观察**：先点相关对象，或预测下一次变化。
3. **看机制变化**：只改变一个独立输入，重算所有受影响结果。
4. **说成一句规律**：带条件，例如“在这个给定响应下，大注会赶走多数付款的差牌”。
5. **做未见题**：换表面但保持关系，先答再解释。
6. **回真实决策**：依据当前课包的课程动作执行，更新范围和后继。

机制实验和真实策略练习必须相接，但不能混成同一种证据。实验可以完整规定对手行为来显示因果，课程动作需要规则或匹配参考。

## 2. 三张卡是最小结构，不是充足题量

| 卡 | 必须具体填写 | 不能用来充数 |
|---|---|---|
| 基准卡 | 具体牌、双方范围、金额、响应、问题、答案、解释、后继／结束 | 只有“以后填一个案例” |
| 对照卡 | 改动的独立输入、保持字段、重算字段、差异理由 | 只有一组候选变化字段 |
| 迁移卡 | 未见输入、独立答案、适用边界与错误回退 | 原题重答、同一案例只换无关装饰 |

之后扩展成机制族：同机制不同表面、相似表面不同条件、动作不变对照、例外／停止题、隔题回忆、连续应用。界面不显示“基准卡”等作者术语。

## 2.1 每个教案都要有对应的证据图

教案不是一段讲义加几个例子。作者必须在卡片上写明`evidenceKind`：`fact`（牌力／金额／合法性事实）、`experiment`（给定范围和响应的因果实验）、`course`（用户资料明确的打法）或`gto`（匹配配置的参考策略）。只有最后一种可以声称“这是求解器在该节点的策略”。

策略教案的答案屏必须能顺着同一条链查看：先看策略矩阵或动作频率，再点“看动作后范围”，最后进入下一节点或显示停止原因。范围图至少显示动作前总质量、动作后总质量、选中组合的`原份量×动作频率=留下份量`，并可切换质量／构成。没有逐组合政策时不画伪精确范围图，而显示课程规则、实验模型或“资料未提供”。

推荐的用户顺序是：

1. 观察基准图，先说自己看到的关系；
2. 只改变一个条件并预测哪些组合、频率或收益会变；
3. 提交动作或排序；
4. 先看正确答案，再展开参考策略、课程覆盖和动作后范围；
5. 用同机制的未见表面执行，最后接入真实下一节点。

牌力、听牌和最佳五张不需要硬套GTO图；它们使用确定性评估图。机制实验使用给定模型图。只有涉及“应该采取什么动作、频率是多少、动作后策略范围如何变化”的教学点才强制绑定匹配GTO或明确课程来源。这种分层让图表成为证据，不让图表本身制造权威感。

## 3. 教案A：为什么大注不总比小注好

### 3.1 完整给定模型

河牌K♥7♦2♣3♠9♥，自己Q♠Q♣，底池10BB，双方后手50BB，无抽水。对手可能牌：J♠J♦占30%、T♠T♦占30%、A♠K♣占40%。这三组是作者规定的实验范围，不是从真实牌局猜出的概率。

自己可过牌、小注3BB、大注8BB。过牌后直接摊牌；对手面对下注只跟或弃，不加注。实验明确规定其响应：

| 对手牌 | 小注跟注率 | 大注跟注率：版本甲 | 大注跟注率：版本乙 |
|---|---:|---:|---:|
| JJ、TT | 100% | 100% | 1/3 |
| AK | 100% | 100% | 100% |

唯一干预是“较差牌面对大注的跟注率”，其他输入相同。

### 3.2 用户实际体验

第一屏让用户点哪两组牌比QQ差。第二屏示范版本甲：大注被差牌全跟能多收钱。第三屏切到乙，只让JJ／TT变薄，显示“8BB时只剩三分之一差牌愿意跟”。第四屏让用户选择过牌、小注、大注。

从当前节点计算净收益，之前投入不重复扣：

| 动作 | 版本甲 | 版本乙 |
|---|---:|---:|
| 过牌 | 6BB | 6BB |
| 小注3BB | 6.6BB | 6.6BB |
| 大注8BB | 7.6BB | 4.4BB |

乙的大注分解：差牌退出获得底池的贡献4BB，差牌跟注贡献3.6BB，被AK跟注损失3.2BB，总计4.4BB。图先展示筹码路径，再可展开公式。

### 3.3 用户应带走的规律

“不能只看自己领先就加大注；要看多投的钱换来了哪些跟注。”这不是“被跟后权益降低就一定不能大注”的口诀。最终要比较弃牌、跟注、加注和过牌的完整收益。

迁移题改用独立的同构合法牌局和不同金额，让用户先找付款对象，再计算／选动作；同时安排大注仍然最好的反例。真实课程中将此关系接到Nevir2.2、2.6的尺度解释，但不移植本实验数字成为实际处方。

## 4. 教案B：读懂价格，而不是只背出路

河牌对手下注前底池10BB，用户对指定下注范围的权益为30%，假定最后一次决策、没有再加注和后续、无抽水。

- 对手下5BB：跟后底池20BB，跟注净收益为0.30×20−5=1BB。
- 对手下10BB：跟后底池30BB，跟注净收益为0.30×30−10=−1BB。

先点“要补的筹码”，再把待补筹码放进跟后底池。用户看到改的是对手下注额，派生变化是当前底池、待补额和门槛；它们必须一起重算。

保持30%权益不变是本实验人为固定对手范围的条件。真实牌局换尺寸可能换范围，不能直接沿用。迁移题先换牌局／金额考同一关系，再给“范围也变了”的题让用户选择需要重算。翻牌听牌题则显示完整后续，不套用河牌结算公式硬判跟注。

## 5. 教案C：看到阻挡究竟删了什么

用[原理文档](03_翻后原理与分类.md#5-阻挡牌为什么必须教又为什么不能独立背口诀)的T♥8♦5♣与A♥4♥。第一步只数AT全部合法组合12；点A♥后剩9。第二步将AT格展开，只筛同花，用户发现仍是3。

第三步让用户选“减少了AT同花跟注吗？”答案取决于实验给定响应：若仅ATs继续则没有；若ATo也部分继续，则相应继续质量减少。第四步加入同时被阻挡的弃牌目标，显示不能只数强牌。

迁移先练其他合法占牌关系，再进入价值下注、诈唬、抓诈三个用途。范围图给逐组合的响应权重，不靠“红心是好阻挡”的颜色标签判分。实际动作需要匹配参考；没有时只问物理和给定模型，不问“所以你必须下注吗”。

## 6. 教案D：跟注以后谁留下了

给定对手三组范围质量：强牌2、中等牌6、弱牌2；面对下注跟注率分别为1、1/2、0。跟注后的质量是2、3、0，总质量从10降为5；相对构成为40%、60%、0。

用户先看到原来的2／6／2，再看到2／3／0，最后选择是否切到相对构成40／60／0。解释：“强牌份数没有增加，只是其他牌少了，所以现在占比更高。”

再加入慢打对照：强牌过牌／跟注仍可能留下，不能一律清零。三组质量实验说明过滤，不代表真实范围只有三类，也不包含双方牌张相容性；接完整13×13图时由底层组合数据运算。

该教案接Nevir2.4的“我全范围下注而对手筛选后跟注，转牌双方结构改变”，再研究对应转牌课程规则。不能只凭看到相对强牌增加，就自动决定全范围过牌。

## 7. 教案E：后门怎样变成真正听牌

翻牌T♥8♦5♣，对照Q♥7♥与Q♠7♠。先让用户判断现在是否已是直接同花听牌，再展示转牌2♥：前者有四张红心，下一张红心可成花；后者不具备黑桃后门路径。河牌9♥时展示双方最佳五张，而非只播“变强”动画。

如果要展示概率：只知自己与公共牌、均匀未知牌模型中两张红心跑牌为C(10,2)/C(47,2)=45/1081。它是成花事件概率，不是赢牌概率；如果对手范围也条件化了未知牌分布，应重算。

迁移包含无后门、一个后门、两个后门、直接听牌和听牌完成但仍输的情况。学习者最后回到当前动作比较：这条未来路径提供什么机会，被加注放弃又损失什么。

## 8. 教案F：新牌不是重开一题

保留已跟注过滤后的范围和账本，发一张合法转牌。用户先点新牌占用的组合，再看自己和对手范围的最佳五张变化，最后确定现在轮到谁。

相邻对照必须来自同一前序节点的两条机会分支，原分支与对照分支有独立快照。若前序节点也换了，必须标为“换线路比较”，不能声称只有一张牌变化。

课程动作使用各分支的实际规则／参考。没有策略时仍可练物理事实；连续路线到该处收束，不用未知动作接成完整三街。

## 9. 对35项逐项制作时的填写要求

每项使用以下固定内容表，不新增一份独立报告：

| 区块 | 作者必须写出的内容 |
|---|---|
| 归属 | 七步中的父层、情境、先修、来源 |
| 因果关系 | 独立输入 → 派生事实 → 双方范围／收益 → 行动或停止 |
| 基准 | 具体局面与完整已知条件、一个主要问题 |
| 对照 | 一次干预、保持字段、重算字段、动作改变或不变的理由 |
| 迁移 | 未见表面、独立答案、会误导用户的反例 |
| 视觉 | 操作对象、变化前、变化后、返回原题的方法 |
| 判分 | 答案身份、合法答案集合、精度、错误原因与未知处理 |
| 后继 | 对手响应、新牌、下节点或收束 |

当前35项只有大量结构卡位；未填的策略数据不能用教案A—F重复换数字宣称全面完成。前四个机制教案用于建立通用原理，之后必须补齐真实位置、街次和角色的课包。

## 10. 练习量与会话安排

默认一段围绕一个原理：一例示范、两例补步、若干独立变式、一次对照和一次隐藏标题迁移。数量是可调整的产品预设，不是科学证明的掌握门槛。每段以用户能否独立找对象、说出条件和完成动作来决定推荐下一段。

边缘和内部都练。机制理解阶段先用清晰案例，再碰接近边界的牌；快练才按用户比例安排。答错后先解释，再安排一题新的同构变式；隔题回访防止只凭短时记忆。用户可以结束或换专项，当前计数不变成长期能力档案。

外部依据与适用边界见[来源与决策](../05_交付与依据/02_来源与决策.md#3-外部学习依据)。本教案中的模型参数均为设计给定，必须在题中明确标识。
