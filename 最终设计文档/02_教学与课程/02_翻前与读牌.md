# 翻前图表训练与读牌基础

上层：[主线](01_主线与首遍.md)。计算细节：[状态、范围与公式](../03_数据与算法/01_状态范围与公式.md)。

## 1. 翻前：精确记住最终简化图

翻前目标是按用户最终确认图准确回答完整动作向量。例如“加注50%、弃牌50%”，而不是本次随机选择加注或弃牌。不要求额外记住课程没给的尺寸；大盲防守必须先按对手位置和开池尺寸选择来源图。

当前导入数据位于[src/data/ranges.json](../../src/data/ranges.json)：5张开池、4张3bet相关图、6张大盲图。图名“3bet防守”不能单独决定究竟是面对开池做3bet还是开池后面对3bet；须核对原图行动头。当前[src/preflop.js](../../src/preflop.js)将相关图用于“面对前位开池”，新实现不能只按标题擅自改成面对3bet，也不能继承错误的假想对手位置。

每张最终图登记：图ID、来源图片、行动头、适用自己位置、允许的对手／尺寸条件、169格动作向量、颜色图例。来源有歧义的图先不开放具体场景判题。

大盲当前导入的映射如下，作为逐项原图核对清单，不是本设计新增的范围：

| 对手开池位置 | 开池尺寸BB → 大盲简化图 |
|---|---|
| UTG | 2→普通宽；2.25→普通中；2.5／3→普通紧 |
| HJ | 2→普通宽；2.25／2.5→普通中；3→普通紧 |
| CO | 2→普通宽；2.25／2.5→普通中；3→普通紧 |
| BTN | 2／2.25→普通宽；2.5／3→普通中 |
| SB | 2→小盲宽；2.5→小盲中；3／3.5→小盲紧 |

尺寸未列出的场景不做线性插值、不自动挑最近一张图；提示资料未覆盖。数个场景共用一张图时，综合出题不能按映射次数把该图重复加权。

### 1.1 一题怎样呈现

小桌子标自己与对手 → 一句场景 → 两张真实卡牌 → 动作／频率组合按钮 → “我不知道”。题前不展示整张答案图。答错后范围图接管中心区域，相关格子用双轮廓和行列定位，侧边显示正确向量与一句来源。

综合压缩图如果没有定义精确对手，就显示“本位置综合简化图”，不虚构一个具体开池者。它能练图表规定，不能由此生成精确翻后起始范围。

### 1.2 边缘牌怎样定义

边缘分三类，可同时命中：

| 类型 | 可计算定义 | 教学用途 |
|---|---|---|
| 混合格 | 动作向量中至少两个动作权重大于0 | 记准50／50与纯动作 |
| 几何边界 | 同类手牌的相邻格动作向量不同；对子只比较对角相邻对子，同花和非同花不跨类作几何邻居 | 学会范围边界 |
| 情境变化 | 同一手牌在当前选定、确实可比较的其他图中动作不同 | 学会换位置／开池尺寸重新查图 |

最后一种不是当前图的几何边界，设置中单列解释。边缘类别集合取并集，去重后成为边缘池；其他手牌成为其余池。全图模式对169种牌类均衡覆盖，不按实体组合数把非同花牌挤占课堂题量；实体组合权重在范围计算中单独使用。

### 1.3 设置冲突的最终处理

只保留一个“抽题方式”控件：全图均衡／边缘优先／自定义。全图均衡禁用比例条；边缘优先是自定义比例的预设80%；自定义开放0—100%。边缘类型三个勾选只定义边缘集合，不再充当独立抽样模式。

用户改比例会转入自定义。取消全部边缘类型时仅能使用全图均衡，不能偷偷把空池当作弃牌题。某池为空，显示原因并建议调整；跨图混合时先分配图覆盖，再在图内按比例选牌，避免某张图被尺寸映射次数重复加权。

具体抽样和去重见[自动出题](../03_数据与算法/03_自动出题与判分.md)。

## 2. 读牌基础的依赖顺序

```text
认点数花色 → 牌力大类顺序 → 七张选最佳五张 → 两方比大小
                                            ↓
                     顺子／同花听牌 → 后门 → 改善是否真的获胜
                                            ↓
                         六类牌面 → 多属性与范围关系
```

用户可单练任一项；主线发现卡点时推荐最近先修。每项都有明确可核算答案，不混入策略猜测。

### 2.1 牌力顺序练习

默认从弱到强点击横向排列的一行卡片：高牌 → 一对 → 两对 → 三条 → 顺子 → 同花 → 葫芦 → 四条 → 同花顺。皇家同花顺显示为同花顺中的最大情况，不另造一个不相容的十类评估器。

桌面宽度不足时分两行、按阅读方向显示，不缩成无法点击的小字。乱序是题目输入；点过的卡片移入已确认顺序带。点错即判本轮错并显示正确相邻关系，不把九次点击计成九题；可以选由强到弱，说明方向。每个牌型有实体牌示意，可展开但不在排序前自动把答案排好。“我不知道”结束本轮计错。

### 2.2 最佳五张与比大小

先练五张牌认类别，再练七张选五张，再练双方共用公共牌。比较顺序是牌型 → 组成该牌型的关键点数 → 踢脚，不用花色决定输赢；A2345为五高顺，TJQKA为A高顺，QKA23不能绕接。

如果多组实体五张具有相同最大排名，选中任一合法最大五张都算对，不要求和评估器返回的那一组卡牌ID完全一致。全桌公共牌已是最佳牌时，正确答案可能是平分、双方均不用底牌。

### 2.3 顺子识别

把A同时放在低端与高端的两条合法刻度中，重复点数只占一个等级。先点“缺哪几个点数”，再展示具体剩余花色。依次区分双头、卡顺、双卡顺、已有顺子、只是连续三张，最后把辅助刻度收起。

不能把顺子当作“画面中五张排成一排”；系统须展示跳过无用牌仍能组成的最佳五张。练习安排对照：同点数不同花色仍是一张等级；公共牌成顺时自己的顺子未必更大。

### 2.4 听牌、后门与改善

| 问题 | 操作 | 反馈 |
|---|---|---|
| 一张能否成花／成顺 | 点出能完成目标牌型的合法下一张牌 | 展示去重后的具体牌，不只给“9张／8张”口诀 |
| 是否后门 | 先翻一张建立听牌，再翻一张完成 | 明确需要连续两张，不叫直接听牌 |
| 改善就赢了吗 | 看改善后双方最佳五张 | 区分成花但输更大花、成顺平分、对子反被两对压住 |
| 哪些牌让对手也变强 | 双方同步高亮 | 相同新牌对双方作用可能不同 |

“完成目标牌型的牌”与“获胜的出路”使用不同标签。对手底牌未知时，只能说改善事实；净出路和获胜概率要对指定范围计算，不能凭直觉写死。

## 3. 六类牌面的算法与教学边界

沿用工作簿六类查找入口：A高、K/Q高、J/T高、低牌、成对、三同花。它们是导航，不是六条自动下注规则。为避免一块牌面同时属于多个类别，主标签优先级规定为：

1. 成对／三条公共牌；
2. 无重复点数且三张同花；
3. 剩余按最高牌分A、K/Q、J/T、9及以下。

额外始终保留多属性：最高点数、对子点数、花色计数、可能顺子、直接听牌、后门与具体组合。即使主标签是成对，也不能丢掉花色；这个主标签只是本设计为课堂导航规定的优先级，不冒充课程唯一分类法。

转牌和河牌不强行继续使用“翻牌六类”作全部分类，应从上一节点比较新牌：配对、超张、同花完成／新增、顺子完成／新增、组合冲突和相对空白。一张牌可能同时命中多项，必须允许多标签。

连接性不靠任意“点数间隔小于3”决定全部策略。用合法具体底牌枚举当前成顺及下一张可成顺集合；“低连接”“湿润”可作描述词，不能替代这些事实。

## 4. 翻前如何正确交给翻后

翻前专项回答一手牌属于哪个动作；进入翻后则需要双方所有合法组合与该历史的权重。两者不是同一份信息。

完整起始范围只有在图的场景与实际历史匹配时才能从格子展开。4bet、挤压或未给跟注范围不因软件需要就推造；此类局面可以继续练位置、牌力、价格事实，但策略段显示未开放。牌力基础训练和来源清楚的翻前专项不因翻后参考缺失而被整体关闭。
