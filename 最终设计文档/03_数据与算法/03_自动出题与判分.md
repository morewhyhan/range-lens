# 自动出题、判分与会话队列

上层：[课程简化流水线](02_参考策略与课程简化.md)。界面：[交互](../04_界面与软件/01_界面与交互.md)。

## 1. 出题原则

软件用代码生成题面并核对答案；不让语言模型现场编造策略。文本生成只可把已验证结构转换为受控句子，不能添加动作、百分比或因果断言。

三种生成器分开：

| 生成器 | 允许变化 | 答案来源 |
|---|---|---|
| 翻前图表 | 已授权图、169格、合法实体花色、对应场景 | 最终图动作向量 |
| 事实／给定实验 | 合法牌、规定范围、金额、明示响应 | 独立牌力、枚举、代数或完整给定树 |
| 翻后策略 | 已编译节点、范围内合法手牌、经验证对照分支 | 课程规则或匹配参考 |

没有对应策略数据的新牌面，不允许仅凭“同属A高”生成精确动作答案。范围图随意换花色也可能改变阻挡和后门；只有整个状态、双方范围和策略均保持花色同构时才可等价映射。

## 2. 生成一题的步骤

```text
读取当前父层、练习方式和筛选
→ 过滤数据身份、配置、适用条件和发布状态
→ 分配本段尚未覆盖的图／情境／关系
→ 按边缘、内部或其他题型目标选择样本
→ 检查牌张、可达性、金额和后继
→ 从独立答案键取得答案
→ 生成题面投影与受控解析
→ 登记题目身份并展示
```

题库耗尽时显示“本轮已覆盖，开始复习／调整范围”，允许用户重练；不把复习当作新题，也不报错卡死。

## 3. 稳定身份与去重

```text
instanceKey = 配置 + 课包版本 + 节点历史 + 具体牌 + 问题种类 + 答案身份
structureKey = 机制 + 角色/位置/街次/行动状态 + 关键条件 + 因果关系
```

相同实例不连续重出；同结构换表面可作巩固，但不能全部算独立迁移证据。测试用seed重放题序；用户可选择随机或顺序练习。seed影响抽题，不影响某组合应回答什么频率。

策略抽样默认按牌类覆盖或用户教学需求；参考政策评估必须按真实组合到达质量。二者在接口和报告中使用不同字段。

## 4. 边缘比例的精确定义

翻前边缘池按[边缘定义](../02_教学与课程/02_翻前与读牌.md#12-边缘牌怎样定义)建立并去重。自定义比例p按一个20题的计划块分配：`round(20×p)`题来自边缘池，其余来自其余池；块内交错、池内轮转，避免重复消耗少量牌。短于20题的会话不承诺比例恰好相等。用户改设置时重建下一计划块。

默认全图均衡不启用“70%边缘”的隐含偏好；边缘优先预设80%，可改。内部牌包含纯跟、纯加、纯弃等，不只练下注范围内牌。某类型没有有效题时在设置里说明并禁用该比例组合，不能静默借用其他身份题。

翻后边缘来自课程混合、经过校准的动作接近、策略敏感节点；不能用13×13几何相邻直接声称翻后战略边缘。未校准者可显示“参考敏感，观察用”，不进入课程精确边缘题池。

## 5. 题目与答案结构

```ts
type Question = {
  instanceKey: string; structureKey: string;
  packageId: string; nodeId: string; parentStep: StepId;
  answerIdentity: 'fact'|'experiment'|'course'|'reference'|'conditional';
  prompt: string; visual: VisualSpec; options: Option[];
  interaction: 'single'|'multi'|'bestFive'|'order'|'amount'|'inspectChange';
  available: boolean; missingReason?: string;
};
type AnswerKey = {
  questionKey: string; accepted: AcceptedAnswer;
  sourceRefs: SourceRef[]; precision: PrecisionSpec;
  explanation: ExplanationSpec; nextNodeOrStop: string;
  gtoBinding: GtoBinding; chartEvidence: ChartEvidence;
};
```

其中`GtoBinding`遵守[参考策略与课程简化](02_参考策略与课程简化.md#11-gto-图表绑定合同)；`ChartEvidence`至少记录`policy`、`reachBefore`、`reachAfter`、`delta`和`successor`中实际存在的图层及其数据身份。事实题可以只填写牌力／补牌图，实验题可以只填写公式和给定响应图，但策略题缺少匹配参考或明确课程来源时不得生成精确动作答案。

题面渲染组件不接收“正确按钮颜色”或完整解析作为首答提示；答案由判分服务读取。在纯本地软件中这不是防作弊安全隔离，而是避免组件意外泄露。

## 6. 各类题怎样判分

| 类型 | 正确规则 | 常见陷阱 |
|---|---|---|
| 翻前 | 动作向量逐项等于图值，完整回答0／50／100 | 不用随机一次行动替代频率 |
| 课程动作 | 在明确适用条件下等于课程动作与尺寸 | 不把所有相近EV动作自动收为课程答案 |
| 参考频率 | 使用题目预先声明精度或频率档，按组合键核对 | 不把原始47%硬判为50%，除非题目明确是量化课程 |
| 多动作均可 | 答案键明确列出允许集合及原因 | 不因规则冲突就擅自判全部正确 |
| 最佳五张 | 所选五张的排名等于最大排名 | 多组等价最大五张均接受 |
| 多选出路 | 与合法目标集合比较，解释漏选／误选 | 改善牌不等于净赢牌 |
| 顺序 | 完整点击序列符合指定升降序 | 每次点击不重复计整题 |
| 金额 | 等于合法筹码单位下的目标，显示舍入规则 | 不能用文本相等或任意误差 |
| 我不知道 | 本题有效时计错，立即显示解释 | 不是弃牌动作，不执行牌局弃牌 |
| 数据无效 | 不判用户对错，从计分分母排除 | 不能让用户为缺资料承担错误 |

判分同时检查答案身份和证据身份：`gto`题按声明精度核对参考策略，`course`题按课程规则核对，`experiment`题按给定模型和公式核对，`fact`题按确定性评估核对。图表是答后证据，不提前泄露首答；没有对应数据的图层显示“未提供”，不能用插值或邻近牌面填充。

页面选项必须显式含“过牌”或“弃牌”的合法语义，不能用“0%”代替所有不行动。大盲分别区分跟注、加注、弃牌及混合。

## 7. 反馈与计数

有效首答提交后立即锁定，正确与错误各只加一次。改答案、打开解释、重答和点击下一题不能重复加分。统计键包括训练模块、课包／课程、练习方式、用户所选范围与抽样配置；每个练习范围独立计数，切回保留当前会话该范围计数，刷新后全部清除。

右上角只显示“本组 X对 Y错”，颜色加文字；示范不计分。错误反馈依次显示：正确答案 → 一个关键原因 → 相关范围／牌／金额变化 → “下一题”与可选“这一步没懂”。数据来源在次级抽屉，不要求用户阅读原始表格才看懂解释。

用户错因未被题目直接观测时，不自动断言“你不懂范围”；显示“可以从这里核对”。只有明确的中间题答案或用户选择的困惑类别才触发相应补习。

## 8. 会话队列

推荐顺序为：完成当前段 → 错误后的新同构题 → 清晰内部牌 → 边缘／条件对照 → 隔题回访 → 隐藏标题迁移 → 连贯练。用户选择的专项优先，不把每次答错都强制拉回开头。

快练答对默认约650毫秒后下一题，提供“手动下一题”开关用于慢读；该偏好只在本次运行中保存。教学关键解释不自动消失。打开设置／来源／子练习时取消自动跳题，关闭后保持原题与判分状态。

结构与迁移测验的首答、帮助和错误层可在内存中临时记录，用于开发和试读验收。普通用户不看到复杂报告；不因此建立长期档案。若研究需跨天验证，使用经用户同意的人工记录，不给产品添加隐形保存功能。

## 9. 发布前必须检查

每题必须能追到原图／规则／模型／参考；生成器不得抽出非法牌、零到达节点或未开放策略。对照题须验证一次独立干预和全部派生字段；连续题须能逐事件重放。覆盖报告用于作者检查遗漏，不作为面向用户的仪表盘。

## 10. 本轮已验证的实现边界

当前运行代码与设计契约已完成一次端到端静态核验：`npm run build`成功，`npm test`共42项通过。新增的前置测试覆盖四组边界：

- 翻前15张图、2535格、20个BB映射，以及读牌九类牌力、最佳五张和听牌事实。
- 公式与判分：底池赔率、河牌EV、范围后验、范围图定位、题目选项合法性、答案身份和分数隔离。
- 翻后58个来源节点的完整登记：41个`course`、12个`conditional`、5个`closed`，无未登记节点。
- 全部训练模块的可生成性、无持久化和已登记教学路线的物理前缀连续性。

“已验证”指代码在固定样例和随机合法样例中遵守契约，不等于已经完成所有翻后精确策略树。任何没有逐组合策略、对手响应和后继快照的节点都由[翻后覆盖登记](../../src/postflop-registry.js)明确关闭范围图／连续策略，不会由生成器猜答案。
