# 简化策略与GTO参考的差异评估合同

2026年10月21日。本合同规定“把复杂 GTO 简化成小学生或老奶奶也能练的规则”以后，怎样知道简化是否仍然足够可靠。它不预设一个漂亮的百分比，也不把单个 QQQ 案例扩大成全部课程；它要求每个简化节点同时记录参考策略、课程政策、范围变化、收益差异和后继闭合。

## 1. 先区分三种东西

| 名称 | 含义 | 能回答什么 | 不能回答什么 |
|---|---|---|---|
| `ReferencePolicy` | 匹配条件下由作者侧求解器产生的参考策略 | 该节点在声明行动树中的逐手动作、EV、到达和后继 | 课程一定要教成这个按钮；真人一定学会 |
| `CoursePolicy` | 为训练而采用的简化动作、频率或菜单 | 用户在当前课程中应该执行什么 | 原始求解器的完整频率；现实玩家的反应 |
| `SimplificationReport` | 比较两者的输入、动作、范围、EV和后继差异 | 这次简化改变了什么、损失在哪里、是否可发布 | “简化一定更好”或“所有牌面都适用” |

课程政策不能只在显示层把颜色合并或把下注按钮删掉。只要动作菜单、频率、后续或范围筛选改变，就要重新计算受影响的祖先节点，并生成新的政策指纹。

## 2. 评估必须锁定同一局面

每次比较前必须固定：

- 六人现金桌背景和仍在牌局中的活跃玩家；
- 位置、前序、底池、有效筹码和抽水；
- 双方实体起始范围及每手权重；
- 公共牌、自己的底牌视角和已弃牌座位；
- 下注、加注、弃牌、全下和发牌菜单；
- 求解器提交、迭代／停止条件、浮点格式和导出版本；
- 课程政策的量化、菜单删减或路线包装方式。

任何一项改变，比较结果都应标成另一份报告。不能拿NL500的节点评估100BB课程，也不能拿零抽水研究树给带抽水训练题盖章。

## 3. 五层差异指标

### 3.1 输入与物理一致性

先独立确认牌张、最佳五张、平分、合法金额、筹码守恒、公共牌和双方实体组合没有冲突。`equity-calculator`和独立最佳五张代码只服务这一层，不提供下注策略。

必须报告：

```text
inputFingerprint
legalComboCount / legalComboMass
duplicateOrImpossibleCardCount
ledgerConservationError
equityCrossCheckError
```

这一层不通过，不能进入策略差异比较；不能把策略输出的牌力列当作物理事实的唯一证明。

### 3.2 参考策略一致性

先检查参考文件能否重载，逐手动作频率和EV的索引是否对应，零支持手牌是否保留为零，后继公共牌和行动历史是否闭合。参考的整体可利用度指标、迭代次数或能打开文件，不单独证明每个逐手动作正确。

必须报告：

```text
referenceCommit / solverConfigFingerprint
reloadPreserved
supportedDecisionRows / unsupportedDecisionRows
successorCoverage
terminalValueRecheck
bestResponseEvidenceStatus
```

若只有局部节点或后继缺失，报告只能作为参考候选，不得开放整手精确判分。

### 3.3 课程策略与参考策略的动作差异

对同一节点的每个实体组合 `h` 和动作 `a`，保留：

```text
p_ref(a | h, node)
p_course(a | h, node)
delta(h,a) = p_course - p_ref
```

先做逐手绝对差，再按参考到达质量加权汇总。可以报告动作支持是否改变、混合是否量化为0／50／100、边缘牌是否被移到邻近动作，但不把“总体下注率接近”当作逐手策略接近。

建议记录以下指标，但在目标配置和试读校准前不擅自规定通过阈值：

- 加权动作L1差异；
- 逐手最大差异与超过预定观察线的组合清单；
- 动作支持改变数量；
- 课程边缘格与参考边缘格的重合／错位；
- 同一手牌在相邻位置或尺度下是否被错误复用。

阈值未校准时使用 `observed`、`needs_review`、`not_comparable`，不用“95%就是正确”。

### 3.4 课程政策的收益与可利用度影响

在相同输入、相同参考回应和明确政策变换下，重新计算根及受影响祖先的价值。至少分开：

```text
EV_ref(root, policy)
EV_course(root, policy)
loss_vs_reference = EV_ref - EV_course
rootBestActionChanged
successorValueChanged
```

若要说“简化不改变当前动作”，必须在所有仍允许的候选中比较；若删除后续动作使根最佳动作改变，原课包只能降级或重新设计。固定对手政策下的差异不是完整均衡可利用度，锁定一个行动者的结果也不是双方最佳回应证明。

目标参考允许的误差、动作并列和课程可接受损失要由一组匹配节点校准后确定。单个案例出现小正差，不能说简化优于GTO；负差也不能只看根节点，要列出哪一类牌、哪一条后继和哪种对手回应造成。

### 3.5 行动后范围和教学后继一致性

对每个允许动作生成：

```text
R_before
R_after_ref(a)
R_after_course(a)
rangeMassBefore / rangeMassAfter
normalizationDenominator
successors
```

`R_after`必须逐手按 `w_before × p(action | hand)` 生成，再按分支质量归一；双方未知底牌要在合法联合配对上联合筛选。物理移除、行动筛选和重新归一化要分别标记。

如果课程图看起来与参考图相似但某些新牌、下注回应或再加分支没有后继，不能把它发布成连续策略课；最多发布到当前示范帧并显示停止原因。

## 4. 简化的四类变换怎样判

| 变换 | 例子 | 最少要评估什么 | 不能直接假设 |
|---|---|---|---|
| 视觉展开 | 把高级参数藏到子层 | 输入和答案身份不变，父帧可恢复 | UI变了所以策略不变无需核对 |
| 频率量化 | 混合压成0／50／100 | 逐手差异、根EV、边缘组合和动作支持 | 总体频率接近就无损 |
| 菜单限制 | 删除一个尺寸或再加 | 全路径EV、祖先动作、后续闭合和可利用度状态 | 只删用户看不到的按钮 |
| 课程路线 | 先示范后独立回答 | 首答／重答隔离、快照恢复、迁移身份 | 看完示范就会独立执行 |

任何变换若同时改变多个字段，报告必须拆开列出，不能只给一个总差异数。

## 5. 题目开放闸门

| 开放身份 | 必须通过 | 用户可做什么 |
|---|---|---|
| `fact` | 物理和规则独立复核 | 牌力、价格、合法性、组合冲突 |
| `demonstration` | 输入、来源、账本和父帧明确 | 跟看一条规定路线 |
| `course_policy` | 简化动作有来源、政策指纹和受影响重算 | 按课程规则练当前动作 |
| `reference_policy` | 匹配参考、后继闭合、动作／EV／范围差异有报告 | 做精确策略题 |
| `not_open` | 任何硬门槛缺失 | 显示缺什么，不让用户猜 |

`course_policy`不是`reference_policy`的低清晰度显示；两者必须在题目身份、解析和报告中分开。缺失对手回应、抽水、动作菜单或后继时，自动降级，不把学习者答错。

## 6. 评估报告的最小结构

每个报告保存：

```text
reportId
referenceFingerprint / coursePolicyFingerprint
inputConfig
referenceStatus
physicalChecks
actionDeltas
evAndRootActionDeltas
rangeDeltas
successorClosure
uncertainties
releaseStatus
nextEvidenceNeeded
```

报告必须能回答三句话：

1. 这是什么条件下的参考和简化？
2. 简化具体改变了哪些手牌、动作、范围或收益？
3. 在什么范围内可以教学，什么时候必须停止或补资料？

不能只输出“通过／不通过”一个颜色。

## 7. 当前真实状态

已有的SB对BB QQQ第二轮结果可以作为一个参考层质量候选，且已有权益、重载、终局和前向路线复核；它仍不是原课程A72，也不是所有牌面的简化损失评估。当前没有一组覆盖所有父层和位置的匹配参考，也没有经过成人初学者试读后校准的简化误差阈值。因此本合同可以约束下一批课包，不会把现有局部结果升级成完整NL50课程。
