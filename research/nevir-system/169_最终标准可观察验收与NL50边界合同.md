## 这份合同把最终标准变成什么

“小学生或者老奶奶跟着练完能够进NL50”包含两个不同问题：

1. 页面和教学是否低门槛、顺序清楚、没有漏步骤；
2. 训练后是否真的具备目标级别的策略能力。

第一件事可以由低基础试读和结构回放证明；第二件事必须有匹配参考、陌生连续题、独立复核和真实决策审计。年龄称呼本身不是证据，也不能用作者自己走通、题目很多或短期盈利代替目标级别验证。

## 一、一次跟练到底要留下什么

一次完整跟练结束时，学习者至少要能用自己的话说出：

```text
先定位局面和行动权
→ 读公共牌与自己的牌
→ 看哪些范围组合还可能存在
→ 比较牌力、价格和动作目的
→ 执行一个合法动作
→ 看动作或新牌怎样改变状态
→ 走到后继或明确停止
```

页面上每一步都必须真实出现。若资料不足，系统显示“缺少什么、为什么不能继续、回到哪里”，这也算该层的完成方式；用默认过牌或猜测答案填空，算结构错误。

## 二、低基础可理解性怎样验收

低基础标准不是“点击速度快”，而是以下证据同时成立：

- 首遍没有主持者替用户补知识；
- 每屏只有一个问题和一个主要动作；
- 一次只引入一个新的未掌握概念；
- 牌、范围、金额、行动权和返回点都在画面上可见；
- 隐藏步骤标题后，用户能复述七层顺序；
- 三个未见父帧能定位当前层和下一层；
- 两个故意错误能回到最近缺失层；
- 一个只改变单字段的陌生题能指出应该重新检查哪一层。

这套标准允许用户慢，也不要求倒计时。页面越漂亮、答案越快，如果用户不知道当前为什么来到这一层，仍然不能算学会。

## 三、“一步不落”怎样和“不平铺”同时成立

“一步不落”检查的是父层交接字段；“不平铺”检查的是用户一次只看到一个父帧。两者通过以下规则同时满足：

1. 学习者外层只给一条`L0→L4`路线，随后在同一父帧内进入`p1→p7`；旧`L5→L8`只作为作者宏观审计别名；
2. 翻后当前父帧只沿`p1→p7`推进；
3. 35个单元只在对应父帧中按需打开，一次一个；
4. 子单元关闭后恢复原父帧、牌面、历史和首答；
5. 每层都必须留下一个交接字段，否则停在该层；
6. 没有后继的节点显示停止卡，而不是把下一街伪造出来。

因此，后台可以完整，前台仍然保持一条可以复述的主线。

## 四、怎样证明慢速执行不是记住案例

首遍之后，训练器必须按这个顺序增加复杂度：

```text
同一父帧同一机制
→ 相邻牌面只改一个字段
→ 换位置或前序但保持问题结构
→ 进入新牌或回应后继
→ 未曝光连续三街
```

每道迁移题都记录首答、帮助等级、改变的唯一字段、错误层和回退点。原题重做、看完解析再答对、同花色同构题，都不能算独立迁移。

## 五、什么时候才可以谈NL50

必须依次具备：

1. 六人现金桌、100BB、抽水、位置、前序和动作菜单冻结；
2. 至少一条完整翻前三街有匹配参考和输入指纹；
3. 课程简化、原始参考和动作后范围分开保存；
4. 未曝光连续题通过，范围分母、金额、行动权和后继没有断裂；
5. 独立复核者能从输入重建答案；
6. 真实牌局中只统计已覆盖配置的决策，并记录未知节点、帮助使用和错误层；
7. 有外部目标基准和足够长期的决策级样本。

在这些条件之前，最准确的表述是“课程结构和局部能力正在验证”，而不是“完成后保证进入NL50”。目标没有降低，只是把证明顺序固定下来。
