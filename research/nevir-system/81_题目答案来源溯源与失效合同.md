# 题目答案来源溯源与失效合同

## 1. 这份合同解决什么问题

训练器不能只保存“正确答案”，还必须保存答案为什么成立、在哪个条件下成立，以及当资料变化时是否仍然成立。否则，题目看起来很精确，实际上无法复核，也无法知道旧答案是否已经失效。

每一道题都要能从公开题面回放到：父级状态、事实来源、公式或原始参考输出、课程规则转换、教师答案、解析和下一题。任何一段缺失，都要降级显示，不能伪装成确定结论。

## 2. 来源分层

| 来源类型 | 作用 | 典型内容 | 可以支持的结论 |
|---|---|---|---|
| `source_fact` | 直接资料事实 | 用户表格、用户笔记、已确认规则、牌面事实 | 资料明确写出的事实 |
| `derived_fact` | 可复算事实 | 组合数、权益、SPR、底池赔率、范围交集 | 由公式从输入推出的事实 |
| `reference_output` | GTO参考输出 | 引擎版本、配置、原始策略、收敛信息 | 参考策略或频率，不自动等于课程答案 |
| `course_policy` | 本训练器采用的简化规则 | 节点开放、动作合并、简化颜色和判分 | 本软件怎样把参考变成可练的决策 |
| `teaching_explanation` | 教学解释 | 一句话因果、识别信号、下一步提示 | 帮学习者理解和迁移，不能替代事实来源 |

## 3. 每条来源必须有的身份字段

最少记录以下字段：

1. `sourceId`：稳定的来源编号。
2. `sourceKind`：上述五种来源类型之一。
3. `location`：文件、工作表、页码、段落、单元格或原始输出路径。
4. `versionOrRevision`：版本号、提交号、文件修改时间或人工修订号。
5. `contentHash`：内容哈希，防止同名文件被静默替换。
6. `condition`：适用条件，包括街道、位置、有效筹码、底池、行动历史、牌面和简化节点。
7. `inputFingerprint`：计算输入的稳定指纹。
8. `retrievedAt`：读取或计算时间。
9. `licenseIdentity`：外部资料的许可或引用身份。
10. `reviewStatus`：未审、已核对、已发布、已失效等状态。

派生事实还必须保存 `formulaId`、`independentChecker`、`roundingRule`、`unit` 和 `intermediateValues`。参考输出还必须保存 `engineRevision`、`configurationHash`、`actionTreeHash`、`convergenceMetric`、`stoppingReason`、`rawOutputHash` 和 `supportStatus`。

## 4. 一道题的完整溯源链

题目应按以下顺序回放：

```text
公开题面
  → 父级状态与输入指纹
  → 来源事实/派生事实/参考输出/课程规则
  → 公式或原始输出
  → 课程简化与动作合并
  → 教师答案
  → 解析、范围变化图和下一题
```

“课程规则”和“GTO参考”必须分开。参考输出说明原始策略看到了什么，课程规则说明本软件为何把它压缩成当前练习；两者的指纹不能相同，否则无法发现未经说明的改写。

## 5. 缺失时怎样降级

- 缺少事实来源：标为“资料未核实”，不能给确定判分。
- 缺少课程规则来源：只能做演示或识别练习，不开放正式正确率。
- 缺少原始参考输出：可以练课程中明确写出的动作，但不能显示“精确GTO频率”。
- 缺少下一状态或后继：停止连续课程，只保留当前单题。
- 来源哈希变化：把受影响的父题、答案、解析和后继全部标为待重编译。

公开题面只显示短身份（课程规则、事实计算、参考策略、资料待补）；详细来源在解析中展开，不能把答案字段、私有原始输出或隐藏判分条件塞进题面。

## 6. 发布前检查

每次发布题包前必须检查：

1. 公开题面不含私有答案。
2. 每个答案都有来源和适用条件。
3. 每个公式有单位和独立校验器。
4. 参考输出有原始输出哈希、停止原因和后继状态。
5. 课程规则指纹与参考输出指纹不同且可解释。
6. 过期来源会使祖先题和迁移题失效。
7. 证据不足时不会给精确分数。
8. 页面显示的来源身份与实际答案身份一致。
