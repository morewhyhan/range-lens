## 为什么需要单独的原理总账

七个父步骤只能说明用户按什么顺序走。它不能自动证明每个必须内化的关系都被看见过。低基础学习者最容易出现的情况是：按钮顺序走完了，却把“新牌造成的物理移除”记成“对手弃牌”，把“行动后范围变窄”记成“这张牌本来就不在范围里”，或者只记住“这类牌下注”，没有学会价格、位置和后继如何共同改变答案。

因此首遍必须同时满足两条链：

```text
路线链：L1 → L2 → L3 → L4 → p1 → p2 → p3 → p4 → p5 → p6 → p7
原理链：定位 → 价格 → 牌面 → 手牌 → 范围 → 过滤 → 比较 → 执行 → 更新 → 后继 → 收束
```

原理链不是第二个平铺菜单。每个原理只在自己的父步骤第一次出现，使用一个直观视觉和一个问题；需要深入时从当前父帧打开子层，完成后回到原处。用户不需要背十二个名称，但必须能在陌生局面中重新做出这十二个关系。

为了防止“原理讲过但没有迁移入口”，机器合同还为12个原理各自登记一个单变量迁移蓝图。蓝图只规定改变哪个字段、回到哪个父步骤和要重新回答的白话问题；它不在缺少参考时虚构动作答案。

## 十二个不可省略的原理原子

| 原理 | 首次出现 | 用户看到的直观对象 | 用户交给下一步的东西 | 最容易发生的偷换 |
|---|---|---|---|---|
| P01 定位与行动者 | L1（p1复核） | 六人桌、位置高亮、行动箭头 | 谁在决定、轮到谁、行动历史 | 只看自己的座位，忘记当前行动者 |
| P02 价格与账本起点 | L1（p1复核） | 底池、跟注额、双方后手 | 当前价格、底池、后手 | 只看牌力，不看价格 |
| P03 牌面结构 | p2 | 公共牌按花色和连接度分组 | 牌面类别、公共牌新增效果 | 看到一张高牌就直接跳到下注 |
| P04 手牌、牌力与改善牌 | p2 | 最佳五张、牌型顺序、补牌集合 | 当前牌力、听牌、改善牌 | 把听牌机会当成已经成牌 |
| P05 行动前范围 | p3 | 固定分母的13×13范围图 | 哪个范围进入比较 | 把一手具体牌当成整个范围 |
| P06 物理过滤与行动过滤 | p3 | 新公共牌划掉实体冲突，再叠加动作筛选 | 物理过滤、行动过滤状态、分母 | 把被公共牌冲突移除当成对手弃牌 |
| P07 动作目的与比较维度 | p4 | 价值、保护、实现权益、拒绝权益等目的卡 | 当前动作是在比较什么 | 以“牌型名称”直接推出动作 |
| P08 价格、尺寸与阈值 | p4 | 下注尺寸、底池赔率、所需权益 | 合法动作与价格条件 | 只背固定尺寸，不会重新算价格 |
| P09 执行动作与账本更新 | p5 | 动作按钮、筹码移动、底池/后手变化 | 选择的动作、金额、下一行动者 | 点中按钮但金额和状态不守恒 |
| P10 行动后范围变化 | p6 | 同坐标前后范围图和权重变化；当前无匹配参考时显示停止卡 I10 | `rangeAfter`及其来源身份，或明确停止原因 | 把课程范围图冒充原始求解范围 |
| P11 新牌效果与后继 | p6 | 新牌前后对照、下一节点箭头 | 新牌影响、后继或明确停止 | 没有真实后继却自动跳到河牌 |
| P12 结算、错误层与下一手 | p7 | 结果账本、错误定位、下一手入口 | 结果与决策分开、下次重查哪层 | 用赢输结果证明当时决策正确 |

## 每个原理必须怎样教

每个原理的首遍卡片固定四段：

1. **白话句**：只说用户当前能观察到的关系，例如“公共牌上的牌不能同时出现在任何人的底牌里”。
2. **中心视觉**：只突出一个变化，例如一张 Q♥ 出现后，所有含 Q♥ 的格子变暗；不同时显示策略颜色。
3. **唯一问题**：只问这个原理，例如“哪些组合必须移除？”；“不知道”按错误处理，但解析回到当前父帧。
4. **交接句**：明确告诉用户结果交给哪一步，例如“现在才把剩下的范围交给动作比较；被物理移除不代表对手采取了动作”。

技术术语只在白话句答完后出现，并与同一对象绑定。首遍不同时引入阻挡牌、组合数、动作频率和后继策略；这些是 P06、P07、P10、P11 的子层，不是新的首页入口。

## 原理链怎样和嵌套路线合并

- 外层 L1 首次建立 P01—P02；进入翻后 p1 时只复核并接收这两个状态，用户不在这里回答牌力或下注。
- p2 只建立 P03—P04；牌面视觉和最佳五张必须先于范围图。
- p3 只建立 P05—P06；先显示实体合法性，再显示有来源的行动筛选。
- p4 只建立 P07—P08；先问动作目的，再问价格和尺寸。
- p5 只建立 P09；把按钮变成可核对的金额和状态，而不是结束题目。
- p6 只建立 P10—P11；新牌先做物理变化，再进入行动后范围和真实后继。
- p7 只建立 P12；结算、错误回退和下一手迁移必须分开。

同一父步骤内可以打开一个子单元，但子单元只能解释当前原理。例如 P06 可以打开“阻挡牌/实体冲突”练习，完成后必须回到 p3；不能从 P06 横向跳到下注尺寸或河牌路线。

## 首遍完成的含义

首遍完成不是十二个按钮全答对，而是取得四类独立证据。P01—P02 在翻前外层首次建立，p1 再检查它们是否随历史正确交接：

- 用户能按 p1—p7 说出下一步去哪里；
- 用户能在每个原理的中心视觉上指出发生了什么变化；
- 用户能把原理产物交给下一步，不丢失行动者、范围分母、价格或账本；
- 用户在只改变一个字段的陌生题上，能先指出受影响的原理，再重新执行。

事实资料或匹配策略缺失时，原理仍可教到事实边界，但必须显示停止原因。六个缺口插入点已经编译为父帧内的子卡，见 [first-hand-gap-frame-cards.json](first-hand-gap-frame-cards.json)；它们关闭后回到原父帧，不生成新的顶层步骤。P10 的 I10 卡会明确要求“没有匹配参考，停止”，因此“动作后范围”不再是首遍遗漏的原理，但仍不是可判策略。不能用相邻案例填补 P10 的 `rangeAfter`，也不能用实体过滤代替 P07 的行动政策。只有完成匹配参考、课程政策、后继和学习者迁移，才允许把相应原理升级为可判策略练习。

## 当前证据边界

这份合同补的是“首遍不漏原理”的结构完整性，不是学习者已经掌握的证据。机器账本已列出 P01—P12 的首次位置、视觉、交接和禁止偷换；现在每个原理都有一个主帧、事实子卡或明确停止卡，但 P05、P07、P08、P10、P11 仍没有完整匹配策略或后继。当前仍没有真实页面试读、低基础首答、未见迁移、完整 A72 匹配参考或 NL50 结果，因此状态保持为 `twelve_principles_have_frame_or_stop_without_learner_trial`。
