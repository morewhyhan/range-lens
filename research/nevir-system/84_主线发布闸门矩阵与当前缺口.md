## 1. 为什么还需要这张表

L0—L8已经有作者侧课程编排，但“写出一个停点”和“这个停点可以让学习者独立练”是两件事。本表只做作者侧发布检查：每个宏观停点要有哪类输入、哪类证据、哪类后继，缺哪一项时必须停在哪个身份；学习者实际只沿规范L0—L4→p1—p7→回放推进。它防止继续用增加局部案例掩盖主线的断点。

## 3. 闸门之间的依赖

```text
L0桌面
  → L1场景
  → L2格子
  → L3动作
  → L4范围交接
  → L5翻后定位
  → L6当前比较
  → L7连续更新
  → L8结算迁移
```

不能跨过中间闸门直接发布后面的精确策略题：

- L3没有来源身份，L4只能教物理范围，不能声称起始策略已正确；
- L4没有双方联合范围，L6只能教牌力、牌面和公式事实；
- L6没有动作后范围和后继，L7只能做单步示范，不能做连续路线；
- L7没有未见后继，L8只能做账本或路线回看，不能证明整手会执行；
- L8没有真实试读，不能证明低基础学习者形成了结构，更不能谈NL50准备度。

## 4. 每个闸门的最小发布包

每个停点的课包至少包含：

```text
routeNode
parentFrame
publicPrompt
visibleInputs
sourceIdentity
coursePolicyIdentity
referenceIdentity（如果开放精确策略）
teacherAnswer
causalExplanation
rangeBefore / rangeAfter（需要时）
successorState 或 stopReason
firstAnswer / retryAnswer 的会话字段
```

“原始资料”不是必需显示给学习者的内容，但来源身份必须在作者包中存在。缺少 `referenceIdentity` 时不能显示精确GTO频率；缺少 `successorState` 时必须停止连续课程；缺少 `parentFrame` 时不能打开子层。

## 5. 当前优先顺序

接下来不再扩展新的首页专题，按以下顺序补：

1. 先冻结一条与课程条件匹配的A72首课输入和来源链；
2. 再取得翻牌、转牌、河牌的匹配参考与行动后范围；
3. 将参考编译成L5—L7的一条连续静态课包；
4. 用未见题做独立范围图、账本和后继核验；
5. 最后才做低基础首遍试读和帮助撤除。

QQQ等工程候选可以继续用于检查求解器和存储链，但不能替代A72课程匹配首课。若A72某一闸门资料或资源不足，就保持该闸门关闭，不用另一个牌面或局部模型填充。

## 6. 当前状态

主线结构已具备纸面路线和机器检查，但L3、L4、L6、L7和L8仍有实质发布缺口；完整连续策略、真实低基础试读、迁移和NL50证据均未取得。本表是后续补证的优先序，不是完成率。
