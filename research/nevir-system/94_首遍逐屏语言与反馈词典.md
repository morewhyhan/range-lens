# 首遍逐屏语言与反馈词典

## 1. 目的

低基础学习者首先需要知道“现在要看什么、要点哪里、答错后回哪里”。因此首遍的语言不能把技术名词当作导航，也不能用一句“这是范围优势”代替视觉证据。本词典把p1—p7的屏幕标题、普通话问题、成功反馈、错误反馈、未知反馈和子层入口固定下来，供页面和主持脚本共用。

普通话是入口，精确术语在答后或抽屉里出现。任何文案变化都不能改变题目的证据身份和判分规则。

## 2. 七个屏幕的固定用语

### p1：先看现在发生什么

- 屏幕问：**“现在轮到谁？前面发生了什么？如果继续，要补多少钱？”**
- 成功反馈：**“对。先把人、动作和钱摆清楚，下一步才有意义。”**
- 错误反馈：**“先别猜按钮。你漏看了行动顺序／前面的动作／还要补的钱。”**
- 不知道：**“按不知道处理。打开行动线和账本，再在同一局面回答。”**
- 子层按钮：**“看行动顺序”**、**“看钱怎样变化”**。

### p2：再看我的牌

- 屏幕问：**“我用这几张牌组成的最好五张是什么？还可能改善成什么？”**
- 成功反馈：**“对。先确认牌力和改善牌，暂时不要从牌型直接猜下注。”**
- 错误反馈：**“你把牌面关系／最佳五张／改善牌看错了。先回到实体牌。”**
- 不知道：**“按不知道处理。逐张点牌，系统只展示最佳五张和合法改善牌。”**
- 子层按钮：**“拼最佳五张”**、**“练牌力顺序”**。

### p3：看双方可能拿什么

- 屏幕问：**“这次已知的牌和前面的动作，让哪些组合不可能、变少或留下？”**
- 成功反馈：**“对。你指出的是实际组合的变化；这还不是下注答案。”**
- 错误反馈：**“你把‘牌不可能’和‘动作后变少’混在一起了。看两张同坐标图。”**
- 不知道：**“按不知道处理。先点一组真实组合，再看它为什么被划掉或变淡。”**
- 子层按钮：**“看前后范围”**、**“看一组组合”**。

### p4：比较现在能做的事

- 屏幕问：**“在这些合法选择和当前价格下，哪一个动作符合本题的课程规则？”**
- 成功反馈：**“对。你是在比较动作的目的、价格和后续，不是只看牌名。”**
- 错误反馈：**“先回到价格／范围／后续中的缺失一层，再重新比较。”**
- 不知道：**“按不知道处理。只保留当前两个合法选择，打开它们各自的后续。”**
- 子层按钮：**“比较过牌和下注”**、**“比较跟、弃、加”**。

### p5：把动作做完整

- 屏幕问：**“点哪个按钮？投入多少？行动接下来给谁？”**
- 成功反馈：**“对。动作、金额和行动权都对上了，账本没有跳步。”**
- 错误反馈：**“动作想对了，但金额／合法性／行动顺序没有对上。”**
- 不知道：**“按不知道处理。先只看合法按钮和待补金额。”**
- 子层按钮：**“看金额怎样算”**。

### p6：动作或新牌后重新看

- 屏幕问：**“这次回应或新牌，具体改变了什么？”**
- 成功反馈：**“对。你保留了前面的信息，只更新发生变化的那一项。”**
- 错误反馈：**“不要把整手牌重置。回到动作前的范围、钱和行动者，只改这一项。”**
- 不知道：**“按不知道处理。先打开行动前后对照，或只看新牌造成的变化。”**
- 子层按钮：**“看回应怎样筛选范围”**、**“看新牌怎样改变组合”**。

### p7：结算并找错层

- 屏幕问：**“最后发生了什么？如果错了，错在状态、牌面、范围、价格、动作、账本还是更新？”**
- 成功反馈：**“对。结果只是结果；我们先回看当时能看到的依据。”**
- 错误反馈：**“不要用这次输赢倒推上一步。先定位哪一层缺了。”**
- 不知道：**“按不知道处理。并排看决策前信息、结果和错误层。”**
- 子层按钮：**“回看这层”**、**“做一题只改一个因素的题”**。

## 3. 文案与视觉的绑定

### 3.1 八个脑内节点的固定句式

七个父步骤仍是用户主线；其中 p2 在同一父帧里先看公共牌、再看自己的最佳五张，形成两个连续子节点，不把它们拆成首页入口。每个节点统一使用“看到什么 → 用户说/点什么 → 交给下一步什么”的句式：

| 节点 | 看到什么 | 用户说/点什么 | 交给下一步 |
|---|---|---|---|
| A1 定位 | 桌面、行动线、底池和待补 | 说出谁行动、前面发生什么、还要补多少 | 情境帧 |
| A2 牌面 | 公共牌和街次 | 说出牌面带来的成牌、顺子或同花关系 | 牌面关系 |
| A3 手牌 | 自己的牌和最佳五张轮廓 | 拼最好五张并点改善牌 | 牌力和改善机会 |
| A4 范围 | 同坐标行动前后图 | 区分不可能、变少但仍可能、课程未开放 | 范围后快照与分母 |
| A5 比较 | 合法按钮、价格和后续摘要 | 只比较当前合法动作 | 课程动作及身份 |
| A6 执行 | 按钮、金额、行动权 | 做出动作并核对账本 | 新底池、后手和下一行动者 |
| A7 更新 | 回应或新牌的一处变化 | 只更新发生变化的字段 | 变化字段和后继 |
| A8 收束 | 结果、依据和返回点 | 定位错误层并选一处迁移 | 下一次练习入口 |

每个节点的技术词只在答后出现；页面不能只给一句解释而没有对应的牌、图、金额或返回点。机器可读副本在 `first-pass-copy-deck.json` 的 `architectureMicrocopy`。

| 文案说法 | 页面必须同时出现 | 页面不能出现 |
|---|---|---|
| “不可能” | 具体组合打叉和冲突牌 | 只有降低透明度的颜色 |
| “变少但仍可能” | 同坐标前后图、非零标记、组合数 | 把格子直接涂成空白 |
| “还要补多少钱” | 待补、跟后池、后手 | 只显示百分比 |
| “动作后留下” | 动作前范围、动作筛选后范围、筛选身份 | 没有来源的确定频率 |
| “新牌改变” | 只高亮新牌引起的字段 | 重置整手牌或跳到新专题 |
| “错在某层” | 错误层名称和返回点 | 只显示红色而不告诉回哪里 |

## 4. 首遍不得出现的表达

首次主线不能把以下词作为唯一导航或唯一答案：`EV`、`frequency`、`range advantage`、`nut advantage`、`blocker`、`backdoor`、`GTO`。这些词可以在答后作为技术别名出现，但必须同时有普通话和可点击的视觉对象。

同样禁止用“牌面湿所以下注”“有阻挡牌所以诈唬”“我有顶对所以下注”等单句口诀替代当前范围、价格和后续。缺少参考时，文案必须写明“本题只练事实/课程示范”。

## 5. 语言合同的验收

逐屏文案只有在以下条件同时满足时才可进入首遍：

1. 不看技术词，学习者知道当前要点什么；
2. 答错反馈能指出一层和返回点；
3. 子层关闭后原问题、牌面、金额和首次答案恢复；
4. 解析只解释当前层，不提前给出后面所有动作；
5. 文案、图形和判分身份一致；
6. 只改一个字段的未见题能复用同一用语。

当前词典是纸面文案合同，尚无真实低基础试读结果。机器可读版本见 [first-pass-copy-deck.json](first-pass-copy-deck.json)。
