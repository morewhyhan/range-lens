# 单一路径总装与首次全图导航合同

2026年10月21日。本合同把现有翻前专项、翻前到翻后入口、翻后七步、错误回退和迁移验收接成一条用户实际能跟随的路线。它解决的是“看完一遍以后脑子里有没有一张路线图”，不是把已有局部材料升级成完整 GTO 策略，也不是宣称已经达到 NL50。

## 1. 用户只看到一条主线

第一次打开训练器，用户不从一张课程目录中挑选几十个主题。画面只给当前所在的一步、一个问题、一个主要动作和一个返回位置。所有深入内容都是当前父步骤里面的子层，关闭后回到父步骤；专项练习在完成后也回到同一条主线。

```text
看懂桌面
  ↓
翻前：定位场景 → 读169格 → 精确动作 → 边界与迁移
  ↓
翻前动作生成起始范围快照
  ↓
翻后：定位 → 读牌 → 看范围 → 比较 → 执行 → 更新 → 结算
  ↓
恢复整条路线 → 一处相邻迁移 → 进入下一次练习
```

这条主线不是把所有节点都自动打开。用户在某一步看不懂时，打开该步的一个子层；子层完成后精确返回。这样“全面”来自路线经过每个必要层，“简单”来自一次只处理一个层。

## 3. 每层怎样套入下一层

纵向是固定路线，横向是当前步骤的一个深入层：

```text
外层停点 L
  └─ 当前父帧 P：牌、钱、历史、行动者、范围视角
      └─ 一个子层 C：牌力 / 范围 / 价格 / 金额 / 后继之一
          ├─ 一个对照
          ├─ 一个局部回答
          └─ 关闭，恢复 P，再回到 L
```

子层必须保存父帧的公共牌、私牌、行动历史、底池、后手、行动权、来源版本、课程政策和范围视角。关闭时逐项恢复；不能只把筹码画回去，不能把子层里后来知道的对手底牌带回主线，也不能把另一条互斥分支接成真实历史。

同一时刻最多打开一个教学子层。需要比较两个选项时，两个选项是当前父帧内的并列候选，不是同时打开两个新课程。任何回看分支都带“从哪一步打开”和“回到哪一步”的标记。

## 4. 用户每一屏只承担四件事

1. **看见当前状态**：小桌、牌、底池、后手、行动者和必要范围。
2. **回答一个问题**：只涉及当前层，例如“轮到谁”“哪一格”“哪个动作”。
3. **做一个动作**：点格、点按钮或输入金额；不同时要求解释全部原因。
4. **知道下一步**：显示“继续到哪一步”或“返回哪一层”，不把用户送回目录。

主画面固定一个视觉语法：中央保留当前桌面或范围图；顶部只显示当前路线位置；旁边放一句普通话解析；深入内容用同一位置的抽屉打开。仪表盘、长期成绩、几十个平铺卡片和没有父子关系的功能入口不属于首遍路线。

## 5. 三种帮助怎样逐步撤掉

每个父层都使用相同的帮助梯度，但不改变路线：

| 帮助层 | 画面提供什么 | 用户要完成什么 | 计入什么证据 |
|---|---|---|---|
| 示范 | 逐步指出事实、按钮和金额 | 跟着看完并能说出下一层 | 了解路线，不计独立正确 |
| 引导 | 保留必要输入，隐藏一个关键结论 | 在当前父帧完成一次局部回答 | 有帮助完成，首答单独保留 |
| 独立 | 收起答案颜色和步骤名，保留真实必要输入 | 自己定位层、比较并执行 | 独立单步或迁移证据 |

撤掉帮助不能删除完成判断所需的范围、历史、价格或行动顺序。若缺少匹配策略，不能用“独立”伪装成难题；只能把这一步标成事实、示范或资料待补。

## 6. 错了怎样沿原路线回退

错误不触发另一个菜单，而是回退到最近的缺失层：

```text
按钮对但范围错       → 当前父帧的范围子层
金额或合法性错       → 执行层的账本子层
新牌后不知道看什么   → 更新层的牌面／行动筛选子层
不知道现在轮到谁     → 定位层的桌面／历史子层
不知道该打开哪层     → 首遍结构地图 L1–L8
```

反馈顺序固定为：指出错层 → 高亮一个事实 → 给一个最小对照 → 在同一父帧再答 → 回到原来的下一步。第二次答对不能覆盖首次错误，也不能把“我不知道”变成独立通过；但它可以作为有帮助完成继续路线。

## 7. 首遍结束的三个结构检查

L8结束后不立即展示“完成课程”。只做三个短检查：

- **顺序恢复**：把“定位、读牌、范围、比较、执行、更新、结算”打乱，恢复正确顺序；
- **下一层定位**：给一个未见的短局面，只指出现在应该打开哪一层；
- **一处迁移**：换一个位置、公共牌或明确前序，指出哪个字段改变，再进入一个局部动作题。

这三项检查的是路线是否进入脑中，不是完整策略掌握。失败时只回到对应层；通过后才能进入更多未见练习。通过一次首遍不会把现有局部模型变成 NL50 证据。

## 8. 训练器的最小状态合同

每个可恢复父帧至少有以下字段：

```text
routeNode
parentNode / returnTo
game / seats / effectiveStack
publicCards / heroCards / visibleInformation
history / actor / actionToFace / legalActions
pot / stacks / streetPaid
chartOrReferenceVersion / coursePolicy
rangeOwner / comboWeights / normalizationView
assistanceLevel / firstAnswer / retryAnswer
```

答案身份还必须包含题型、场景、格子或牌面、动作权重和版本。没有这些字段，系统只能给事实或示范反馈，不能判一个脱离上下文的“对”。

## 9. 这条路线怎样继续变成完整能力

首遍以后按同一顺序扩展：先补同一机制的独立题，再补相邻条件，最后补陌生前序和连续路线。翻前专项从F1到F5完成后，只生成起始范围快照；翻后能力仍要经过七步和连续回应。阻挡牌、后门、下注尺寸、范围变化和转牌／河牌不是首页新栏目，而是在“范围”“比较”“更新”三个父层内逐层打开。

要讨论 NL50，必须再满足完整参考、覆盖分布、动作与金额误差、连续路线和未见迁移的外部验收。文档数量、作者演示、单个求解案例和一次练习正确率都不足以证明这一点。当前状态保持未验证。
