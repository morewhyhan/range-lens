# 层级解锁与复习进入合同

2026年10月21日。本合同规定用户怎样沿一条主线逐层进入练习，以及答错、使用帮助、延迟回忆和迁移后怎样进入下一轮。它不做仪表盘式等级展示，也不把分数自动保存成长期能力。

## 1. 解锁不是菜单，而是当前父层的下一步

用户只看到当前父层的一个主要入口：

~~~text
当前帧完成
→ 当前父层的下一子层
→ 当前外层的下一停点
→ 首遍结构检查
→ 下一轮帮助撤除
~~~

其它已存在的内容只显示为“稍后在当前父层打开”，不能变成几十个并列按钮。

## 2. 六种进入状态

| 状态 | 用户看到 | 进入条件 | 不能宣称 |
|---|---|---|---|
| map | 完整路线和示范 | 进入首遍 | 不代表会做 |
| guided | 当前父层和一个关系 | 看完示范并完成一项带帮助操作 | 不代表独立 |
| independent | 必要输入、无标题、无答案色 | 在同机制未见题首答完成 | 不代表连续迁移 |
| adjacent | 只改变一个字段的对照 | 独立题完成且能指出变化层 | 不代表陌生路线 |
| delayed | 经历其它父层后回忆 | 延迟后恢复关系和下一层 | 不代表稳定长期记忆 |
| continuous | 未见历史、回应、新牌和结算 | 前层具备独立和迁移证据 | 不代表NL50 |

状态可以因资料缺失或策略变更向后退回；不能用重复题或展示更漂亮的解析强行晋级。

## 3. 首遍解锁顺序

首遍只按以下顺序：

1. L0桌面和目标；
2. L1翻前场景；
3. L2格子；
4. L3翻前动作；
5. L4范围交接；
6. L5翻后定位；
7. L6牌面、牌力、范围和动作；
8. L7金额、回应、新牌和更新；
9. L8结算和结构检查。

每个停点只有在当前问题答完或以明确示范身份完成后，才允许进入下一个停点。用户可以返回当前父层，但不能从入口直接跳到后街精确策略。

## 4. 错误和帮助怎样影响进入状态

| 情况 | 当前记录 | 后续动作 |
|---|---|---|
| 首答正确 | 独立候选证据 | 进入同层未见对照或下一层 |
| 使用帮助后正确 | 帮助完成 | 留在当前层，换一个同机制题 |
| 重答仍错 | 当前层未通过 | 回最近缺失层，再示范一个事实 |
| 只答对事实 | 事实正确 | 允许进入课程规则或示范，不开放策略独立 |
| 动作对但范围错 | 动作暂不通过 | 回范围子层，不推进后继 |
| 策略对但金额错 | 执行暂不通过 | 回账本子层，不推进下一街 |
| 资料缺口 | 停止身份 | 显示缺什么，不进入精确题 |

一个维度通过不能覆盖另一个维度的错误。

## 5. 复习队列怎样进入

同一父层的复习按照固定顺序：

~~~text
一个已会关系
→ 一个动作保持的相邻对照
→ 一个动作改变的相邻对照
→ 一个延迟回忆
→ 一条完整路线
~~~

复习不依赖长期数据库。当前会话可以记录首答、帮助和重答；关闭后由课程版本和会话种子重新生成确定队列。研究者若要做延迟试读，在课包外记录版本，不写入用户产品状态。

## 6. 进入连续路线的硬条件

进入continuous前必须同时满足：

- 当前父层能在未见题中定位；
- 牌面和最佳五张事实正确；
- 范围图能区分物理过滤和行动筛选；
- 动作和金额符合已声明政策；
- 动作后范围、底池、后手和行动权更新；
- 所有正支持回应和新牌有后继；
- 至少完成一条动作保持对照和一条单字段迁移；
- 首答和帮助后答分开。

缺任何一项，停在当前层或adjacent，不把用户送进一条看似完整但中间缺数据的路线。

## 7. 当前状态

该合同把“下一步何时出现”从分数逻辑改成父层和证据逻辑。当前文档已定义状态和进入条件，但页面解锁、真实试读和各层阈值尚未验证。任何百分比或题量门槛都要等试读后校准。
