# 首手19帧纸面候选与p3插入审查

## 1. 为什么建立候选版本

95号审计确认原18帧缺少p3范围交接，96号已经写出一个事实层候选。现在把它放进整条帧序，检查它是否真的位于p2和p4之间，以及关闭后能否回到同一父帧。

这是**纸面候选版本**，不是对原18帧的静默修改，也不是已接入应用的发布包。它只验证结构插入：原18帧仍保留，新增一帧后首遍核心父步骤不再缺p3。

## 2. 候选帧序

```text
S01 进入位置
→ S02 认识总额与新增额
→ S03 翻牌后定位行动者       p1
→ S04 读自己的牌力           p2
→ R01 范围交接事实桥         p3（新增）
→ S05 比较过牌与下注         p4
→ S06 执行给定金额           p5
→ S07 对手回应与金额         p6
→ S08 新牌更新               p6
→ S09 转牌重新比较           p4
→ S10 执行转牌金额           p5
→ S11 回应后更新池            p6
→ S12 河牌重新定位           p1
→ S13 河牌比较               p4
→ S14 全下后等待回应          p6
→ S15 进入摊牌               p7
→ S16 比较最佳五张            p7（打开p2事实子层）
→ S17 结算账本               p7
→ S18 未见短局面迁移          结构检查
```

R01只问实体范围事实，不问下注；选项和A72输入身份沿用96号。它完成后返回S05的比较父帧，不改变S05的牌面、历史、金额或首次答案。

## 3. 候选通过条件

纸面候选只有在以下检查都通过后，才可以进入作者课包审查：

- p1—p7各至少有一个核心帧；
- R01前后父帧哈希一致；
- R01的已知牌、公共牌和图表来源可复核；
- R01明确标记动作筛选为“资料不足”；
- S05仍然是动作比较，不被R01的物理事实答案替代；
- S18仍然是未见结构/单变量迁移候选，不能因为帧数变成19就标学习通过。

即使这些结构检查通过，仍需要匹配的动作后范围、完整后继、真实页面和低基础试读；因此候选身份仍不是完整GTO首课。

机器可读候选见 [first-hand-lesson-v3-candidate.json](first-hand-lesson-v3-candidate.json)。
