这份合同把最终标准压成一个可以检查的产品结果：**一个没有扑克基础、阅读慢、操作慢的人，沿着一条顺序主线跟完第一次，能说出每一步要解决什么；之后在不看答案的陌生局面里，能慢慢完成同一套步骤；最后才用冻结配置和独立复核讨论目标级能力。**

“小学生或老奶奶能练到 NL50”是设计目标，不是已经得到的保证。前半句由低基础试读和结构回放证明，后半句必须由匹配参考、未曝光连续题、独立复核和真实决策审计共同证明。任何一份纸面合同、题量、短期盈利或求解器截图都不能单独推出这个结论。

## 一、学习者真正经历的唯一主线

学习者不先看到 35 个能力入口，也不先看到求解器参数。第一次只看到下面这条路线：

```text
L0 这手牌发生了什么
  → L1 谁在什么位置、谁先行动
  → L2 翻前动作怎样结束、起始范围从哪里来
  → L3 现在的牌面和我的牌是什么
  → L4 进入翻后父帧
      → p1 定位当前行动者和历史
      → p2 读牌面、牌力、听牌和牌面类别
      → p3 看哪些范围组合仍然可能
      → p4 比较双方、价格、动作目的和课程边界
      → p5 选择当前动作或明确停止
      → p6 看动作/新牌怎样更新范围、金额和行动权
      → p7 结算、回放、做一个只改一项的迁移
```

每一个 `p` 步骤都可以打开一个子练习，但子练习只能在当前父帧中出现；关闭后恢复原来的牌面、历史、范围、首答和下一步。后台可以有完整的 35 个单元，前台始终只有一条当前路线。

## 二、每个停点必须让用户看懂的五件事

每次只问一个主要问题，画面固定回答以下五件事：

1. **我现在在哪一层？** 用一条短标题和当前节点标识说明，例如“p3｜看范围”。
2. **为什么现在问这个？** 用一句白话说明它解决哪一个前置问题，例如“先确认哪些牌还可能，下一步才比较下注”。
3. **眼前要看什么？** 只突出当前中心视觉：桌面、牌面、个人牌、范围图、动作按钮或更新后的范围图。
4. **我需要交付什么？** 明确答案形状：点一个选项、指出一个格子、输入金额、选择动作，或选择“资料不足，停止”。
5. **答完往哪里走？** 显示一个下一步或停止卡；出错时显示回到哪个父层，不把用户送进另一条路线。

如果资料不足，停止本身就是可执行答案：告诉用户缺少哪一层、为什么不能猜、回到哪个父帧。不得用相邻牌面、权益最高动作或默认过牌填空。

## 三、一次跟练怎样建立脑内架构

第一次不是考试，而是完整示范加一次首答。每一层都按相同节奏运行：

```text
先看当前画面
→ 用户先作答（可选“我不知道”，仍按错误记录）
→ 只解释这一层的原因
→ 用户用一句话复述交接
→ 执行唯一主要动作
→ 看到下一层或停止卡
```

首次完成后，用户至少能用自己的话复述：

```text
先定位 → 再读牌 → 再看范围 → 再比较 → 再执行 → 再更新 → 再回放/迁移
```

能点完按钮但说不出“为什么现在到这一步”，不能算形成结构。阅读慢、计算慢不算错误；页面必须替用户决定当前层、答案或下一步，才算结构失败。

## 四、从跟练到能执行的四级递进

| 阶段 | 学习者看到的帮助 | 必须形成的能力 | 允许得出的结论 |
|---|---|---|---|
| S0 首遍导览 | 层标题、当前问题、中心视觉、白话解析 | 能按顺序走完并复述交接 | 只证明路线可理解 |
| S1 慢速执行 | 隐藏部分标题，保留输入和输出形状 | 能在陌生但资料充分的节点逐层完成 | 证明单步执行，不证明连续能力 |
| S2 单字段迁移 | 只改变牌面、位置、前序、范围或动作菜单中的一个字段 | 能指出应重新检查哪一层，并保留其它字段 | 证明结构迁移，不证明真实盈利 |
| S3 连续与目标复核 | 连续三街、未曝光题、独立重建和真实决策审计 | 范围、金额、行动权、后继和停止边界不断裂 | 才能在冻结配置下讨论目标级准备度 |

帮助撤除必须按证据推进：首答、提示级别、错误层、父帧恢复和迁移结果都记录在当前会话内。看完解析再答对只能说明复习有效，不能覆盖第一次独立答案。

## 五、每道策略题必须具备的后台闭环

事实题可以只依赖实体牌和明确课程规则；策略题必须同时具备：

- 固定配置指纹：桌型、有效筹码、抽水、位置、前序、牌面、范围和动作菜单；
- 来源身份：原始参考、课程简化、事实或停止卡，不能混用；
- `R_before`：当前行动前范围及分母；
- 当前动作答案：逐手频率、课程量化规则、动作金额和判分身份；
- `R_after(action)`：按动作频率筛选并重新归一化后的动作后范围；
- `successors`：新牌、对手回应、下一街或明确停止；
- 差异账本：课程简化相对参考改变了什么、代价是什么、受影响的祖先节点有哪些；
- 用户可见版本：当前一步的图和白话解释；完整原始数据只能作为按需展开的证据层。

缺一个关键字段，当前节点只能降级为事实、示范或停止题，不能继续做精确策略判分。`equity`、牌力、局部锁定模型和桌面舍入图都不能替代动作策略。

## 六、为什么这套结构能从“案例”迁移到“原理”

每个练习不是单独记一个答案，而是把案例拆成同一条因果链：

```text
输入改变了什么
→ 哪个观察层受到影响
→ 哪些组合/价格/行动权随之变化
→ 当前动作的理由怎样变化
→ 动作后范围和后继怎样变化
```

例如只换一张转牌，系统不能只显示“答案从下注变过牌”；它必须让用户先看到牌面变化，再指出受影响的牌力/听牌/阻挡或范围层，最后看到动作前后范围差异。只有这样，下一道未见牌面才有可复用的思考路径。

## 七、目标级能力的硬边界

在以下条件都没有满足以前，系统只能说“正在验证课程结构和局部能力”：

1. 六人现金桌、100BB、抽水、位置、前序、动作菜单和课程版本已经冻结；
2. 至少一套课程配置取得匹配的逐组合参考、动作后范围和合法后继；
3. 原始参考、课程政策、差异账本和用户课包分开保存；
4. 35 个单元都能挂回同一条父子路线，资料缺失处有停止边界；
5. 低基础真实试读逐停点记录语言、视觉、记忆和操作四类证据；
6. 未曝光单字段迁移和连续三街题通过，且范围、金额、行动权和后继守恒；
7. 独立复核者能从冻结输入重建答案；
8. 真实牌局只统计已覆盖配置，并把输赢与决策正确性分开；
9. 有外部目标基准和足够长期的决策级样本。

## 九、35 项怎样进入这条主线，而不重新变成平铺菜单

35 项不是首屏的 35 个按钮。调度器根据当前父帧和学习者证据一次释放一个子单元：

| 释放阶段 | 用户看到的内容 | 进入条件 | 失败时 |
|---|---|---|---|
| 首遍代表 | 1.5、2.1、3.1、4.5、5.7 五张代表卡，每次只开一张 | 当前父帧已到 p4 或 p6 | 留在当前父帧，不能打开下一组 |
| 结构地图 | 每个单元的白话问题、必需输出和返回点 | 首遍顺序、层定位、错误回退、单字段迁移已记录 | 回到缺失的结构停点 |
| 引导单元 | 当前父帧下的基准卡、对照卡、必要的事实卡 | 单元身份、来源和事实边界齐全 | 只开放事实/示范或停止卡 |
| 独立单步 | 资料充分单元的未见题，答后看解析 | 参考策略、金额和动作前后范围齐全 | 返回当前单元，不跳到连续路线 |
| 相邻迁移与延迟 | 只改一个字段，隔开原题后再答 | 保持字段已核对，首答先于帮助 | 重新显示差异，不替用户作答 |
| 连续路线 | 进入转牌、河牌和结算的合法后继 | 后继、范围账本和停止身份全部闭合 | 停在当前父帧，不猜下一街 |

五组单元的父帧固定为：`compare.unopened`、`compare.bet`、`compare.raise` 进入 `p4`；`update.response`、`update.card` 进入 `p6`。调度器只在父帧内部打开组，关闭后恢复同一父帧。边缘/内部比例、事实/混合比例和迁移比例只能改变可用题池的抽取比例，不能改变政策、范围、EV或判分答案；题池为空时显示不可用，不用邻近题填充。

这条释放链解决两个相反的风险：只练五个案例会记住样本，直接平铺35项又会失去结构。用户始终只处理当前一个子任务，作者侧仍能用35项覆盖矩阵检查有没有漏项。

## 十、视觉上怎样让用户感觉到这条结构

每个停点只保留四个区域：顶部路线和当前层、中央唯一主视觉、下方一个问题和一个主要动作、右侧或抽屉里的可选解析。中央主视觉随父步骤变化：

| 父步骤 | 中央主视觉 | 用户要看见的变化 |
|---|---|---|
| L0—L2 | 六人桌、位置、前序和翻前图 | 谁在桌上、谁先行动、范围从哪张图来 |
| L3/p2 | 真实牌面、最佳五张、牌力顺序和听牌 | 牌面类别、当前牌力、哪些补牌有效 |
| p3 | 固定坐标和固定分母的范围图 | 物理撞牌删掉什么，哪些组合仍可能 |
| p4/p5 | 合法动作和实际金额 | 当前比较对象、价格、动作目的和课程边界 |
| p6 | 同尺度的动作前后范围图、账本和行动箭头 | 哪些组合因物理冲突减少，哪些因动作频率减少 |
| p7 | 终点账本、停止卡或单字段迁移卡 | 本手链条、错误层、下一次从哪一层重新检查 |

动画只表达一次变化：旧状态 → 一次动作或一张新牌 → 新状态和下一行动者。动画在问题出现前停下，用户必须先作答。正确/错误不能只靠红绿颜色表达，牌面使用牌面文字和花色，行动者同时使用箭头与文字，范围变化同时使用边框、纹理和数值。前后范围必须保持同一 13×13 坐标、同一尺度和同一分母；“实体上不可能”“动作后减少”“资料未知”必须是三种不同语义。

因此视觉不是装饰层，而是交接层：上一张图的输出必须在下一张图中继续可见。关闭范围图、解析或子练习后，父帧的牌面、历史、金额、范围和首答都恢复；任何子层如果改变了主线状态，却没有明确交接字段，就不能发布。

## 十一、每个单元怎样从案例变成可迁移原理

每个单元都必须有三张卡，但三张卡仍挂在同一个父步骤里：

```text
基准卡：看懂一个具体局面
→ 对照卡：只改变一个字段，看什么随之变化
→ 迁移卡：换成未见局面，先自己指出要回哪一层
```

每张卡至少交付：一个白话原理、一组可见事实、唯一决定变量、动作前范围或事实快照、变化后的范围/账本/停止、父帧返回点和下一步。解释顺序固定为“先说答案或事实 → 指出变化字段 → 解释为什么影响当前层 → 展示范围/账本/后继变化 → 说下一次先检查什么 → 最后才展开公式和技术名称”。

这样学习者学到的不是“这张牌按这个按钮”，而是“什么改变会把我送回哪一层”。牌面类别、阻挡、后门、牌力标签都只能作为事实或范围修正，不能单独生成动作答案；动作必须有合法后继或明确停止。

## 十二、首遍不能漏掉的十二个原理

首次路线必须依次把这些原理放进用户能看见的步骤里，之后再在对应父帧复查：

1. 谁在决定、轮到谁行动；
2. 底池、待补金额和双方后手；
3. 公共牌的花色、连接和配对结构；
4. 自己的最佳五张、牌力和改善牌；
5. 行动前双方的合法组合和固定分母；
6. 实体牌冲突与动作筛选是两件事；
7. 当前动作的目的是什么；
8. 尺寸带来的价格和阈值怎样变化；
9. 执行动作后金额、底池、后手和行动权怎样交接；
10. 动作后范围具体留下和减少什么；
11. 新牌改变了什么，真正的后继是什么；
12. 结果、错误层和下一次重新进入哪一层。

这十二项不是十二个平铺课程入口，而是同一条路线上的十二个交接字段。缺少其中一项，首遍只能标记为结构未闭合；后面的题量、分数和解析不能补回被漏掉的原理。

## 十三、低基础用户第一遍到底听到什么

首遍默认使用“白话层 + 操作层”，技术词只在用户完成一次操作后作为可选别名出现。第一遍不把 `EV`、`GTO`、`CFR`、阻挡、后门、频率、后继、分母等词放在导航按钮上；它们必须先被翻译成用户能看见的动作：

| 技术概念 | 首遍说法 | 首遍先看什么 |
|---|---|---|
| 范围 | 对手可能拿的牌 | 固定坐标的牌格 |
| 权重 | 这些牌留下的可能性高低 | 同一分母下的格子深浅/数值 |
| 实体过滤 | 这张牌已经被占用，所以不可能 | 被划掉的具体组合 |
| 动作过滤 | 做完这个动作后，哪些牌更常留下 | 动作前后箭头和同格变化 |
| 阻挡 | 我手里的牌让对手某些牌变少 | 我的牌指向对手格子 |
| 后门 | 需要连续两张补牌才会改善 | 两步补牌路径 |
| 权益 | 摊牌时平均能分到多少池 | 摊牌份额图 |
| 期望收益 | 这个动作长期平均多拿还是少拿 | 动作结果对照条 |

按钮始终使用普通话，例如“先看现在轮到谁”“看我的牌力”“看对手可能拿什么”“比较这两个动作”“执行并更新”“回看我错在哪一层”。错误反馈只说“你漏了哪一层、回到哪里”，不说“你不是阻挡牌理论没学会”。

## 十二、怎样判定“真的学会”，而不是只会点按钮

所有证据分开记录，不合成一个漂亮的总分。至少分别观察：

| 维度 | 观察结果 | 不能替代的维度 |
|---|---|---|
| 路线理解 | 能复述顺序、定位当前层、说出下一步和错误回退 | 不能替代策略正确 |
| 事实与数学 | 牌张合法、最佳五张、价格、金额和账本正确 | 不能替代动作政策 |
| 单步执行 | 在资料充分节点先答，再交付动作、金额和更新/停止 | 不能替代连续路线 |
| 原理迁移 | 只改一个字段，能回到受影响层并重做 | 不能替代多街执行 |
| 连续性 | 翻牌到转牌到河牌保持历史、范围、账本和行动权 | 不能替代真实决策审计 |
| 独立复核 | 外部复核者能从冻结输入重建答案和差异账本 | 不能替代学习者试读 |
| 真实目标审计 | 只在覆盖配置记录真实决策，并把结果与决策分开 | 不能推出未覆盖局面 |
