# 逐街行动状态与后继可达性合同

2026年10月21日。本合同检查“每个地方和步骤都不遗漏”是否真的成立。它把街次、角色、行动状态、动作菜单、范围更新和后继拆成可审计的格子；一个格子没有后继时必须显式停止，不能被相邻案例或默认动作填补。

## 1. 覆盖索引的六个轴

每个可练节点至少绑定：

~~~text
street          flop / turn / river
role            preflop_last_raiser / preflop_caller / blind_defender / responder
position        IP / OOP及具体座位
decisionState   unopened / facing_bet / facing_raise / allin / terminal
ownerView       当前学习者和被观察范围的拥有者
successorKind   response / new_card / settlement
~~~

同一张牌面只覆盖其中一个角色和一个行动状态时，不能宣称覆盖整张牌面。一个“无人下注”节点没有面对下注后继，也不能自动替代。

## 2. 五种行动状态

| 状态 | 用户先回答 | 必须有的后继 |
|---|---|---|
| unopened | 当前谁先行动，可用过牌和下注 | 对手回应、下一张牌或终局 |
| facing_bet | 价格、弃牌、跟注和已开放加注 | 跟注后的行动、弃牌终点、加注回应 |
| facing_raise | 新价格、对手加注范围和跟／再加／弃 | 再加回应、跟注后新牌或终局 |
| allin | 当前可争池、待补和跟／弃 | 摊牌或弃牌结算 |
| terminal | 为什么行动结束 | 账本、最佳五张、平分和结果 |

若某课程政策只开放两个动作，题面必须写明“本题动作菜单”；不能把删掉的动作说成规则上不存在。

## 3. 街次和角色覆盖

作者发布前按以下矩阵检查：

| 街次 | 翻前最后加注者 | 翻前跟注者／盲防守者 | 面对下注 | 面对加注 | 新牌更新 | 结算 |
|---|---|---|---|---|---|---|
| 翻牌 | 有／无参考分别登记 | 有／无参考分别登记 | 逐节点登记 | 逐节点登记 | 转牌后继 | 若全下或弃牌 |
| 转牌 | 保留前序和范围 | 保留前序和范围 | 逐节点登记 | 逐节点登记 | 河牌后继 | 若终局 |
| 河牌 | 保留全部历史 | 保留全部历史 | 逐节点登记 | 逐节点登记 | 无下一公共牌 | 必须结算 |

“翻前最后加注者有题”不能填补翻前跟注者的空白；“翻牌有一条参考”不能填补转牌和河牌。

## 4. 节点发布状态

每个格子使用以下状态：

~~~text
not_open
fact
demonstration
course_policy
reference_policy
learner_verified
~~~

状态必须绑定缺口和下一补证动作。not_open不是错误，它表示作者没有足够资料开放精确练习。fact可以练牌张、金额和合法性，不能给策略按钮；course_policy必须声明是用户简化；reference_policy必须有完整动作和后继。

## 5. 后继索引的最低字段

每一条可继续边必须保存：

~~~text
parentNode
actionId
actionAmount
actor
rangeBefore
rangeAfter
normalizationDenominator
nextStreet
nextBoardCard
nextActor
nextDecisionState
successorId
supportStatus
terminalOrContinue
~~~

对于新牌，必须记录具体牌张和合法分母；对于回应，必须记录是过牌、下注、跟注、弃牌或加注；对于终局，必须记录金额账本和摊牌身份。

## 6. 可达性审计

一个完整首课的可达性审计按下列顺序运行：

1. 从L0进入，找到翻前场景；
2. 从翻前动作生成L4范围交接；
3. 在翻牌节点分别检查无人下注、面对下注和面对加注；
4. 每个正支持动作都检查转牌和河牌后继；
5. 每张开放新牌都检查下一行动者和范围更新；
6. 每个弃牌、全下和摊牌终点都检查账本；
7. 从任意子层返回父帧，确认路线和状态不变；
8. 把所有没有后继的节点列成停止清单。

审计报告必须同时列出已覆盖节点数、事实节点数、示范节点数、课程政策节点数、目标参考节点数和未开放节点数。不能只报告“题目总数”。

## 7. 自动出题的边界

出题器只能从已登记的可达节点取题：

- 进入未开放状态时，练“识别资料缺口”或不出题；
- 进入事实状态时，练牌张、牌力、金额和合法性；
- 进入课程政策状态时，按声明的简化动作判分；
- 进入参考策略状态时，才可判逐手频率、EV、范围和后继；
- 进入终局状态时，必须完整结算后再关闭父帧。

不允许通过复制相邻牌面、随机发新牌或默认对手回应填空。
