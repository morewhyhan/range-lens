# A72范围交接事实候选帧

## 1. 这帧的身份

这是95号审计要求的补位候选，只负责把学习者从“我拿到什么牌”带到“双方可能拿什么”。它使用现有翻前图作为输入，并先练最容易验证的物理事实：已知底牌和公共牌会让某些实体组合不可能。

它**不是**完整的动作后范围，也不是翻牌下注策略。动作筛选需要匹配的回应参考；当前资料不足时，界面必须明确写“资料不足”，不能把物理过滤后的图叫作对手真实后验。

## 2. 候选题面

当前父帧沿用A72候选首手：六人桌、100BB研究配置，BTN开池，SB 3bet后BTN跟注；翻牌 `A♥ 9♣ 2♥`，学习者底牌 `A♣ Q♦`。输入图表身份为 `open-BTN` 与 `threebet-SB`，仅用于建立起始范围的来源坐标。

题目只问：

> **“先不选下注。已知公共牌和我的底牌后，下面哪一组牌在对手手里已经不可能？”**

选项：

1. `A♣K♣`：不可能；
2. `K♠Q♠`：仍是物理上可能的候选；
3. “所有带A的牌都不可能”：错误，公共牌和我的底牌只占用具体实体牌；
4. “我不知道”。

正确事实是第1项，因为 `A♣` 已在学习者手里。第2项没有与已知牌冲突，不能因为它“看起来不像”就划掉。这个答案只证明实体冲突识别，不证明BTN会以什么频率继续或弃牌。

## 3. 屏幕应怎样显示

```text
左：BTN开池图 / SB 3bet图（同一坐标，不重排）
中：A♥ 9♣ 2♥ + A♣ Q♦实体牌
右：点选一组组合，显示“物理不可能 / 仍可能 / 资料不足”
底部：一个“打开动作后范围”按钮，但当前保持关闭并注明缺参考
```

点开 `A♣K♣` 时，组合被打叉并显示原因“已知A♣在自己手里”；点开 `K♠Q♠` 时保留非零的物理可能标记。页面不得把未取得的行动概率填成颜色或百分比。

## 4. 关闭与后续

候选帧完成后回到S05的动作比较父帧，保留原牌面、历史、金额和首次答案。下一层可以继续比较过牌与下注，但本帧不能替代后续的动作筛选范围。

要把它升级为可发布的p3完整帧，还需要：

- 同一配置下双方动作前范围的可复现输入；
- 响应动作对每个实体组合的筛选概率或明确课程政策；
- 固定分母的动作前/动作后范围图；
- 一个未见题检验学习者能否把物理移除与动作筛选分开。

机器可读候选见 [a72-range-handoff-candidate.json](a72-range-handoff-candidate.json)。
