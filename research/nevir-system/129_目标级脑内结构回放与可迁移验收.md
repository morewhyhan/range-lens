# 129｜目标级脑内结构回放与可迁移验收

这份合同补上最终标准中最容易被误判的一层：用户跟着一手牌走完以后，是否真的形成了“下一步该看什么、这一层交给下一层什么”的脑内结构。它不把答对按钮当作结构掌握，也不把看到解析当作会迁移。

## 一、验收的对象不是答案，而是状态链

每个父步骤都要留下一个可以交给下一层的状态。把一次学习者回答记成：

```text
T = (当前父层, 可见输入, 学习者输出, 交接状态, 错误回退点)
```

如果用户只说“下注”而没有交出金额、行动权和下一位，p5没有完成；如果用户说“对手范围变紧”却没有指出是物理冲突还是行动筛选，p3没有完成；如果用户根据最终输赢判断前面的动作，p7没有完成。系统必须按字段检查，而不是只看最后一个按钮。

## 二、七层回放必须还原的交接

| 层 | 学习者要能说清 | 交给下一层的最小状态 | 不能用什么替代 |
|---|---|---|---|
| p1 局面 | 谁行动、历史、底池、后手、待补 | `actor/history/pot/stacks/toCall` | 只看自己的底牌 |
| p2 牌力 | 最好五张、成牌、听牌、改善牌 | `bestFive/category/improvementCards` | 看到湿牌面就猜下注 |
| p3 范围 | 哪些组合物理不可能、哪些因行动改变 | `before/physical/actionFilter/denominator` | 把撞牌说成对手弃牌 |
| p4 比较 | 合法动作、价格、声明后续、课程政策身份 | `legalActions/price/purpose/policyIdentity` | 只背牌型口诀 |
| p5 执行 | 具体按钮、实际金额、下一位 | `action/amount/potAfter/stacksAfter/nextActor` | 只点按钮 |
| p6 更新 | 回应或新牌改变的字段、范围和后继 | `changedField/rangeAfter/newCard/successor` | 把整手牌重置 |
| p7 收口 | 结算、决策与结果分开、错误层、下一次只改什么 | `settlement/resultSeparation/errorLayer/nextEntry` | 用输赢倒推动作 |

## 三、用户怎样完成回放

回放不是一个新的平铺课程，也不是把七个步骤同时展示出来。它是首手结束后的四段嵌套检查，每次只给一张卡：

1. **路线回放**：隐藏步骤名称，只给七个空位置和一条已走过的状态线；用户依次说出每层先做什么。系统不要求速度，但要记录是否跳层。
2. **交接回放**：随机打开一个父层，显示必要输入，用户先指出当前层，再给出要交给下一层的字段。答完才显示该层解析。
3. **断点重接**：系统故意在一个交接处放入已知错误，例如金额正确但行动权错误，用户指出最近缺失层并回到该父帧。不能从首页重新开始。
4. **单变量迁移**：只改变一个字段（牌面、位置、价格、回应或新牌），用户先指出受影响的层，再完成同一交接。题面不出现“本题考阻挡牌”等标签。

每段都保留首答、帮助级别、重答和回退点。帮助后答对只能证明“在帮助下修正”，不能覆盖首答，也不能直接升级为独立掌握。

## 四、结构通过的最低条件

纸面合同不等于真人通过；下面是未来施测时必须检查的结构条件：

- 路线七层全部出现，并且顺序没有跳过；
- p1—p7每层的最小交接字段都非空，字段身份正确；
- 至少一次错误能回到最近缺失层，并恢复原父帧；
- 单变量题中，用户先指出受影响层，再做判断；
- 首次回答发生在任何解析、颜色提示或主持者引导之前；
- 题面只开放当前层必需信息，不靠隐藏信息逼用户猜答案。

其中任意一项缺失，只能标为“完成示范”或“看到路线”，不能标为“结构已建立”。不设速度门槛；慢是允许的，跳层和把答案背出来不允许。

## 五、错误如何定位和退回

| 观察到的错误 | 归因层 | 只回放什么 |
|---|---|---|
| 不知道谁行动或待补多少 | state | p1 的历史和账本 |
| 把三张牌看成两对、漏掉听牌 | board/hand | p2 的最佳五张和改善牌 |
| 把已知牌冲突说成对手弃牌 | range | p3 的物理过滤与行动筛选对照 |
| 合法动作或价格没看全 | price | p4 的动作菜单和价格 |
| 按钮点对但金额/行动权错 | action | p5 的执行账本 |
| 新牌或回应后仍沿用旧范围 | update | p6 的差分与后继 |
| 用输赢判断前面动作 | ledger/close | p7 的结算与决策分离 |

错误回放只打开这一层和一个最小对照，不把其余35项一起展开。若同一错误在单变量迁移中再次出现，才提高帮助等级并返回该层父题。

## 六、与策略正确性的边界

这份回放合同只证明学习者是否能沿结构运行，不能证明某个下注频率是GTO。p3的范围交接必须等匹配参考策略；p4的动作判分必须有课程政策或匹配参考；p6的连续后继必须有真实后继或明确停止原因。资料缺失时，回放仍可检查“知道这里应停下”，但不能把未知当成错误策略答案。

同样，结构回放通过不等于NL50。它只允许进入下一层的慢速单步和迁移验收；连续三街、目标配置对标和真实决策审计仍需独立证据。
