## 这份合同解决什么问题

课程需要把复杂参考压成少量按钮，但“看起来接近”“总体下注率差不多”都不能证明它适合判题。186号规定：先用匹配参考测出自然误差，再测课程压缩的动作、范围、收益和后继损失，最后才决定一个节点能否发布为精确练习。

没有完成校准时，系统只能说“这是课程规则”或“这是示范”，不能把任意阈值写成 GTO 正确答案。

## 一、比较对象必须完全同源

每次校准同时保存：

```text
same inputFingerprint
same rangeFingerprint
same actionTreeFingerprint
same solverCommit and solve settings
reference snapshot A / reference snapshot B
coursePolicy snapshot
```

A/B 两次参考运行用于估计求解器数值噪声、重载差异和未收敛误差。只有先知道“同一参考重复计算会差多少”，才可以判断课程压缩造成的额外损失。

## 二、四个核心指标

设实体组合为 `h`，动作是 `a`，动作前权重为 `w(h)`，参考策略为 `p(h,a)`，课程权重为 `q(h,a)`。

### 1. 动作分布差

```text
D_action = Σ_h w(h) × 1/2 × Σ_a |p(h,a) − q(h,a)|
```

它衡量课程政策和参考策略在动作分布上相差多少。它不能单独决定发布，因为小频率差也可能发生在关键后继上。

### 2. 参考策略下的课程损失

```text
L_policy = Σ_h w(h) × [EV_ref(h,best_ref) − Σ_a q(h,a)×EV_ref(h,a)]
```

它问的是：在同一参考回应下，学习者执行课程政策相对参考最佳动作少了多少价值。若动作菜单已被删减，必须使用重新编译后的祖先和后继，不能继续读取旧的根 EV。

### 3. 动作后范围差

```text
R_ref(h,a) = w(h) × p(h,a)
R_course(h,a) = w(h) × q(h,a)
D_range(a) = Σ_h |R_ref(h,a) − R_course(h,a)| / Σ_h w(h)
```

物理冲突先从 `w(h)` 中移除，不能把实体不可能误算成课程损失。视图归一化时保留同一父节点和同一分母，并单独记录未知和零支持。

### 4. 后继完整度

```text
C_successor = 已有真实后继的正支持动作质量 / 全部正支持动作质量
```

后继完整度不是相似度指标，而是发布硬门槛。任何正支持动作、新牌或回应没有真实后继或明确停止原因，连续练习直接停止。

## 三、先校准参考噪声，再校准课程损失

校准分成四组，不能只取容易的稳定牌：

1. **稳定动作组**：单一动作明显领先，用来测求解器和导出噪声；
2. **边缘混合组**：两个或多个动作接近，用来测量频率量化和判分风险；
3. **菜单敏感组**：删除一个下注尺寸会改变祖先选择，用来测政策重算是否完整；
4. **后继敏感组**：新牌、回应或行动后范围会改变，用来测连续链是否闭合。

每组都要有独立校准样本和未见复核样本。阈值必须满足：

```text
reference_noise_floor < course_release_tolerance < unacceptable_policy_loss
```

三者没有通过独立样本分开估计前，不允许写死一个统一百分比。不同父步骤、动作菜单和牌面类型可以拥有不同阈值，但每个阈值必须绑定课程版本和校准报告。

## 四、发布等级

| 等级 | 必须满足 | 用户能做什么 |
|---|---|---|
| `fact` | 牌力、金额、合法性可复核 | 读牌和价格事实题 |
| `demonstration` | 输入、来源和账本完整，但参考或损失未校准 | 跟着看一条规则示范 |
| `course_safe` | 动作差、策略损失在已校准容忍区间，范围和后继完整 | 按课程动作独立练习 |
| `edge_review` | 边缘指标或支持动作不稳定 | 只练“识别混合边界”，不判唯一动作 |
| `not_comparable` | 输入、动作树或参考身份不一致 | 显示缺口，不能判策略 |

`course_safe` 是“在声明配置和校准范围内可用于课程”，不是“等于原始 GTO”，更不是“适用于所有牌局”。

## 五、0/50/100 的额外条件

频率量化只有在以下条件同时满足时才能发布：

- `q(h,a)`来自声明的有限课程政策空间；
- 量化误差和局部策略损失都低于该类校准阈值；
- 动作支持没有被静默删除；
- 动作后范围差已计算并可视化；
- 正支持动作的后继完整；
- 边缘组合在题面中标为边缘，而不是涂成与稳定牌相同的确定颜色。

若多个量化向量都在容忍区间内，保留为混合边界或采用课程明确规定的 tie-break，并在解析中说明；不把任意一个向量写成唯一真理。

## 六、报告必须能回答什么

每份校准报告必须用普通话回答：

1. 这道题在什么局面、范围和动作菜单下成立？
2. 课程政策和参考策略具体在哪些牌、哪些动作、哪些后继上不同？
3. 这些不同造成了多少动作差、范围差和参考策略下的损失？
4. 这项损失是否低于同类已校准容忍区间？
5. 如果不能发布，用户应该练事实、看示范，还是停下来等待资料？

报告不能只输出一个绿灯，也不能用全局平均掩盖少数关键边缘牌。

## 七、当前边界

当前还没有完整匹配的 A72 参考、独立 A/B 重复求解和跨类别校准样本，所以本合同不能给出一个假想的“允许损失百分比”。它先把阈值的来源和发布顺序固定下来，防止未来为了尽快出题而先拍阈值、后找证据。
