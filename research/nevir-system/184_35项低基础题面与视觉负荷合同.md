## 为什么还要给35项单独做题面合同

主路线已经有普通话问题，释放合同已经有单元证据，但编译器如果直接把后台字段复制到题面，仍可能出现“请判断 action-filter、EV、successor 或 range”的技术问法。低基础用户会把记术语误认为学会结构。

184号只管用户第一眼看到的题面和视觉负荷，不改变策略答案。它要求每个单元都能用一句生活语言提问，并把技术别名放到答后解析或资料抽屉。

## 一、每个单元的可见卡只有五个东西

```text
一个普通话问题
一个中心视觉
一个主要动作
一个“我不知道”按钮
一个明确的父层返回点
```

同一屏最多突出三个视觉对象：当前牌/牌面、一个变化箭头、一个答案区域。范围前后图、金额账本和动作菜单只有在当前单元需要时出现；不能把整棵行动树、所有技术字段和完整解析同时铺开。

## 二、题面语言规则

1. 先问“谁、什么、哪里、变了什么、接下来做什么”，再在解析中出现技术名；
2. 主问题不得使用 `EV`、`GTO`、`CFR`、`blocker`、`backdoor`、`frequency`、`successor`、`denominator` 等词；
3. “范围”可以在练习层出现，但首次题面优先说“对手还可能拿什么”；
4. 不用“选择最优策略”这种没有对象的句子，必须指出当前合法动作、价格或变化字段；
5. 不把“这次赢了/输了”作为动作是否正确的线索；
6. “我不知道”按错误处理，并回到当前父帧，不跳题；
7. 答案颜色不能是唯一提示，文字、图例和按钮语义必须独立成立。

## 三、五个单元组的视觉骨架

| 单元组 | 生活语言主问题 | 中心视觉 | 主要交付 |
|---|---|---|---|
| 无人下注 | 现在没人下注，我要比较什么？ | 牌面、对手可能拿的牌、两个动作按钮 | 动作和一个原因 |
| 面对下注 | 对手下注后，我要付多少钱，继续的理由是什么？ | 待补金额、底池、动作三分栏 | 跟、弃或加及价格关系 |
| 面对加注 | 已经有人加注，我还要重新比较哪些牌？ | 前后价格、继续组合、加注按钮 | 新的动作和继续范围 |
| 回应更新 | 对手回应后，哪一件事真的改变了？ | 动作前后范围图、账本和行动箭头 | 唯一变化字段、后继或停止 |
| 新牌更新 | 新牌出现后，哪些牌变了，哪些没有变？ | 新牌高亮、最佳五张、组合划除 | 牌力/组合变化、后继或停止 |

这些骨架是同一套“输入 → 变化 → 受影响层 → 输出”，不是五个首页模式。打开子题时，父层路线条保持不动，关闭后恢复原父帧。

## 四、题面发布前的机器检查

每个题面必须通过以下检查：

```text
plainQuestion 非空
forbiddenTechnicalTerms 命中数 = 0
onePrimaryAction = true
centerVisual 数量 ≤ 3
unknownButton = true
parentFrame 和 returnTo 存在
firstAnswerBeforeHelp = true
```

若检查失败，题面不能进入首遍或独立练习；只能留在作者资料层修订。机器检查通过也不等于低基础用户真的看懂，仍需真实成年初学者试读。

## 五、与183号释放闸门的关系

184号只证明“题面没有把技术结构泄露成术语”。183号还要证明用户能在这个题面下首答、回退、单变量迁移和连续执行。两者都通过后，单元才可能从 `guided` 进入 `independent`；任何一个失败，都只修当前单元，不通过增加题量掩盖。

机器可读题面合同见 [learner-visible-question-contract.json](learner-visible-question-contract.json)。
