## 这份合同补的是什么

现有合同已经分别规定了主路线、八个思考节点、35项单元和错误回退，但低基础学习者最终看到的是页面，不是合同列表。页面必须让用户在同一张牌局上看见三件事：

1. 当前处在主路线哪一步；
2. 当前子问题正在改变哪个事实；
3. 子问题完成后会回到哪个父问题，以及父问题保留了什么。

因此，首遍的视觉目标不是把所有资料同时摆出来，而是让复杂性按“外层路线 → 当前父帧 → 一个子层 → 回到父帧”的顺序出现。任何解释、范围图、阻挡牌、尺寸或后继都必须附着在当前父帧上。

## 一、学习者真正走过的路线

第一次只走一条不可分叉的代表路线：

```text
桌面与前序
  → 翻前范围入口
  → 翻前动作与范围交接
  → p1 当前局面
  → p2 牌面与手牌
  → p3 对手范围
  → p4 当前动作比较
       ↳ 1.5 无人下注代表题
       ↳ 2.1 面对下注代表题
       ↳ 3.1 面对加注代表题
  → p5 执行与账本
  → p6 状态更新
       ↳ 4.5 回应后范围更新代表题
       ↳ 5.7 新牌后更新代表题
  → p7 结算与迁移
```

首遍代表题固定为 `1.5、2.1、3.1、4.5、5.7`。它们不是五个首页按钮，而是当前父帧中的五次“打开子层—完成一个关系—返回父帧”。后续训练沿同一父帧补完其余单元；不改变首页结构，也不另起一套课程。

## 二、每一屏的视觉骨架

页面必须保持固定的空间语义，使用户不必重新学习界面：

| 区域 | 永远表达什么 | 首遍允许出现的内容 |
|---|---|---|
| 左上 | 当前路线位置 | 一个短标签，例如“现在轮到谁”或“新牌来了” |
| 中央 | 当前事实 | 六人桌、底牌、公共牌、行动历史、底池和后手 |
| 右侧 | 当前比较对象 | 一张范围前后对照图，或明确的停止原因 |
| 底部 | 当前唯一任务 | 一个问题、一个主要动作和“我不知道” |
| 子层抽屉 | 当前父帧的一个缺失关系 | 一个事实、一个局部图或一个公式；关闭后回父帧 |

右侧范围图必须沿用同一坐标和同一分母；切换动作不能自动重新拉满颜色。任何颜色都要配文字、数值或边框语义，使用户即使不懂颜色也能判断“留下、移除、退出或资料不足”。

## 三、一次只让用户处理一种变化

每一屏都声明本题唯一变化字段：

- `context`：谁行动、前面发生什么、要付多少钱；
- `board`：公共牌纹理、连接、配对和新牌；
- `hand`：最佳五张、牌型和改善牌；
- `range`：实体去重、行动筛选和范围前后；
- `purpose`：动作想让谁继续、谁退出或谁付钱；
- `price`：投入、底池、所需权益和后手；
- `execution`：金额、账本和行动权交接；
- `update`：回应或新牌导致的单字段变化；
- `successor`：真实后继或明确停止；
- `result`：结算和决策分离。

一屏不同时讲阻挡牌、下注尺寸、EV和河牌。若当前题的正确答案依赖多个事实，系统先按父子层顺序逐个补齐；补齐后回到原动作比较，不能用一个长解析替代多个可观察步骤。

## 四、打开子层与返回父帧

打开子层时，页面只增加三样东西：

1. 父帧的短标题和当前问题仍然可见；
2. 本子层新增的一个事实或对照；
3. 一个明确的“回到当前判断”动作。

关闭子层后必须恢复：底牌、公共牌、行动历史、底池、后手、范围快照、第一次答案和当前待答问题。子层不能偷偷改变下注政策、发出新牌或把邻近单元接入当前历史。

如果资料缺失，子层不显示猜测答案，而显示停止卡：缺少什么、为什么不能继续、回到哪一层。停止卡是路线的一部分，不是错误页面。

## 五、首遍结束时必须看见的结构

首遍结束画面不展示总分或仪表盘，而是让学习者完成四个短动作：

1. 把八个节点按顺序放回：定位、牌面、手牌、范围、比较、执行、更新、收束；
2. 点出每条箭头传递的状态，例如“范围图交给比较层”；
3. 在一个只改变牌面或动作的相邻题上，指出需要重新检查的层；
4. 答错时回到最近缺失层，重新回答原父题。

这四项只验证结构是否建立，不宣称策略已掌握。随后才进入帮助撤除、单变量迁移、连续三街和冻结目标条件下的独立评估。

## 六、为什么这种结构适合低基础学习者

- **固定位置**：牌桌、范围图和问题始终在同一位置，学习者记的是关系，不是按钮位置变化。
- **单变量**：每次只变一个字段，学习者能看到“为什么这次要回到范围层”，而不是把所有原因混成“这牌下注”。
- **父子返回**：复杂内容被限制在当前问题里面，关闭后仍知道自己原来要做什么。
- **可见交接**：每一步都明确把什么交给下一步，避免只记住八个标题。
- **停止而不猜**：资料不足时保留结构但停止策略推进，防止把作者补的答案误学成GTO。

## 七、发布闸门

这份视觉合同只有在以下证据齐全后才可进入真实试读：

- 主路线与嵌套路由的代表题序列完全一致；
- 每个首遍停点有一个问题、一个主要动作和唯一返回父帧；
- 五个代表题能从同一父帧打开并恢复；
- 范围图、牌面、金额和停止理由在同一身份快照下可复现；
- 错误反馈一次只改变一个帮助字段，重答前不泄露完整答案；
- 未见结构回放能检查节点顺序、状态交接、错误回退和单变量迁移；
- 真实页面和低基础学习者试读尚未通过前，状态必须保持“纸面合同”。

这份合同解决的是“看起来不乱、走一遍能建立架构”的页面与路线问题。它不替代匹配GTO参考、课程简化差异、完整后继或NL50验收。
