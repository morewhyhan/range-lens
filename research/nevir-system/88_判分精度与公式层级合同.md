## 1. 判分先看答案身份

训练器不能把所有题都压成一个“对/错”算法。答案身份不同，允许的判分精度不同：

| 答案身份 | 例子 | 正确依据 | 缺什么就停止 |
|---|---|---|---|
| 事实 | 最佳五张、牌型顺序、合法金额、物理移除 | 独立规则或枚举器精确重算 | 牌面/手牌/历史不完整 |
| 翻前课程政策 | 169格的0/50/100、BB尺度动作 | 用户图表的格子和声明权重 | 来源格或尺度身份缺失 |
| 翻后课程政策 | 课程规定的过/下注/跟/弃/加 | 课程规则在当前条件下的动作集合 | 课程没有明确当前条件 |
| 参考策略 | 具体手牌动作频率、EV、后继范围 | 固定配置下的原始求解输出 | 原始输出、收敛或后继缺失 |
| 迁移 | 换一个字段后能否回到正确层 | 未见同构题的结构和动作证据 | 变量改变超过一个或父题不同 |

“我不知道”是用户在有明确答案的题上的错误；资料缺失时不生成这道精确题，而不是让用户猜。

## 2. 事实层公式

### 2.1 最佳五张和牌力

给定底牌和公共牌，枚举所有五张子集，取牌力最高者：

~~~text
rank(h, b) = max{ evaluator(s) | s ⊆ h ∪ b, |s| = 5 }
~~~

牌型顺序固定为：高牌 < 一对 < 两对 < 三条 < 顺子 < 同花 < 葫芦 < 四条 < 同花顺。相同牌型再比较牌点和踢脚；不能只用“牌型名字”判定大小。

### 2.2 合法组合与权益

双方实体底牌必须互不冲突，且不能包含已知公共牌、自己的牌或死牌。对所有合法跑牌枚举：

~~~text
equity_i = (wins_i + ties_i / players_sharing) / total_legal_runouts
~~~

多人局中，平局事件数不能直接当作分池权益；分母和分池方式必须保留。权益计算器只负责这层事实，不直接产生下注策略。

### 2.3 底池赔率和跟注收益

面对需要补 `C`、跟注后底池为 `P` 的跟注，最低所需权益为：

~~~text
required_equity = C / (P + C)
~~~

在明确的全下或终局跟注模型中，净收益可写成：

~~~text
call_EV = equity × (P + C) - C
~~~

若仍有未来行动、弃牌权益、加注或不同响应，不能用这个单步公式冒充完整策略EV，必须使用声明的后继模型。

## 3. 翻前课程图表的判分

### 3.1 纯格

纯格只有一个声明动作。用户选择该动作才算正确；选择其它动作、漏答或“我不知道”均为错误。

### 3.2 混合格

混合格必须显示动作集合和来源权重。用户先选择动作，再在需要时选择权重身份。判分要求：

~~~text
chosen_actions = source_declared_actions
chosen_weight = source_declared_weight
~~~

不能把混合格随机抽成一个纯动作，也不能把训练题中边缘牌的曝光比例当作现实策略权重。大盲题还必须把动作与下注尺度绑定。

### 3.3 图表坐标和牌面

同一格在所有练习中使用固定坐标、固定分母和固定动作语义。颜色只是辅助；格子文字、边框、图例和动作名称必须能够独立表达答案。

## 4. 翻后课程动作的判分

翻后课程动作只有在当前课程规则明确覆盖该条件时才可精确判分。课程规则至少要声明：街次、位置、翻前角色、牌面类别、具体牌面、双方范围、行动历史、底池、后手、合法动作和后继政策。

如果课程把参考频率量化为0/50/100，量化规则必须在课程版本中固定；临界值附近的频率保留“边界”身份，不用未校准的四舍五入制造确定答案。

用户答案可以有以下状态：

- **精确正确**：与课程政策声明的动作/权重一致；
- **策略集合正确**：课程允许多个动作，用户选择其中一个且题目不是要求频率；
- **错误**：动作或权重不在声明集合中；
- **不可判分**：该节点本不应开放，或来源、条件、后继不完整。不可判分题必须在发布前被拦截，不能作为用户练习题出现。

## 5. 参考策略的精度

当题目开放原始参考策略时，必须保留每个实体组合的动作概率、到达权重、动作EV、引擎版本、配置哈希、行动树哈希、收敛指标和后继。

### 5.1 策略距离

对同一父节点、同一合法组合集合和同一动作菜单，可以报告加权L1策略差：

~~~text
D = Σ_h w_h × Σ_a |p_ref(a|h) - p_course(a|h)| / (2 × Σ_h w_h)
~~~

其中 `w_h` 是父节点的实体或质量权重，`p_ref` 是原始参考，`p_course` 是课程政策。这个距离用于作者侧比较，不直接作为学习者单题分数。

### 5.2 EV差

~~~text
ΔEV_h = EV_best_ref(h) - EV_chosen(h)
~~~

整节点差异按父范围权重加权。若动作被锁定、未来回应被删除或行动树不同，必须标明比较身份；锁定模型自身收敛不能证明课程简化无损。

### 5.3 行动后范围

对动作 `a` 的实体组合，先保留绝对质量：

~~~text
w_after(h) = w_before(h) × p(a|h) × legal(h, board, known_cards)
~~~

展示相对范围时再单独归一化：

~~~text
q_after(h) = w_after(h) / Σ_h w_after(h)
~~~

绝对保留质量和重新归一化占比必须同时标记，不能把“图上比例变大”解释为组合数量增加。

## 6. 金额和后继的判分

每个动作后必须独立重算：本街投入、总投入、底池、剩余后手、行动权、合法动作和下一个状态。账本守恒是事实层门槛；账本正确不等于策略正确。

若对手回应、新牌或结算后继缺失：

1. 当前题可以保留事实或示范身份；
2. 不能开放精确策略答案；
3. 不能自动填充默认跟注、弃牌或下一张牌；
4. 连续路线必须在当前节点停止。

## 7. 解析怎样显示精度

解析面板按以下顺序显示：

1. 本题答案身份（事实、课程规则、参考策略或迁移）；
2. 适用条件和来源版本；
3. 用户答案与标准答案的差异；
4. 公式、单位和中间值；
5. 范围前后图和后继；
6. 如果资料不足，明确显示停止原因。

显示数字可以按页面需要舍入，但原始值、舍入规则和零支持状态必须留在课包中。页面不能用一个“约”字掩盖精确判分所需的条件差异。

## 8. 当前状态

事实、翻前图表、课程政策、参考策略、范围更新和迁移现在有统一的判分层级和公式合同；当前仍没有完成35项匹配目标策略、完整三街后继、低基础试读或NL50验证。因此本合同提高了可计算性和审计性，不代表答案数据已经齐全。
