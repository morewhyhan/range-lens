## 这份合同解决什么

首遍结束后，学习者应该能在一手没见过的牌局中慢慢找到正确入口。这里的“慢慢会做”不是凭感觉多想一会儿，也不是记住某个牌型口诀，而是按固定循环把当前状态转换成一个可检查的动作和下一状态。

慢速单步的目标不是速度，而是让用户在没有标题提示时仍能完成：

```text
读清输入 → 找到当前层 → 交付本层结果 → 比较有依据的动作
→ 落到账本 → 看见范围或停止原因 → 回到下一状态
```

## 一、用户真正看到的六个阶段

| 阶段 | 页面只问什么 | 用户交付什么 | 通过条件 | 错误回退 |
|---|---|---|---|---|
| 0 输入冻结 | “这手牌的局面是什么？” | 位置、历史、牌面、底池、后手、待补 | 必要输入齐全且身份一致 | 回桌面和历史 |
| 1 定位 | “现在先看哪一层？” | 当前行动者和当前父步骤 | 能说出先看状态、牌面、范围或比较 | 回路线地图 |
| 2 事实 | “这一层的事实是什么？” | 最佳五张、改善牌、物理过滤或范围前图 | 事实与牌张、分母相符 | 回事实层 |
| 3 比较 | “当前有依据的选择有哪些？” | 合法动作、价格、目的和政策身份 | 只比较允许动作，不把未知当答案 | 回范围或价格 |
| 4 执行 | “实际要做什么、投入多少？” | 动作、金额、底池后、后手后、下一行动者 | 金额合法、账本守恒、行动权正确 | 回执行层 |
| 5 更新/停止 | “这次变化后下一步是什么？” | changedField、动作后范围或停止、真实后继 | 变化可追溯，后继合法或明确停止 | 回最近变化层 |

阶段不是六个平铺按钮。系统只显示当前阶段，完成后把一张小结果卡交给下一阶段；缺资料时停在阶段5，不用默认后继填空。

## 二、一次陌生单步题怎样运行

1. **先冻结题面**：系统把输入身份和来源版本固定，用户不能通过点开解析改变题面。
2. **先让用户定位**：不显示“本题考范围”或“本题考价格”，只问现在先处理什么。
3. **只开放必要事实**：当前层的牌、历史、范围或金额可见，其余技术资料按需打开。
4. **先记录首答**：在帮助、颜色提示和完整解析出现前保存用户输出。
5. **只判当前层**：事实错回事实层，比较错回比较层，金额错回账本层，不用总分掩盖断点。
6. **显示一个最小因果对照**：一张最佳五张、一格范围、一个价格或一条后继；不一次展示整套求解器报告。
7. **恢复同一父帧重答**：帮助后仍回原题，重答不覆盖首答记录。
8. **完成后再做同父帧未见题**：只改变一个字段，检查用户是否知道该回哪一层。

## 三、怎样区分慢想和猜题

慢想允许暂停、回看当前输入和使用事实工具，但必须满足三条：

- 用户先指出当前层，再给动作或金额；
- 用户能说出至少一个影响该动作的事实，而不是只报按钮；
- 用户完成动作后能更新账本、范围或停止原因。

以下情况不算慢速执行通过：直接点动作但没有定位层；看完答案再重复；靠输赢反推选择；把未知资料当成默认跟注或弃牌；金额正确但行动权和后继为空。

## 四、不同错误只修一个变量

| 观察 | 当前错误层 | 反馈只增加什么 | 不增加什么 |
|---|---|---|---|
| 不知道先看什么 | route/state | 当前父层和入口箭头 | 不给动作答案 |
| 最佳五张或听牌错误 | hand/board | 一张最佳五张或改善牌对照 | 不显示下注频率 |
| 把物理移除当弃牌 | range | 同坐标物理过滤/行动筛选对照 | 不替换历史 |
| 不会比较跟注价格 | compare/price | 待补、跟后底池和所需权益 | 不直接选跟注 |
| 金额或行动权错误 | execution/ledger | 金额公式和账本前后 | 不重新讲阻挡牌 |
| 新牌后沿用旧判断 | update | changedField 和真实后继 | 不把整手牌重置 |
| 缺少策略或后继资料 | source/stop | 缺什么、为什么停止 | 不把错误归给用户 |

每次只改变一个帮助变量。相同错误在未见题重复出现时，先检查题面、来源、范围和父帧，再决定是否增加练习剂量。

## 五、慢速单步的释放条件

一个学习者不能因为在示范题上跟着点完，就进入陌生单步。至少要有以下证据：

1. 在无标题题面中能先定位当前层；
2. 能交付当前层最小输出，而不是只点按钮；
3. 能完成一个合法金额和行动权交接；
4. 能看到动作后范围，或正确识别停止原因；
5. 在同父帧未见题中只改一个字段，并先于解析指出受影响层；
6. 首答、帮助、重答和错误层被分开记录。

通过这些条件只开放相邻单变量迁移，不直接开放连续三街。连续路线还需要每个后继、范围分母和账本守恒独立闭合。

## 六、把“会看”变成“能做”的可观察证据链

慢速执行不能只留下一个最终按钮。训练器要把一题拆成连续的八个可见交付物，上一格的结果必须成为下一格的输入：

```text
锁定局面 → 找到入口 → 读出事实 → 看见范围变化
→ 比较有依据的选项 → 落到账本执行 → 更新或停止
→ 在同一父帧找到下一道迁移题
```

每个交付物都必须回答一个用户能听懂的问题：

| 交付物 | 用户先交什么 | 系统随后才能做什么 |
|---|---|---|
| 局面 | 谁在行动、底池、后手、待补 | 确认题面身份 |
| 入口 | 现在先看哪一层 | 打开事实或范围视图 |
| 事实 | 最佳五张、牌力、改善牌 | 判定牌面事实是否正确 |
| 范围变化 | 哪一格因为何种原因变化 | 区分物理冲突、行动筛选和未知 |
| 比较 | 合法动作、价格、目的 | 只有资料齐全时判精确动作 |
| 执行 | 动作和实际金额 | 检查底池、后手和行动权 |
| 更新 | 动作后范围或停止原因、下一行动者 | 打开真实后继或停在当前父帧 |
| 迁移 | 只改了什么、要回哪一层 | 决定是否进入相邻陌生题 |

这条链的最低证据是“首答先完成链条，再看帮助”；只点对按钮、看完解析后复述、或用最终输赢反推，都不算完成。机器可读字段和释放规则见 `slow-single-step-execution-contract.json` 的 `observableActionChain` 与 `evidenceRecord`。

## 七、资料边界

精确动作题必须有课程政策或匹配参考；只有实体权益、牌力或物理跑牌时，只开放事实题。只有当前街动作而没有下一街后继时，只允许停在当前节点。任何求解器显示、颜色强弱或相邻牌面都不能自动变成答案。

## 八、当前状态

这份合同把“慢一点也能找到正确步骤”压成了可运行的循环和释放条件，但仍是纸面规格。页面、匹配策略、完整后继和低基础真人试读尚未通过，因此当前不能把 O3 慢速执行标为真实掌握，更不能由此推出 NL50。

机器可读版本见 [slow-single-step-execution-contract.json](slow-single-step-execution-contract.json)。
