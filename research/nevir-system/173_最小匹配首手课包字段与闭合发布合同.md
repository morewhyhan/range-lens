## 这份合同为什么要单独存在

当前资料已经有范围输入、求解器能力、教学路线和发布闸门，但它们仍是分散的作者侧文件。若直接开始做35项，最容易得到的是许多局部示例，仍然没有一手从输入到三街、从参考到课程政策、从练习到迁移的完整闭环。

因此先只定义一个最小首手课包。它不是新增课程内容，而是检验整条链能否闭合的样板。样板没有闭合之前，其他单元只能继续停在事实或示范身份。

## 一、样板固定输入

样板使用当前A72候选配置，所有字段必须冻结在同一个输入指纹：

```text
six_max_cash
100BB_starting_stack
BTN_open_2.5BB
BB_call
flop_A♠7♥2♦
BB_first_to_act
flop_pot_5.5BB
effective_stack_97.5BB
zero_rake_research_config
no_bunching
```

动作树的真实金额必须从构建后的动作ID读取：翻牌过牌、33%底池、全下；转牌和河牌过牌、75%底池、全下；面对下注时弃牌、跟注、2.5倍加注、全下。任何金额、抽水、范围、位置或动作菜单改变，都产生新的样板版本。

## 二、课包必须包含的四层文件

### 1. `reference/`：原始参考层

保存完整求解原始输出，不先舍入、不先合并牌型：

- 输入指纹、求解器提交、适配器版本和许可证身份；
- 每个实际节点和动作ID；
- 每个实体组合的动作频率、EV、到达权重和收敛状态；
- `rangeBefore`、`referenceAfter`、合法新牌和真实后继；
- 转牌、河牌和终局账本；
- 独立牌力、权益和金额复核结果。

只有总下注率、截图或一张热力图，不能构成这一层。

### 2. `course/`：简化政策层

在原始参考旁边单独保存课程政策：

- 保留和删除哪些动作；
- 0/50/100或单一主动作怎样量化；
- 边缘牌的曝光顺序与策略权重的区别；
- 每手课程动作、课程动作后范围和课程EV；
- 与参考的逐手、范围、EV和后继差异；
- 政策适用边界和不能继续的停止原因。

课程答案不能覆盖或改写原始参考。只要政策改变了动作菜单或后继，就必须重新评估受影响祖先节点。

### 3. `lesson/`：唯一嵌套用户路线

课包前台只开放黄金路径中的必要帧：

```text
桌面与局面
→ 翻前进入
→ 起始范围交接
→ p1 局面
→ p2 牌力
→ p3 范围
→ p4 比较
→ p5 执行
→ p6 更新
→ p7 收口
→ 结构回放
```

每帧必须有：一个普通话问题、一个主动作、最小交付、解析、错误层、返回点、来源身份、范围或停止视觉。关闭子层后恢复父帧，用户不会看到参考文件、求解器参数或35项平铺菜单。

### 4. `holdout/`：独立迁移层

在用户看过主线之后，生成不暴露答案的测试：

- 同一父帧换一张公共牌；
- 同一父帧换一个位置或价格；
- 加入一次真实回应或新牌；
- 一个两帧微路线；
- 一题没有步骤标题的陌生单步。

每题只能改变一个字段，并保留同一父帧、同一判分身份和同一范围坐标。原题重做、同花色同构和解析后重答不计入独立迁移。

## 三、样板的发布顺序

| 阶段 | 必须交付 | 通过后能开放什么 | 缺失时怎样停 |
|---|---|---|---|
| P0 输入 | 指纹、范围、动作树、提交、许可证 | 预检 | `not_open` |
| P1 事实 | 牌张、最佳五张、合法跑牌、金额、物理过滤 | 读牌和事实题 | `fact_only` |
| P2 参考 | 逐手策略、EV、到达权重、后继 | 作者参考快照 | `reference_pending` |
| P3 政策 | 简化规则、逐手课程动作、差异账本 | 课程示范 | `policy_pending` |
| P4 后继 | 转牌、河牌、终局和账本 | 连续课程候选 | `stop_at_current_node` |
| P5 教学 | 嵌套帧、错误回退、解析和范围视觉 | 首遍跟练 | `guided_only` |
| P6 迁移 | 未见单变量题、判分、帮助撤除 | 陌生单步候选 | `no_independent_release` |
| P7 试读 | 独立首答、结构回放、连续三街和错误归因 | 发布候选 | `trial_pending` |

只有P0—P7全通过，才允许把这个样板标成`matched_strategy_practice`。任何单独的求解器输出、课程规则或首遍页面都不能越级。

## 四、用户走完这个样板后必须留下的结果

用户不需要记住A72、C0或P5这些编号，但必须能：

1. 说出从局面到收口的顺序；
2. 在牌面图上认出当前牌力和改善方向；
3. 看懂动作前后范围哪一格因什么变化；
4. 在资料充分时慢速交付动作、金额和下一行动者；
5. 在资料不足时选择停止并说出缺口；
6. 在未见单变量题中指出应该回到哪一层；
7. 在连续后继中保留历史、范围分母、底池和行动权。

这些结果仍然只证明该冻结配置下的课程学习证据；它们不能自动推出其它位置、其它筹码、其它抽水或NL50实战能力。

`P0—P7`、`C0—C9`、`V0—V6`等编号只用于作者侧审计和机器发布，不能直接显示给学习者。学习者看到的只能是“先看局面、再看牌面和范围、比较选择、执行、更新、收口、迁移”这样的普通语言。
