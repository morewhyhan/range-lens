# 练习队列与边缘牌覆盖合同

2026年10月21日。本合同把“自动出很多题、边缘牌重点练、内部牌也不能漏”编成一个可复现队列。它不把抽题比例当成现实策略频率，也不靠随机重复题制造题量。

## 1. 练习队列只属于当前父层

队列先锁定：

~~~text
当前路线父帧
→ 当前能力单元
→ 当前配置和来源版本
→ 当前题型
→ 当前采样参数
~~~

它不会同时混入其它位置、其它街次或其它未开放策略。用户关闭专项后，返回原父帧；下一次练习可以用相同版本和会话种子复现顺序。

## 2. 题目池的五种身份

| 身份 | 作用 | 能否做精确动作题 |
|---|---|---|
| pure | 认识明显纯动作或纯事实 | 能，前提是来源精度足够 |
| mixed | 练混合动作和权重 | 能，必须答完整动作集合和权重 |
| source_boundary | 练边缘和相邻变化 | 只有来源支持时能 |
| internal | 练范围内部的典型牌 | 能，不能因不显眼而省略 |
| unavailable | 资料或后继不足 | 不能，只练停止和资料身份 |

一个格子可以同时是边缘牌和内部实体组合，但题目必须保存它的分类原因。邻近格不能仅因为位置相邻就被自动标成source_boundary。

## 3. 用户可调的采样参数

用户可以调节当前父层内的题目配比：

~~~text
edgeRatio
internalRatio
pureRatio
mixedRatio
boundaryRatio
transferRatio
~~~

有效参数必须满足非负、总和为1，并且当前题目池中存在对应身份。没有source_boundary时，不能为了满足比例凭空生成边缘题；没有后继时，不能把transferRatio转成精确动作题。

系统可以提供“边缘优先”“完整覆盖”“迁移优先”三个预设，但预设只是抽题顺序，不能改变答案、范围权重或现实频率。默认比例不能被解释成科学上最佳比例，除非有学习者试读数据支持。

## 4. 不重复的确定性队列

一个队列按以下顺序编译：

1. 先完成当前父层的必需定位题；
2. 按用户配比从pure、mixed、source_boundary、internal池取未曝光实体；
3. 每个关系至少加入一个动作保持的相邻对照；
4. 每个已开放机制加入一个只改变单字段的迁移题；
5. 在队尾加入一次回到完整主线的连续题；
6. 题池耗尽时标记覆盖完成，不复制同一题冒充新题。

同一实体可以在帮助示范、引导和独立轮次各出现一次，但必须有不同的帮助身份；同一题在同一轮次不能只改按钮顺序或颜色再次出现。

## 5. 翻前和翻后各自怎样排队

### 翻前

~~~text
场景定位
→ 13×13坐标扫图
→ mixed和source_boundary
→ 相邻位置／前序比较
→ 大盲画像和尺度成对比较
→ 生成起始范围事实
~~~

半格必须答出全部动作及权重；只点其中一个动作按错处理。边缘优先只增加mixed和真实来源边界的曝光，不删除pure和internal。

### 翻后

~~~text
当前状态定位
→ 牌面类别和牌力顺序
→ 牌力／阻挡／后门关系
→ 范围前后图
→ 当前动作比较
→ 执行金额
→ 动作或新牌更新
→ 一处连续迁移
~~~

翻后题必须带着前序和范围进入。不能把每个牌面单独随机生成，再把互不相连的题叫作连续练习。

## 6. 判分维度分开

一题可以同时记录五个维度，但不能用一个总分掩盖错误：

- structure：是否进入了正确父层；
- fact：牌张、牌力、价格和金额是否正确；
- policy：是否执行已声明的课程政策；
- rangeUpdate：动作后范围和分母是否正确；
- transfer：改变一个字段后是否找到正确层和后继。

答错后解析只修复最近错误维度；重答通过也保留首答错误。unavailable题只记录是否正确停在资料缺口，不能计入策略正确率。

## 7. 题量和覆盖怎样解释

题量表示暴露的独立题面数量，不表示真实牌局分布。边缘比例表示训练重点，不表示边缘牌在现实中出现的比例。课程政策和参考策略的权重永远按实体质量计算，不能按用户选择的edgeRatio重加权。

一个父层只有在以下条件都满足时才标记覆盖完成：

- 必需定位题通过；
- 当前题池的身份配比已按参数生成；
- pure、mixed、internal和适用的source_boundary至少各出现一次；
- 至少一条动作保持对照和一条单字段迁移存在；
- 所有精确题都有来源和后继；
- unavailable题没有被误算成精确策略题。

## 8. 当前状态

本合同把翻前边缘格、内部格、翻后关系题和连续迁移放入同一确定性队列规则，但题目实际编译器和低基础学习者的最佳比例仍未验证。未来应从试读数据校准参数，而不是先写死一个看似科学的百分比。
