# 从笔记句段到可执行命题：首批审查

总入口：[统一总纲](../../翻后教学系统_统一总纲.md)。这一步把“读过材料”推进为有定位、精度与边界的内容数据。

## 1. 本轮实际抽取到什么

`node scripts/extract-nevir-research-claims.mjs`逐行读取七篇笔记，保留来源哈希、行号、小节与原文，得到275个非空文本句段。它包括标题后的正文、摘要、总结与列表，不等于275条独立战略规则。

其中70个句段出现“所有、永远、100%、必须”等需要检查作用范围的表达。这个数字是检索提示，不是70处错误。规则本身也可能使用绝对措辞，必须逐条看语境。

数据见[source-claims.json](source-claims.json)。未复核句段的状态明确为来源片段，不进入正式答案。

另一个已审查命题是转牌高低牌总结：与前段小注后空白低牌的例子存在作用范围冲突，保留待回原视频/设置核实，不提升为通用规则。

## 3. 这一步为什么重要

不能把“旧软件没有结构化某手牌”当作“原资料没有”。先抽全现有文字，可增加有依据内容，避免无谓地另编案例。

也不能把一句话直接变成题目。它需要拆出场景、对象、结论、精度、前提、例外、来源和与其他版本的关系。一个句段可能有多个命题，也可能只是解释或猜测。

首批复核9条可追溯命题与1条待核实命题。随后又从2.2快速测试补入7条有明确定位的尺寸命题：962彩虹67、JT2小注25、TT5彩虹40、T62两同花40、T62彩虹67、258单色25、T95彩虹40。第二批后为16条文本蕴含复核、1条作用范围待核实；第三批更新见下节。

新增962例能够补T02—T04的翻牌尺寸来源，但不自动补齐选牌与对手范围；JT2的25与T05导入前序33存在版本核对需求，不能将两者静默拼接。其余片段仍需语义复核，不能写成全部命题化完成。

## 4. 第三批：直接影响连续路线和条件选择的命题

新增9条文本蕴含复核，重点不是扩充题数，而是把容易误接的前序、模型和人群条件拆开：

| 来源片段 | 已确认原文说了什么 | 实施前仍需要什么 |
|---|---|---|
| N4-L26、L28 | KT52彩虹、QT52两同花在该小注前序下给出高频大注方向 | 具体选牌和响应；不与单加注底池QT5前序混用 |
| N4-L32 | 单色KT5后9♠与8♣的总下注频率、尺寸方向不同 | 原设置；第四张黑桃不能误讲成翻牌还未成花 |
| N4-L33 | JT2后9♦与5♣的继续方向不同 | 25/33版本核实，实体手牌动作 |
| N5-L20 | T83、BTN下注8BB、SB加到22BB，是所述过弃调整模型 | 约24BB底池前序与完整锁定参数；不是任意21BB池的统一XR |
| N5-L22 | 该XR被跟后描述回到过牌，同时保留K转牌激进讨论 | 不能把过牌自动解释成弃牌；不能混掉例外分支 |
| N6-L66 | 对所述常规玩家讨论价值小注、诈唬大注的可能策略 | 牌面、花色与对手偏差；“可能”不升为普遍纯动作 |
| N7-L33 | 第三枪与其他线路，以及不同人群，需要区分 | 当前对手依据、完整响应；历史统计不反解每手 |
| N7-L25 | 在该紧弱/娱乐玩家下注偏强假设下，区分价值XR和诈唬XR | 不混用3bet底池的T83过弃模型；未给齐跟注防守 |

另新增4条保留待核实/隔离：SB对CO示例将CO说成转牌领先下注，座位与行动顺序不相容；“最大错误是X/C”不能作为禁止所有跟注的策略表；“大概率快玩”不能推出跟注强牌为0；对手过牌不表示此时已弃弱牌。

第三批后为25条文本蕴含复核、5条待核实或隔离。随后为[阻挡与后门教学](14_阻挡与后门怎样接到实际选择.md)补入Q7s后门简化命题，当时增为26条。Q7s仅支持在明示课程条款里的执行，不升级为任意牌面精确求解。文本蕴含复核只证明有条件的课程陈述被正确读取，不等于已取得完整动作规则。疑点保留原文与原因，不自动改写成自创精确策略。当前总数见下节尺寸批次。

## 5. 后续逐条审核顺序

尺寸教学这一轮再补4条有定位命题：T72彩虹较大主尺寸、T高连接与花色对照、T52的AA付款对象、J98听花的AA小注讨论；另将“被跟权益下降足以否决大注”的通用化单列隔离。当时合计30条文本蕴含复核、6条待核实或隔离，原表5个待补节点数量未因此改变。

隔离有[完整给定模型的计算依据](16_下注尺寸怎样教成可比较的选择.md)：小注被跟权益5/7、大注2/3，收益却为9.5和10。它否定仅靠该观察写全局if/then，不证明原视频某个完整情境的具体小注选择错误。原文近似尺寸、表中取整与练习固定值也不得合并成“唯一数学最优”。

优先补能支撑正式首轮整手导览和常见决策的命题；其次补面对下注/加注与后街；最后处理只影响细小频率的补充。每条都保留原文与推导身份。

对绝对表述先找作用范围；频率先分尺寸、范围频率与逐手频率；涉及反应的先分课程观察、假设与给定模型；涉及牌张的先复算。冲突未消除就不能生成唯一正确答案。

随后为[A72动作单元](21_把原文简化编成可执行动作练习.md)新增R37：在明示采用该段对手偏差及最终范围小注简化时，按此简化执行。原始报告为接近100%，不恢复未知逐组合求解频率；基础版KQ过牌不被覆盖。该批后累计31条文本蕴含复核、6条待核实或隔离。程序判分绑定所采用的课程版本，物理后门计数不替代动作依据。

再为[J95单元](22_先认牌力再用规则_弱顶对与组合牌.md)新增R38、R39两条复核：弱顶对过牌的保守执行子集与J8价值下注方向；R40保留方片后门措辞所缺完整花色及同花身份。该批后合计33条文本蕴含复核、7条待核实或隔离。R08/R09的旧牌面元数据已明确未恢复原始完整花色；原文没改。J5是两对、J7可能兼有直接花听的事实，不被用来补出未给定的最优动作。

本次没有将这些新命题写入运行中的练习器，符合当前只研究文档的要求。
