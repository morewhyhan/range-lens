## 这份合同解决的不是“再加一些题”

现有路线已经规定了 35 项从哪个父步骤打开，错误矩阵规定了错后回到哪一层，六轮包规定了帮助怎样逐步撤掉。真正缺的，是把三者合成一个运行时闸门：**每个单元自己证明已经学会，才可以从带练进入独立；一个单元没有通过，不能被其他单元的总分遮过去。**

这份合同因此规定四件事：

1. 每个单元的可见任务和必须交付的证据；
2. 从完整带练到陌生慢速题的统一释放阶段；
3. 错误、`我不知道`、缺参考和帮助使用后的回退；
4. 何时允许进入相邻迁移、延迟回忆和连续三街。

它不是用户首页，也不创造第 36 项。35 项仍然只能从 `p4` 或 `p6` 的父帧按需打开，完成或停止后回到原父帧。

## 一、六个释放阶段

所有单元使用同一套阶段名，但阶段不是总分等级：

| 阶段 | 用户看到的任务 | 单元必须留下的证据 | 通过后允许什么 |
|---|---|---|---|
| `map` 看懂位置 | 跟着父帧指出当前单元在整条路线中的位置 | 能说出当前父步骤、这题问什么、答完回哪里 | 进入带练 |
| `guided` 带练完成 | 在完整提示、范围图和一个对照下作答 | 首答已保存；动作/金额/理由/范围或停止原因齐全 | 同一单元再做未见样本 |
| `independent` 单元独立 | 隐藏答案颜色和关系标题，只保留必要事实 | 首次尝试在帮助前完成；错误层被正确定位；重试后完成 | 进入单变量迁移 |
| `adjacent` 相邻迁移 | 只改变一个字段，先说变了什么，再作答 | 指出变化字段及受影响层；范围图坐标和分母一致 | 进入延迟回忆 |
| `delayed` 延迟回忆 | 中间插入其他题后，重新找到同一单元 | 能说出顺序、返回点、动作后范围或明确停止 | 允许微型连续路线 |
| `continuous` 连续执行 | 新牌局中沿父路由执行到真实后继或明确停止 | 账本、范围快照、行动权、后继链和结算彼此一致 | 仅表示该单元的连续证据，不等于 NL50 |

阶段升级必须按本顺序发生。使用同一道题的重试不能算 `independent`；看过解析后再点正确也不能算首答通过；总正确率不能替代缺失的单元证据。

## 二、每一项都用同一张证据卡

运行时给每个单元保存一张会话内证据卡：

```text
unitId / parentFrame / currentQuestion
firstAnswer / helpLevel / retryAnswer
requiredOutput
errorLayer / returnTo
changedField（若为迁移题）
rangeBefore / rangeAfterOrStopReason
ledgerAfter / successorOrStopReason
releaseStage / releaseDecision
```

判定顺序固定为：

```text
事实可见
→ 当前父帧正确
→ 首答先于帮助
→ 必需输出完整
→ 错误层和回退正确
→ 只改一个字段的迁移正确
→ 后继或停止有依据
```

任何一项为空，当前单元停在原阶段；系统只显示缺哪一项，不拿邻近单元补齐。

## 三、帮助怎样撤除

帮助只减少“答案泄露”，不隐藏完成当前问题所必需的牌、历史、金额、行动权和真实动作菜单。每次只改变一个帮助字段：

```text
H0 完整引导：步骤名、目标格、一个对照和子题入口
H1 关系提示：步骤名、必需输入和一个对照
H2 结构提示：牌面、历史、金额、合法动作
H3 单变量迁移：同一父帧，只展示变化字段
H4 延迟回忆：去掉步骤名，只保留必要事实
H5 连续执行：新牌局，只在错误层提供帮助
```

撤除规则：

1. 只在当前阶段证据通过后撤一层；
2. 同一题再次错误，退回上一帮助层，不直接展示完整解析；
3. 第二次错误先打开当前错误层的事实子题，再回到原题；
4. 缺少匹配参考时停止该单元，不用相邻牌面或相近尺寸代替；
5. 帮助撤除是单元级的，不能因为另一单元通过而全局隐藏。

## 四、错误怎样回退，怎样重新释放

错误只允许归因一个层：

| 错误层 | 回到 | 用户下一次要交付 |
|---|---|---|
| 局面/牌面/手牌 | `p1` 或 `p2` | 当前行动者、公共牌、最佳五张或改善牌 |
| 范围/阻挡牌 | `p3` | 哪些组合仍可能、哪些是实体移除、分母是什么 |
| 动作目的/价格 | `p4` | 这个动作解决什么问题、尺寸改变的价格关系 |
| 实际执行 | `p5` | 实际投入、底池、后手、下一行动者 |
| 新牌/回应更新 | `p6` | 唯一变化字段、动作后范围、真实后继 |
| 结算倒推 | `p7` | 把当时的决策依据与一次输赢分开 |

错题的 `firstAnswer` 永远保留，重试答案单独保存。系统不跳到邻近单元，不把“我不知道”当作跳过；`我不知道`按错误处理并返回同一层。

## 五、35项怎样获得系统性，而不是平铺

首遍只开放每组的代表项，先让用户看见父步骤的共同骨架；其余项从代表项的父帧按需展开。每组的代表项至少完成 `guided → independent → adjacent`，才开放同组其他项的 `guided`：

| 父步骤 | 单元组 | 代表项 | 同组后续的共同变化 |
|---|---|---|---|
| `p4` | `compare.unopened` | 1.5 | 由牌力关系、动作目的和价格共同决定动作 |
| `p4` | `compare.bet` | 2.1 | 面对下注先比较价格，再看价值/诈唬与继续范围 |
| `p4` | `compare.raise` | 3.1 | 面对加注重新比较价格、价值和继续组合 |
| `p6` | `update.response` | 4.5 | 动作后账本、范围和行动权一起更新 |
| `p6` | `update.card` | 5.7 | 新牌先做物理移除，再重算牌力、范围和后继 |

组内不是按题号背答案，而是重复同一个“输入 → 变化字段 → 受影响层 → 输出”的关系。一个单元释放后，只开放一个相邻变化，避免同时改变位置、牌面、历史和尺寸。

## 六、什么时候才算“这一项会了”

某一单元只有在以下条件全部满足时，才能标记为 `continuous`：

1. 没看答案时完成过一次当前单元；
2. 至少完成过一次单变量相邻迁移；
3. 中间插入其他单元后仍能回到正确父帧；
4. 错误后能回到正确层，并保留首答；
5. 动作后范围、账本和行动权来自同一快照；
6. 有真实后继，或有明确、可复核的停止原因；
7. 未把一次赢输结果倒推成决策正确。

这只是“该单元的学习证据”。35 项逐项通过也不能直接推出完整目标策略、连续三街能力或 NL50 准备度；那些仍由 172、169 和匹配参考验收合同单独负责。

## 七、实现前必须保留的边界

- 释放状态只存在当前会话，不写入数据库；
- 没有匹配逐组合参考时，不开放精确动作判分；
- 没有合法后继时显示停止卡，不默认生成下一街；
- 原始 solver 输出、课程简化政策和用户可见结论分层保存；
- 任何总分、连续答对数或完成题量，都不能绕过单元闸门；
- 本合同完成的是学习证据结构，当前运行时、低基础试读、匹配参考和 NL50 证据仍未完成。
