# 五组首遍代表题面卡与教师边界

## 1. 这五张卡怎样使用

100号只选出了五个代表单元；本文件把它们写成首遍可以实际呈现的题面卡。卡片仍然不平铺：每次只从当前父帧打开一张，答后返回父帧。

每张卡都分为“学习者看到的题面”和“教师/作者边界”。学习者看不到来源文件、有限模型权重和禁止推论；作者包必须保留这些身份，防止把一个关系题误写成精确策略题。

## 2. 五张题面卡

### 卡1：无人下注时，先比较什么

- 父层：p4 / `compare.unopened`
- 题面：**“我现在有一点摊牌赢面。先把哪两条路线放在一起比较？”**
- 选项：过牌后谁会继续/我能否摊牌；只看自己牌型；直接看最后输赢；我不知道。
- 正确层：比较过牌基点、下注后谁继续和完整后续；不是直接选下注或过牌。
- 来源身份：有限价值模型/课程示范。
- 禁止推论：有摊牌赢面不自动代表过牌或下注。

### 卡2：面对下注，先看什么

- 父层：p4 / `compare.bet`
- 题面：**“面对下注时，我能赢其中一部分取值牌。下一步还必须看什么？”**
- 选项：价格、对手下注范围和跟/加后的后续；只看我是不是顶对；只看这次会不会赢；我不知道。
- 正确层：把价值部分与诈唬部分分开，再带入价格和所有合法后继。
- 来源身份：有限防守/价值比较示范。
- 禁止推论：能赢部分取值牌不自动代表跟注或加注。

### 卡3：面对加注，先算新价格

- 父层：p4 / `compare.raise`
- 题面：**“加注后，我还要补多少？跟完以后能争多少池？”**
- 示例账本：当前模型的再加节点需要补 `60`，跟后价格写成 `60 / 201`；学习者只需正确摆出待补和跟后池。
- 正确层：区分已投入、加到的总额、还需补和跟后池；不能把前街投入再算一次。
- 来源身份：有限防守树金额事实。
- 禁止推论：价格公式本身不决定策略。

### 卡4：对手回应后，账本怎样更新

- 父层：p6 / `update.response`
- 题面：**“对手跟完22.05BB以后，池会变成多少？”**
- 示例答案：在该首手账本中进入 `73.5BB`，然后发转牌；学习者不需要在这里选择下注策略。
- 正确层：把回应、金额、池、后手和下一街接起来。
- 来源身份：账本事实。
- 禁止推论：金额更新正确不代表前一步策略正确。

### 卡5：新牌怎样移除组合

- 父层：p6 / `update.card`
- 题面：**“新牌发出后，先划掉哪一类组合？”**
- 选项：含有新公共牌实体的冲突组合；所有弱牌；所有没有改善的牌；我不知道。
- 正确层：只划掉实体冲突，保留前序动作筛选和原有质量；再回到当前动作。
- 来源身份：转牌物理事实。
- 禁止推论：新牌移除组合不等于对手主动弃牌，也不自动生成下注动作。

## 3. 统一答后模板

```text
你答的是：<选项>
这一题只检查：<事实/关系/金额/账本/实体过滤>
它改变了：<一个字段>
它没有证明：<禁止推论>
现在回到：<父帧>
下一步只看：<一个后继>
```

题目来源不足时，模板中的“没有证明”必须出现；系统不能用一个绿色按钮掩盖资料身份。
