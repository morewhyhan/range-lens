# 学习者一页慢想运行卡

2026年10月21日。这是给第一次学习的人看的固定运行卡。它把后台的路线、范围、策略和覆盖合同压成同一套顺序。用户不需要记住35个单元名称，也不需要先背一套口诀；每次卡住，都从第1格重新定位。

## 先记住一句话

```text
先看清现在 → 再看牌和范围 → 比较能做什么 → 执行金额 → 更新以后再来
```

如果不知道答案，不要跳过前面的格子，也不要凭“这手牌看起来很强／很湿”直接点按钮。

## 七格运行卡

### 1. 现在发生了什么？

看小桌和行动历史，回答：

- 现在轮到谁？
- 我是自己要行动，还是在观察对手回应？
- 前面发生了开池、3bet、下注、跟注、加注还是过牌？
- 底池、已经投入、本街待补和有效后手是多少？

如果这里答不出，先不要读牌或看策略。回到桌面、位置和历史子层。

### 2. 牌面和自己的牌是什么？

按最佳五张从七张牌里重新组合：

- 当前是高牌、一对、两对、三条、顺子、同花、葫芦、四条还是同花顺？
- 自己是领先、落后、接近平分还是暂时无法判断？
- 有直接听牌、后门听牌、改善牌，还是没有未来补牌？
- 哪些补牌只是变成更好看的牌，仍然可能输？

“有听牌”只说明牌面事实，不直接说明该下注、跟注或加注。

### 3. 谁的范围留下了什么？

先看行动前范围，再看已知底牌和公共牌造成的物理移除，最后才看行动筛选：

- 谁的范围更强、更宽或更集中？
- 哪些具体组合因自己底牌或新公共牌离开？
- 哪些组合是因为对手这次行动才降低权重？
- 这张阻挡牌改变了谁的继续组合，还是只改变了物理可能性？

如果只有一张静态图，没有动作后范围或回应依据，只能把这一步当作事实或示范，不猜策略。

### 4. 现在有哪些合法选择？

把真实按钮摆出来：过牌、下注、跟注、加注、弃牌或全下。再问：

- 这个按钮是否合法？
- 下注是相对当前底池还是固定金额？
- 跟注需要补多少，跟后底池是多少？
- 选了它以后，对手还能做什么，下一张牌或下一行动在哪里？

不能用“默认小注”“默认跟注”替代当前声明的动作菜单。

### 5. 比较当前动作

先说明每个动作想改变什么：

- 过牌：不投入，保留哪些对手弱牌，允许什么后续；
- 下注：哪些更差牌会付钱，哪些更好牌会退出，自己失败时损失多少；
- 跟注：价格是多少，能赢哪些真实组合，未来还会承受什么；
- 加注：对手哪些牌会弃、跟、再加，自己的后手和未来是否改变；
- 弃牌：放弃什么收益，避免什么更大损失。

动作答案必须使用当前课程政策或匹配参考。若资料没有给出完整回应，解析应说“这里还缺什么”，而不是把某个牌型自动改成唯一动作。

### 6. 执行并交接

点按钮前最后核对：

- 要投入多少？
- 底池和后手怎样变化？
- 行动权交给谁？
- 本街是否结束、是否重开、是否已经全下？

金额算错时，先修账本，不重新讲一遍阻挡或牌力。自己全下后仍可能等待对手回应，不能直接进入摊牌。

### 7. 更新并回到第一格

动作、新回应或新公共牌出现后，回到第1格：

- 历史增加了什么？
- 哪些范围组合按物理或行动离开？
- 新牌改变了牌力、听牌、阻挡、价格还是未来机会？
- 现在下一步是自己行动、观察对手，还是结算？

河牌只是关闭未来补牌，不会自动关闭当前行动。结算结果也不能倒推当时的首答。

## 卡住时的固定回退

```text
不知道按钮        → 回到第1格，看行动者和历史
牌型说不清        → 回到第2格，重拼最佳五张
不知道谁更强      → 回到第3格，看双方范围和物理移除
不知道跟不跟      → 回到第4—5格，算价格并列出回应
金额不对          → 回到第6格，重摆已投、待补和后手
新牌后混乱        → 回到第7格，先更新再重新看第1格
资料不够          → 停在事实／示范层，不替作者猜策略
```

## 这张卡不提供的东西

它不把“高牌下注”“有听牌就跟”“阻挡牌就诈唬”变成通用口诀，也不直接给出所有牌面的GTO动作。它只保证用户在慢想时不会丢失顺序；真正动作仍需当前已开放的课程政策或匹配参考。
