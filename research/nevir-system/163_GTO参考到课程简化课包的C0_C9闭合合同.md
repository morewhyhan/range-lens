## 这份合同为什么必要

已有文档分别规定了求解器能力、参考质量、课程简化、范围变化和教学帧，但一个单元要真正发布，必须把这些依赖按固定顺序串起来。否则容易出现：有一张求解图就直接出题、有一个课程动作就写成GTO、有一张范围图就假定后继完整。

163号合同把每个练习单元压成一条 `C0→C9` 编译链。任何一环失败，节点只能降级为事实、示范或停止，不允许跨级发布。

## 一、C0—C9 编译链

| 阶段 | 作者侧必须完成什么 | 生成什么 | 缺失时身份 |
|---|---|---|---|
| C0 身份 | 固定位置、六人桌、100BB、街次、历史、底池、后手、抽水、来源提交 | `inputFingerprint` | `not_open` |
| C1 物理事实 | 核对牌张、最佳五张、合法跑牌、金额和实体组合 | `factSnapshot` | `fact_only` |
| C2 参考求解 | 用固定范围和行动树得到逐手策略、EV、到达质量和后继 | `referenceSnapshot` | `demonstration` |
| C3 参考质量 | 核对输入、收敛、动作菜单、终局账本、范围分母和可重载性 | `referenceQuality` | `reference_pending` |
| C4 课程政策 | 明确保留动作、删除动作、频率量化、适用边界和理由 | `coursePolicy` | `demonstration` |
| C5 差异评估 | 在同一输入下比较参考与课程的动作、EV、范围和支持组合 | `differenceLedger` | `policy_pending` |
| C6 后继闭合 | 为每个正支持动作、新牌、回应和终局建立真实后继或停止原因 | `successorGraph` | `stop_at_current_node` |
| C7 教学编译 | 将结果变成父帧、一个问题、一个动作、解析、错误层和返回点 | `lessonFrames` | `guided_only` |
| C8 迁移编译 | 只改变一个字段生成未见题，并保留相同父帧和判分身份 | `heldoutTransfer` | `no_independent_release` |
| C9 发布审计 | 检查来源、策略、范围、后继、课包结构、试读状态和版本指纹 | `releaseDecision` | `blocked` |

只有 C0—C9 全部通过，才允许 `reference_policy_practice`。C1 可独立开放读牌和合法性；C2—C6 不完整时可以做作者示范，但不得让用户承担精确策略的责任。

## 二、输入指纹必须先锁定

一个参考策略只能在同一组输入下参与课程编译。指纹至少包括：

```text
tableSize / effectiveStack / rake
heroSeat / villainSeats / activePlayers
street / board / actionHistory
pot / invested / toCall / stack
heroRange / villainRange / deadCards
allowedActions / betSizes / allInRule
solverCommit / solverConfig / outputHash
```

任何字段改变都新建配置，不覆盖旧快照。课程只改变展示或政策时，要标记哪些字段保持不变；改变动作菜单、后继或范围时，必须重新计算受影响祖先。

## 三、课程简化怎样证明自己没有偷换问题

课程简化必须是显式政策，而不是在 UI 中重新命名。每项变换记录：

```text
policyId
baseReferenceId
changedActions / changedSizes / quantizationRule
affectedNodes / affectedAncestors
courseActionByHand
courseRangeAfter
courseEV
referenceEV
deltaSummary
boundaryAndStopReason
```

频率从混合压成 0/50/100 时，至少保存逐手差异、动作后范围差和受影响祖先EV。删掉一个下注尺寸时，必须重新求或重新评估后继；不能继续沿用原参考的上游选择。增加边缘牌训练比例只改变曝光顺序，不能改变策略权重和判分分母。

## 四、范围图在编译链中的身份

同一单元至少保存四个快照：

1. `rangeBefore`：当前动作前，经过物理过滤的范围；
2. `referenceAfter`：完整参考按该动作筛选后的范围；
3. `courseAfter`：课程政策按同一动作筛选后的范围；
4. `successorRange`：进入真实后继后重新条件化的范围。

每个快照都使用同一13×13坐标、同一分母和逐手组合质量。图上必须分开标注：物理不可能、行动筛选、相对占比变化和资料未知。没有 `referenceAfter` 不能声称参考差异；没有 `successorRange` 不能继续生成连续路线。

## 五、课包怎样回到用户的嵌套路线

C7不产生新菜单，而是把一个已闭合单元挂回当前父帧：

```text
父帧输入
  → 一个白话问题
  → 一个主要动作
  → 课程答案
  → 一个最小原因或范围变化
  → 返回父帧
  → 同父帧单变量迁移
```

参考原始数据、差异账本和求解器参数放在作者侧抽屉；用户只在当前步骤按需看到一个事实、一个对照或一个停止原因。关闭子层后恢复原牌面、历史、账本、首答和返回点。

## 六、C9 发布审计的不可替代证据

C9必须逐项确认：

- 输入指纹和参考提交可复现；
- 物理事实通过独立核对；
- 参考策略和课程政策分开保存；
- 简化差异有动作、EV、范围和边界记录；
- 所有继续动作和新牌都有后继或明确停止；
- 题面只有一个问题和一个主要动作；
- 错误回到最近缺失层，重答不覆盖首答；
- 单变量未见题和迁移判分身份已经固定；
- 资料缺失、许可证或运行资源问题没有被隐藏；
- 真人试读状态和目标级证据状态没有被夸大。

没有这些证据时，发布器应保留节点但降低身份，而不是删除节点或补一个看起来合理的答案。

## 七、和最终目标的关系

C0—C9闭合只能证明某个单元具备进入训练器的研究和编译条件。它还不能证明低基础用户已经学会，更不能单独证明NL50准备度。目标级标准仍需要一遍结构、慢速单步、单变量迁移、连续三街、冻结目标配置和独立复核全部通过。

当前完整 A72 参考、35项课程政策、连续后继和真人试读仍未闭合；因此本合同现在是发布边界和研究顺序，而不是已完成课包。
