# 首手18帧覆盖审计与范围交接补位

## 1. 审计结论

现有首手结构包有18帧，账本、行动顺序、金额、回应和结算都能逐帧走查；但把它映射到正式的p1—p7主线后，发现 **p3“看范围关系”没有独立的首遍帧**。

当前路径实际是：

```text
p1 看清局面
→ p2 读牌和牌力
→ p4 比较当前动作
```

这会让学习者从“我是什么牌”直接跳到“我该做什么”，无法建立“翻前动作如何交给双方起始范围、已知牌如何过滤组合、动作后范围为何变化”的中间结构。范围图即使在后续解析中出现，也不能替代首遍的父步骤。

因此，18帧不能标为完整首遍；必须在S04（读牌）之后、S05（比较动作）之前增加一个独立的范围交接帧。当前只登记补位规格，不修改原18帧候选，也不把它算作已完成。

## 3. 必须补入的p3帧

补位帧的学习者只回答一个事实问题：

> **“翻前动作、公共牌和我的底牌，让双方哪些组合不可能、变少或留下？”**

屏幕必须同时显示：

1. 翻前动作对应的双方起始范围；
2. 公共牌和自己的底牌造成的实体冲突；
3. 同坐标的过滤前/过滤后范围图；
4. 一组可点开的具体组合；
5. 三种明确标签：**不可能**、**动作后变少**、**资料不足**。

这一帧不要求学习者选下注动作，也不从范围优势推出动作。完成标准是指出一组真实组合的变化，并说出它属于物理移除、行动筛选还是尚无资料。

补位帧关闭后必须回到S05的父帧；S05的牌面、历史、金额和首次答案不得改变。若没有匹配的动作后范围，只允许发布为事实/示范帧，不能显示精确策略频率。

## 4. 发布前的硬检查

- p1—p7每个父步骤至少有一个核心首遍帧；
- p3补位帧必须位于p2之后、p4之前；
- 范围图使用固定坐标和明确分母，不能只用颜色；
- 物理移除不能被写成对手主动弃牌；
- 缺少参考时，身份降级为事实/示范并停止精确判分；
- S18迁移题不能被当成18帧主线已经完成的证据；
- 插入补位后必须重新做一次首答、错误回退和单变量迁移检查。
