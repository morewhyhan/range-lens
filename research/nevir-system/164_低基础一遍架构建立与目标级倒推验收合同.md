## 这份合同解决什么

最终要求不是“题目很多”或“用户能跟着点完”，而是低基础用户第一次沿主线走完以后，脑中已经有一张可复述的路线图；以后遇到陌生牌局，即使慢，也能先找到当前层、交出这一层的结果，再把状态交给下一层。这个结果必须和后面的单步、迁移、连续路线以及目标级评估连起来，不能只写在首遍课程里。

164号合同把这个要求固定为一份跨阶段验收：首遍建立哪一张最小脑内地图、页面怎样呈现、每个父步骤怎样交接、怎样证明不是按钮记忆，以及这些证据怎样逐级释放到目标级别评估。

## 一、首遍只建立三张东西

用户在第一次跟练时不需要同时理解全部求解器资料，只需要形成三个互相连接的对象：

| 对象 | 用户能说出的白话 | 后台必须留下 | 后续用途 |
|---|---|---|---|
| 路线地图 | “先定位，再读牌，再看范围，再比较，再执行，再更新，最后收口” | `routeNode`、`nextNode`、`returnNode` | 找到下一步和错误回退 |
| 当前帧 | “我现在正在处理这一层的什么问题” | `visibleInputs`、`question`、`requiredOutput` | 只显示本层必要资料 |
| 变化箭头 | “我这一步改变了什么，交给谁” | `changedField`、`handoffPayload`、`successorOrStop` | 接住新牌、回应、金额和范围 |

如果用户只能说出按钮名称，不能说出这三张东西，首遍只算跟随完成，不算形成结构。

## 二、用户实际看到的唯一主线

页面只呈现一条规范学习者路线和一个当前父帧：

```text
L0 桌面与目标
 → L1 位置与前序
 → L2 翻前图表坐标
 → L3 翻前动作确认
 → L4 起始范围交接
 → p1 局面定位
 → p2 牌面与手牌
 → p3 范围与阻挡
 → p4 比较当前动作
 → p5 执行金额与行动权
 → p6 按回应或新牌更新
 → p7 收口与下一入口
 → 回放与单变量迁移
```

翻后局面内部顺序执行：

```text
p1 局面 → p2 牌面与手牌 → p3 范围 → p4 比较
→ p5 执行 → p6 更新 → p7 收口
```

35个后台单元只能嵌入 `p4` 或 `p6` 的当前父帧；打开一个子单元后，父帧保持可见，完成后回到同一父帧。任何子单元都不能从首页平铺，也不能通过跳过父步骤直接进入。旧材料使用的 `L5—L8` 只保留为作者侧宏观审计别名，不是第二套学习者导航。

## 三、每个父步骤的最小可复述交接

首遍中每个父步骤只要求一个白话问题、一个主要动作和一个交接结果：

| 父步骤 | 白话问题 | 一个主要动作 | 交给下一步的结果 |
|---|---|---|---|
| p1 局面 | 现在谁行动，前面发生了什么，要付多少？ | 指出行动者和价格 | `contextFrame` |
| p2 牌面与手牌 | 我的最佳五张是什么，牌力和改善牌是什么？ | 点出最佳五张 | `handFrame` |
| p3 范围 | 哪些组合不可能，哪些是行动留下的？ | 看同坐标前后图 | `rangeFrame` |
| p4 比较 | 现在有哪些有依据的选择，价格和目的是什么？ | 选择动作身份 | `decisionFrame` |
| p5 执行 | 实际点什么，投入多少，谁接着行动？ | 填动作和金额 | `ledgerFrame` |
| p6 更新 | 新牌或回应只改变了哪一项？下一步在哪里？ | 指出变化字段 | `updateFrame` |
| p7 收口 | 结果是什么，刚才是哪一层需要修正？ | 做一次回放 | `reviewFrame` |

每一行的“交给下一步”必须在下一行被读取。字段为空、身份混淆或只点按钮，都不能算该层完成。

## 四、一次通过怎样证明不是记住案例

首遍之后按固定顺序做四个检查，而且都在解析和完整提示之前记录首答：

1. **路线回忆**：隐藏步骤标题，用户能按顺序说出七个翻后层和每层先看什么；
2. **当前定位**：给一个未见父帧，用户能指出此刻属于哪一层和下一步接什么；
3. **断点恢复**：故意让一个交接字段错误，用户能回到最近缺失层并恢复原父帧；
4. **单变量迁移**：只改牌面、位置、价格、回应或新牌中的一个字段，用户先指出受影响层，再完成同类交接。

“解析后答对”“记住某张牌的下注按钮”“能说出结果但不能交接状态”都不能替代这四项证据。

## 五、复杂度必须按顺序增加

训练器只一次增加一种复杂度：

```text
路线长度
 → 父子深度
 → 单一事实变化
 → 新牌或回应的后继
 → 动作和尺寸空间
 → 多街连续性
 → 未曝光目标评估
```

第一次练新牌时不能同时更换位置、前序、价格和范围；第一次接入下注策略时不能同时要求用户理解完整混合频率、动作后范围和河牌后继。这样错误才有唯一归因层，用户才知道下一次先检查什么。

## 六、从首遍到目标级别的释放梯度

| 释放级别 | 学习者真正能做什么 | 允许打开什么 | 不能宣称什么 |
|---|---|---|---|
| A0 路线跟随 | 沿父子路线走完一手 | 首遍代表题 | 已建立结构 |
| A1 结构回忆 | 复述顺序、交接和回退 | 隐藏标题回放 | 会选策略 |
| A2 慢速单步 | 在资料充分节点完成事实、动作、金额和后继 | 同父帧练习 | 会走连续路线 |
| A3 单变量迁移 | 先定位受影响层，再完成同类判断 | 相邻未见题 | 已达到目标级别 |
| A4 连续三街 | 保留范围、账本、行动权和后继直到河牌 | 冻结配置连续题 | NL50准备度 |
| A5 目标评估 | 通过未曝光题包和独立复核 | 真实决策审计 | 长期盈利或必然NL50 |

前一级没有证据，后一级不开放。所有级别都可以慢，但不能跳层、用结果倒推动作或把未知资料当成默认答案。

## 七、页面的最小结构

为了同时满足“看得懂”和“每步不漏”，页面固定只有五个区域：

1. **路线条**：只显示当前节点、上一节点和下一节点；
2. **当前父帧**：一张桌面、一组牌、一个问题、一个主要动作；
3. **按需子层**：一张图、一笔账本或一个停止原因，关闭后恢复父帧；
4. **交接卡**：把本层唯一变化和下一入口写成一句白话；
5. **停止卡**：资料不足时说明缺什么、为什么不能继续，不给猜出来的答案。

作者侧的求解器参数、参考范围、差异账本和证据等级放在抽屉中，不成为首遍用户的第二套菜单。

这一页结构还必须服从[低理解门槛与认知负荷合同](low-cognitive-load-contract.json)：首遍默认使用普通话加练习语言，每屏只引入一个未掌握概念，技术词不能成为唯一线索，文字说的变化必须在牌、图、金额或返回点上可见。路线清楚但用户听不懂，仍不能算首遍结构通过。

## 八、与目标标准的关系和当前边界

这份合同把“跟一次就知道大概怎样思考”具体化为可观察的路线回忆、层定位、交接、错误恢复和单变量迁移；它还规定了怎样逐级走向连续路线和目标评估。但合同本身仍是纸面规格，不能替代真实页面、匹配参考、低基础试读、未见迁移、连续三街和独立目标审计。

当前必须保持以下状态：`runtimeImplemented=false`、`beginnerTrial=false`、`matchedA72Reference=false`、`completeSuccessorChain=false`、`NL50Evidence=false`。只有这些证据真正出现后，才可以讨论是否达到用户设定的目标水平。
