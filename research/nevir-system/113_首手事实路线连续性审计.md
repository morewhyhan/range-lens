# 113｜首手事实路线连续性审计

现在把首遍19帧候选真正当作一条路线来检查。这里检查的是事实和示范层的连续性：帧有没有断、父步骤有没有漏、题目和答案是否匹配、金额是否接得上、p3范围帧是否插在正确位置。它不把这条路线升级成完整策略课包。

## 审计结果

- 原始18帧全部存在，另有R01一个p3事实帧，总计19帧；
- p1—p7七个父步骤都有至少一个锚点；
- R01位于S04读牌之后、S05动作比较之前；
- 原始18帧都有状态、题目、视角、答案和解析；
- 原始题目全部明确为事实/示范，未将任何一题标成独立策略判分；
- 4个关键下注/跟注金额转移通过独立守恒检查：21→25.2、25.2→29.4、29.4→51.45、51.45→73.5；
- R01明确停在“缺少行动筛选和固定分母参考”，不会自动进入动作答案。

## 这条路线在用户眼里怎样运行

```text
先找到自己和行动线
→ 执行给定的翻前金额
→ 翻牌先找行动者
→ 拼出自己的牌力
→ 先看一组物理上不可能的组合
→ 再进入过牌/下注的比较
→ 执行金额并等待回应
→ 新牌或回应后保留旧信息并更新
→ 河牌结算、区分结果和决策
→ 换一手短局面找下一层
```

R01的作用是补上“牌力→范围”的交接：学习者先看到Ac已经在自己手里，所以对手不可能拿AcKc；但这不等于对手因为某个动作主动放弃了某组牌。看完R01后回到S05，继续练当前比较，不跳到未经参考支持的下注答案。

## 当前能证明什么

这份审计证明首手候选在事实/示范层已经可以被机器复核为一条连续路线。它证明的是：

- 顺序可以从翻前走到结算；
- 父帧之间有明确的交接字段；
- 金额和行动顺序不会因为插入p3而跳变；
- 资料不足时能停在正确位置。

它不能证明：

- S05、S09、S13等动作比较已经有完整匹配策略；
- R01已经拥有行动后的完整范围；
- 19帧已经通过真实低基础学习者试读；
- 学习者已经建立迁移能力或具备NL50水平。
