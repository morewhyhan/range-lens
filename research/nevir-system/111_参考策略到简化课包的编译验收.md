# 111｜参考策略到简化课包的编译验收

这份合同回答一个核心问题：有了求解器输出以后，怎样才不会直接把一张策略图变成一堆题，而是把“参考策略、用户要练的简化、可理解的教学路径”三者接起来。

## 编译器的真实职责

编译器不是重新发明GTO，也不是让学习者在浏览器里临时跑求解器。它做的是把作者侧研究结果整理成一个带版本指纹的静态课包：

```text
来源与配置
→ 物理事实核对
→ 匹配参考策略
→ 课程简化政策
→ 参考/简化差异
→ 行动后范围与后继
→ 嵌套教学帧
→ 未见迁移题
→ 发布身份
```

任何一层失败，都只能降级或停止。不能因为求解器文件存在，就跳过课程政策；也不能因为课程写了一个动作，就把它写成参考频率。

## 每一层对学习者有什么影响

| 编译阶段 | 学习者最终看到什么 | 缺失时怎样处理 |
|---|---|---|
| 身份 | 位置、前序、牌面、底池、后手、抽水和当前行动者 | 不开放题目 |
| 物理事实 | 最佳五张、牌型、补牌、合法金额和账本 | 只能练事实 |
| 参考策略 | 某动作对哪些组合、以什么频率、留下什么后继 | 不能精确判策略 |
| 课程政策 | 课程要求执行的动作、尺寸和原因 | 只能示范或关闭 |
| 差异 | 课程与参考在哪些牌、动作、EV和后继上不同 | 解析中标明边界 |
| 范围更新 | 同一坐标的动作前后图、固定分母和组合变化 | 无范围后继就停止 |
| 教学帧 | 当前一个问题、一个主按钮、错误层和返回点 | 不平铺、不跳层 |
| 迁移 | 只改变一个字段的未见题 | 无已验证原理就不生成 |

## 范围变化必须怎样计算

行动前每个实体组合的质量先经过物理过滤：自己的底牌、公共牌和已知死牌会划掉不可能组合。之后才应用行动频率：

```text
before(h) = entityWeight(h) × physicalFilter(h)
after(h,a) = before(h) × P(a | h, node)
view(h,a) = after(h,a) ÷ Σ after(h,a)
```

课程政策和参考策略必须分别计算：

```text
courseAfter(h,a) = before(h) × CoursePolicy(a | h)
referenceAfter(h,a) = before(h) × ReferencePolicy(a | h)
delta(h,a) = courseAfter(h,a) − referenceAfter(h,a)
```

训练时可以提高边缘牌比例，但不能改变这些权重。图上必须同时标明范围拥有者、观察视角、固定分母，以及这是物理移除还是行动筛选。否则学习者会把“我拿走一张牌”误解成“对手主动弃掉一组牌”。

## 简化允许做什么

允许把复杂参考压成易执行的课程政策，但每次变换都要留下差异报告：

- 把混合频率量化成0/50/100：要保存逐手差异、根EV差异和边缘组合；
- 删除不教学的下注尺寸：要重新计算受影响祖先和后继；
- 把复杂解释放入子层：不得改变答案身份、父帧和返回点；
- 提高边缘牌抽题比例：不得改变策略评估权重。

课程简化只在声明的配置和边界内成立。它不是把所有牌面、位置和回应压成一句口诀。

## 题目怎样从编译结果生成

题目顺序固定为：

```text
定位 → 关系 → 执行 → 动作后更新 → 单变量迁移 → 回到整手路线
```

每道题只公开一个主要问题。答案身份在后台标为 `fact`、`demonstration`、`course_rule`、`reference_frequency` 或 `reference_policy`；公开题面不显示身份和答案。缺少参考时，系统只能让学习者识别事实、跟看示范或执行已有课程规则，不能判一个编造的精确策略。

## 发布闸门

一个单元要进入独立策略练习，至少要同时拥有：

1. 匹配输入和版本指纹；
2. 物理事实交叉核对；
3. 参考策略的逐手动作、EV、动作后范围和后继；
4. 课程政策及其差异报告；
5. 一屏一个问题、错误回退和父帧恢复；
6. 一个只改变单一字段的未见迁移；
7. 明确的低基础试读状态。

缺一项就降级身份，并显示停止原因。这里的“停止”是正确的课程行为：它保护学习者不把未知学成错误规则。
