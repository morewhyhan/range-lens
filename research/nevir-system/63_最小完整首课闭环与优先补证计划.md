# 最小完整首课闭环与优先补证计划

2026年10月21日。本文件把前面的大量规格收束成一条真正值得先做完的首课闭环。它不缩小最终目标，也不把一条示范路线冒充完整课程；它规定先用一个来源明确、范围可复算、翻后三街可闭合的候选，完成从参考到课包、试读和修订的全过程，再按同一协议扩展角色、位置和牌面。

## 1. 为什么先做一个闭环

继续增加孤立牌面和局部模型，无法证明以下链条能真正闭合：

~~~text
翻前图表
→ 双方实体起始范围
→ 翻牌参考策略
→ 行动后范围
→ 转牌新牌与回应
→ 河牌后继与结算
→ 课程简化
→ 顺序课包
→ 低基础用户试读
~~~

先完成一条闭环的目的，是暴露接口、范围、后继、视觉和教学问题；闭环本身不是NL50资格，也不能替代其它角色和位置的覆盖。

## 4. 每一门实际要保存什么

### C0—C1：输入与起始范围

保存 ReferenceSpec、翻前来源图、动作历史、双方范围所有者、逐实体组合、原始权重、已知牌和联合合法底牌质量。普通中图的格子频率不能直接当作现实玩家真实频率；必须标明它是用户课程政策输入。

### C2—C5：参考与后继

保存原始求解器输出，不先舍入成页面颜色。每个行动节点保存：当前行动者、逐手动作频率、EV、到达质量、下一动作和正支持新牌。每个后继都要能重放金额、范围筛选和终局；缺少后继就标停止，不默认对手弃牌或过牌。

### C6：课程政策

保存参考政策和课程政策两份指纹。若把多个尺寸压成一个按钮、把混合压成0／50／100或删掉再加，重新计算当前节点和所有受影响祖先。报告动作差、EV差、范围差和后继缺口，不能只看总体下注率。

### C7—C8：课包与独立校验

课包主线沿规范L0—L4→p1—p7，翻前和翻后都挂到同一父子结构；L0—L8只保留为作者覆盖映射。每帧只出现一个问题；范围图保持13×13；解析区标明事实、课程政策或参考策略。独立校验用不依赖求解器内部结果的牌力、组合和账本程序复算。

### C9：低基础试读

主持者不提前告诉用户当前考什么。先走翻前和起始范围，再走翻后整手，随后收起步骤名和答案颜色，最后换一个只改变一个字段的局面。记录用户何时找不到下一层、何时混淆物理移除和行动筛选、何时把示范动作当成策略答案。修订只改一个变量，再用未曝光实例复测。

## 5. 首课发布身份

首课只能使用以下身份之一：

- starting_range_fact：只证明翻前图如何形成实体起始范围；
- postflop_demonstration：参考或课程政策不足以判精确策略，但可以顺序示范；
- course_policy_practice：明确声明采用的简化规则，按课程政策判分；
- matched_strategy_practice：C0—C8和参考差异报告均通过，才可判精确策略。

若C9试读未完成，可以发布作者内部示范或试读版本，但不能宣称“低基础用户已经学会”。若C2—C5不完整，不能使用matched_strategy_practice。

## 6. 扩展顺序

首课闭环后按以下顺序扩展，始终回到同一套合同：

1. 同一配置的相邻牌面和一个动作保持对照；
2. 同一位置的不同前序和行动回应；
3. 翻前跟注者角色和盲位防守者角色；
4. 其它位置、SRP／3bet和IP／OOP组合；
5. 更多下注尺寸、加注和全下后继；
6. 未见连续路线和目标配置外部对标。

每一步扩展都要重新取得参考、编译政策、生成范围图并试读；不能把A72首课复制到其它角色后只换标题。
