# 逐街、角色与行动分支完整覆盖矩阵

2026年10月21日。本合同把“每个地方、每个步骤都不落下”变成覆盖账。它不把资料中已经出现的主动方例子扩大成全部牌局，而是按翻前、翻牌、转牌、河牌、结算，结合翻前最后加注者、翻前跟注者、盲位防守者和当前行动角色，逐格登记可开放身份与缺口。

## 1. 覆盖的五个轴

任何精确策略题都必须绑定以下五个轴；缺一个轴，只能降级为事实或示范：

1. **街次**：翻前、翻牌、转牌、河牌、结算；
2. **翻前角色**：最后加注者、翻前跟注者、大盲防守者或不适用；
3. **相对位置**：有位置、无位置、盲对盲或其它已声明关系；
4. **当前决策**：无人下注、面对下注、面对加注、面对全下、终局；
5. **输入身份**：位置、前序、底池、有效筹码、抽水、范围版本、行动菜单和参考版本。

“现在在OOP面对下注”不能替代“翻前是谁加注、对手从哪条范围进入、下注金额是多少”。当前行动者和翻前角色必须从完整历史独立读取。

## 2. 每条完整路线必须覆盖什么

| 街次 | 用户必须看到的连续关系 | 最小可判材料 | 缺材料时的正确行为 |
|---|---|---|---|
| 翻前 | 场景→图表→格子→动作→起始范围 | 来源图、169格、动作精度、实体组合、快照 | 只开放翻前表或起始范围事实 |
| 翻牌 | 前序继承→读牌→范围→比较→执行→回应→更新 | 双方范围、动作菜单、后继、新牌条件 | 进入示范，不能给唯一策略答案 |
| 转牌 | 保留翻牌行动→新牌→双方范围改变→当前动作 | 行动后范围、条件新牌分布、金额和后续 | 只教新牌与范围物理变化 |
| 河牌 | 关闭未来改善→当前胜负／价格→行动／回应 | 完整河牌范围、动作和回应、终点账本 | 只教牌力、价格或给定路线 |
| 结算 | 弃牌／摊牌→金额→错误层→回到路线 | 终局规则、退款、最佳五张、首答状态 | 只做事实结算，不倒推策略 |

每一街都要有“自己行动”“观察对手回应”“新牌或终局”的分支。没有实际回应或后继，不能把一条作者选择的线路称为连续整手策略。

## 3. 当前角色覆盖账

现有资料的角色账不能用题目数量代替：

| 角色审查范围 | 当前登记 | 可以说明什么 | 不能说明什么 |
|---|---:|---|---|
| 原粗场景格 | 48 | 旧分类的检查范围 | 不是完整策略覆盖 |
| 加入翻前角色后 | 96 | 角色与街次／位置组合的审查空间 | 不是已有96套课 |
| 现有混合题 | 85 | 可局部执行的作者模型题 | 不是85个独立策略机制 |
| 翻前最后加注者题 | 85 | 当前题包主要视角 | 不能代替翻前跟注者 |
| 翻前跟注者题 | 0 | 这是明确缺口 | 不得从对手回应反推完整政策 |
| 有局部模型的角色格 | 6 | 少量父层有作者模型 | 不能计算为6／96完成 |
| 完整目标策略格 | 0 | 当前没有通过的目标格 | 不能开放NL50精确课 |

对手在当前街的跟注、过牌或加注是一个观察到的回应，不等于它拥有完整可判的翻前跟注者策略。角色字段必须一直跟随父帧和范围所有者。

## 4. 逐街开放闸门

### 4.1 翻前

翻前可按已有15张图开放场景定位、169格读图、纯格／混合格精确动作、边缘与内部比较、位置和大盲画像迁移。进入翻后前必须生成来源明确的实体起始范围；不能由一张图补出用户没有提供的跟注、挤压或4bet策略。

### 4.2 翻牌

翻牌至少需要四个父层：牌面与最佳五张、行动前范围、当前方案比较、动作后回应。对于最后加注者和翻前跟注者分别登记；一方有参考时，另一方若只是固定作者回应，不开放另一方的最佳策略题。

### 4.3 转牌

转牌必须继承翻牌的实际历史和行动后范围。新牌按合法联合底牌质量发出，不能把所有未知牌当作等概率，也不能把“物理移除”写成“对手主动弃牌”。如果只知道新牌怎样改变牌力，不知道随后下注回应，就停在更新事实层。

### 4.4 河牌

河牌关闭未来补牌理由，但不自动关闭行动。要分别覆盖无人下注、面对下注、面对加注和全下等待回应；河牌动作后要有弃牌、跟注摊牌、加注后继续或缺资料停止等终点。任何来自静态原图的整体比例都不能直接替代具体底牌策略。

### 4.5 结算与回看

结算只使用行动前可见信息判断当时决策，摊牌结果放在回看层。金额、已投入、未匹配弃牌款、平分和最佳五张由独立规则复核；用户赢了不改写首答错误，用户输了也不改写首答正确。

## 5. 覆盖矩阵的一格要交付什么

一个矩阵格只有在以下内容都齐时，才可以标为 `reference_policy_ready`：

- 角色、位置关系、街次、当前决策和完整前序；
- 双方实体起始范围、行动后范围和分母；
- 物理合法牌、公共牌移除和联合到达权重；
- 合法动作菜单、下注金额、抽水和有效后手；
- 当前动作频率、EV、并列／误差身份；
- 每个正支持动作的后继新牌、回应和终点；
- 行动前后范围图及变化类别；
- 示范、引导、独立题和至少一个相邻迁移位；
- 答错、我不知道、资料不足和返回父帧的处理。

缺任一项时，格子应标 `fact`、`demonstration`、`course_policy` 或 `not_open`，并记录下一项补证任务。不能用同一位置的另一街、另一角色或另一范围版本填空。

## 6. 如何检查“没有漏步骤”

发布前按以下顺序走每个适用格：

```text
翻前身份
→ 当前行动者与历史
→ 牌面与最佳五张
→ 范围前状态
→ 当前方案比较
→ 精确执行与金额
→ 观察回应／新牌
→ 范围后状态
→ 下一步行动者
→ 终局与错误层
```

若某格在其中一处跳过，系统应显示“此处没有闭合数据”，而不是自动进入下一街。作者可单独发布一段示范，但必须保留停止位置和缺项，不把顺畅播放误认为完整覆盖。

## 7. 当前结论

覆盖矩阵已经把“资料中有什么”与“目标需要什么”分开：当前主要有翻前图表事实和最后加注者局部模型，翻前跟注者、完整翻后响应、完整多街后继和目标级参考仍有大面积缺口。补文档不会把这些缺口变成已完成；它只确保未来取得参考后，能够按同一矩阵补入路线，而不再平铺或漏掉角色。
