# 127｜首课发布闭合审计与停止清单

2026年10月22日。本审计把A72候选首课的C0—C9发布门逐项读取，明确当前已准备、仅有事实、缺参考、未编译和未试读的区别。它的作用是阻止局部结果被误称为完整翻后策略课。

## 1. 发布身份只有四种

| 身份 | 可以教什么 | 不能教什么 |
|---|---|---|
| `starting_range_fact` | 翻前图表坐标、实体组合、撞牌和起始范围事实 | 翻后动作后范围 |
| `postflop_demonstration` | 有明确来源的流程、账本或固定示范 | 匹配GTO精确动作 |
| `course_policy_practice` | 已声明、可复核的课程简化规则 | 把规则说成原始GTO频率 |
| `matched_strategy_practice` | 同配置下完整参考和课程差异后的精确练习 | 目标配置以外的能力保证 |

只有C0—C8闭合、参考和课程政策分开、后继完整、独立复核通过，才允许第四种身份。C9试读未完成时，仍不能声称低基础用户已经学会。

## 2. A72当前逐门状态

| 门 | 当前状态 | 允许打开 | 必须停止 |
|---|---|---|---|
| C0 配置冻结 | 已准备但引擎版本和适配器仍缺 | 继续做输入预检 | 精确参考 |
| C1 翻前快照 | 有独立事实候选，重算和重载匹配仍缺 | 起始范围事实 | 翻后策略 |
| C2 翻牌参考 | 未取得逐手频率、EV、到达质量和后继 | 事实／示范 | 精确动作 |
| C3 动作后范围 | 只有合同，没有动作条件数据 | 物理过滤 | 行动后范围 |
| C4 转牌后继 | 只有物理发牌结构 | 已闭合事实分支 | 连续转牌策略 |
| C5 河牌与终局 | 只有账本合同 | 账本示范 | 连续三街策略 |
| C6 政策编译 | 编译管线尚未实现 | 课程来源说明 | 简化损失结论 |
| C7 课包编译 | 有纸面路线，未形成静态课包 | 作者示范候选 | 发布课包 |
| C8 独立验收 | 局部事实和账本通过，完整课包未验收 | 纸面审查 | 精确策略课 |
| C9 低基础试读 | 试读包已冻结，尚无参与者结果 | 主持准备 | 学会或NL50结论 |

当前因此只能保留“事实候选／纸面示范候选”身份，不能开放 `matched_strategy_practice`。

六个首手补帧的发布身份也受同一组C门控制：I03可在C1事实层开放；I05仍需C1的完整根范围；I07/I08需C2的课程政策或匹配参考；I10需C3的动作后范围；I11需C4的真实后继。机器审计中的`gapFrameDependencies`记录了这条依赖，不能把补帧规格本身视为参考节点已经收到。

## 3. 每一门的停止条件

- C0：配置、动作树、抽水、来源版本或许可证身份改变，整门回到未开放；
- C1：实体组合、撞牌、联合分母或坐标身份不一致，不能进入翻牌策略；
- C2：没有逐手动作、EV、到达质量、收敛和后继，不得把节点总体比例当答案；
- C3：没有动作后逐组合权重和固定分母，不得画成对手弃牌；
- C4：没有条件新牌分母和真实后继，不得把物理跑牌当策略路线；
- C5：没有终局动作、账本守恒和独立结算，不得把结果倒推动作；
- C6：改变菜单、尺寸或量化方式后未重算祖先，课程政策不能发布；
- C7：公开题面含答案、父帧不能恢复或子层平铺，不能进入试读；
- C8：独立复核依赖同一份答案数据，不能称独立；
- C9：没有首答、帮助、重答、迁移和连续记录，不能声称用户掌握。
