# 从题设答案走向实际判断：先学会辨认结论的条件

2026年10月21日。接[统一总纲](../../翻后教学系统_统一总纲.md)和[撤帮助合同](23_怎样检验真的教会了_顺序试读与迁移合同.md)。本轮只补作者研究和纸面教学，不实现界面。对象是基础很弱的成年学习者；最终面向NL50的完整目标没有缩成会做这一个模型。

## 1. 现有设计还缺的一座桥

题目给出精确候选、比例和回应，学习者按公式算出动作，这是必要的中间阶段。但真实对手不会主动告诉他“我有三分之二的77”。如果教学止于这种题，学习者可能只会操作一台输入齐全的计算器，无法解释实际牌局中自己的判断从何而来。

因此每一项动作教学最终都要接三件事：哪些输入已经看到，哪些只是采用的判断；结论依赖哪项判断；这项判断变化到什么程度，动作才会改变。它们嵌在当前“比较选择”里，不另开一套首页课程，也不要求初学者第一次就估计全部频率。

这不能靠一句“多观察对手”补齐。课程作者必须提供匹配配置的基准，注明偏离依据，逐步训练如何从前序和信息更新。当前仍缺这样的完整参考，故本章只先把其中可严格计算的一小段做实，不宣称解决了真实对手范围估计。

## 2. 用已有同一手牌，先看懂一个会翻转的关系

沿[河牌价值逐帧脚本](29_从整手导览到深入一处_逐帧学习脚本.md)到V13：自己9♣9♦，公共牌K♠9♥2♦3♣7♥，先过牌，对手打17.5，自己加到45，对手全下到83。自己剩38，当前池163，跟38后池201。当前只有弃和跟，不再讨论尚未发生的新街。

沿用已有有限模型：对手此支只含K♣K♦和7♣7♦，自己输前者、赢后者，无平分。这里两个实体候选的“权重”是相对可能质量，不是说一副牌中存在十手一模一样的KK。两种以外的牌被本教学模型排除，现实不能默认也排除。

先固定77权重为2，令KK权重为t。这样改变t只改变强端占比，牌、钱、当前合法动作都不变。跟注赢的份额为`2/(t+2)`；从此刻开始的收益为：

`跟注EV＝201×2/(t+2)－38；弃牌EV＝0。`

用已经有的两版核对：KK权重1时，跟注EV为96；权重8时仍为2.2。后者仍较高，却只比弃牌高2.2，不能把“同样应跟”误解为两个判断一样有把握。

相等处是胜出份额`38/201≈18.91%`，或KK权重`t＝163/19≈8.579`。KK再增加，跟注就会低于弃牌。这个边界来自本模型的金额与候选，不是“三条永远跟”的口诀。

## 3. 用户看到的不是一页公式，而是同一张图逐次变化

中央保留原桌面、自己三条9、当前池和38待补。侧边一次只显示一条对手候选质量带：KK和77，各有牌面、文字与相对宽度，不能只用红绿区别。它表达相对可能性，不伪装成实际亮牌。

第一次先给原比例，让学习者点出“我输KK，赢77”。再把同一条带中的KK逐渐加宽，77保持2；下方只显示跟注相对弃牌的收益线，从正数经过0到负数。可以暂停和逐次切换，不用动画速度考眼力。

不要把全部比例、三张带和整棵树同时摊开。当前画面先解决一个问题：“其他都没变，哪一边变多让跟注越来越差？”答后再显示那条18.91%的界线。正式独立题则收掉收益线和正确侧高亮，只保留必要题设。

数字带属于解释工具，用户不必在实际打牌时逐个数十几份筹码。后续要学的是胜出部分与价格的关系，并能调用有依据的范围参考。若没有范围参考，仅有这张图还不能执行现实策略。

## 4. 把“不很确定”细分为三种实际不同的状态

以下区间都是作者为了教学选的假设范围，不是从真实对手数据估计的置信区间。不要把它们称为已知人群分布。

| 题设给定的KK权重范围；77固定2 | 跟注EV的可能范围 | 在这个模型内能说明什么 |
|---|---|---|
| 1至3 | +42.4至+96 | 虽不知精确比例，区间内始终跟更高 |
| 10至12 | 约−9.286至−4.5 | 区间内始终弃更高 |
| 7至10 | −4.5至约+6.667 | 区间跨过边界，不能由这些输入指定唯一的期望收益较高动作 |

这比“只要不确定就弃”更准确：前一行即使不精确也足以选跟。也比“只要是强牌就跟”更准确：第二行相同三条、相同价格，仍应弃。第三行的不足属于作者参考的不足，不能假装由牌型就能补出来。

并且，“区间内始终较高”仅限已声明的两个候选、权重区间、零抽水及这两个当前动作。遗漏其它候选、错误估计区间或实际结算不同，都可能破坏结论。只在一个狭窄输入上稳健，不能升级为对真实未知对手普遍稳健。

## 5. 不能偷加一个看似合理的默认答案

第三行如果有人说“为了保守就弃”，还要追问保守指什么。本轮只在始终弃与始终跟这两条纯选择中作数学对照，不讨论随机混合，也不把任何一个作为实战推荐：

- 若明确要求最大化区间中的最差EV，弃的最差0高于跟的−4.5，会选弃。
- 若明确要求最小化相对于每个实际权重下较高动作的最大损失，跟的最大损失4.5小于弃的约6.667，会选跟。

同一输入、两个明确的准则，产生不同结果。扑克规则没有替我们选择这两个准则，也没有替我们提供各权重出现的概率。不能擅自均匀平均7至10，更不能拿两个端点的平均当“真实对手”。

这些准则只给作者看，初学者默认页面不新增“最大最小”选择题。用户只需在本层理解：有些结论对判断误差不敏感；有些结论依赖一个必须进一步有依据的估计。正式动作训练仍由作者提供已准入的基准，不要求用户靠猜未知输入过关。

这里只选河牌终局跟弃，是为了避免另一个错误：如果不确定的是整个对手模型，分别在每个模型里假装知道真实模型并优化后街，再把这些最优EV平均，通常不等于一条实际可执行策略的收益。前街要在相同可见历史下共享自己的决定，必须重建共同信息下的比较，不能直接搬本章的一行终局公式。

## 6. 嵌回V13的一段具体主持脚本

此段为按需深入，不自动插进首次18帧导览。用户在V13解析点“为什么比例影响跟弃”才进入；父层快照包含原题、原参考、首答和反馈曝光。实际全下已发生，这里只预演范围判断，不扣38、不结算、不提前揭实际KK。

| 停点 | 只问当前一件事 | 怎样接下一步 |
|---|---|---|
| C01 | 我赢77还是KK？ | 直接用最佳五张对照，读错就原位补 |
| C02 | 跟注还补多少，最后池多少？ | 38与201；之前45不重复投入 |
| C03 | KK从1变8，哪些牌和钱没有变？ | 保留同一桌面，只动候选质量带 |
| C04 | 赢的部分变少，跟注收益向哪边走？ | 答后才显示96到2.2的变化 |
| C05 | 精确到不了一个数，但KK确定在1至3，是否仍能比较？ | 展示整个区间在零线上方，说明不必假装全知 |
| C06 | KK改成10至12，同一手牌还总是跟更好吗？ | 展示整个区间在零线下方 |
| C07 | KK是7至10，只凭这项题设能指定唯一较高动作吗？ | 这是明确标注的条件辨别练习，不记作一次扑克动作选择 |
| C08 | 回到原题后，应该使用哪份参考？ | 恢复原V13比例1:2及相应跟注，不保留预演的7至10 |

独立辨别题不得沿用刚展示的1、3、7、10、12原数。后续可以自动生成同一数学关系的新区间，但这种成功只证明学会边界关系，不算新策略情境迁移。真实试读仍需观察：用户能否解释是哪项输入改变，还是只认收益线颜色。

用户选“我不知道”按正常错误解释，可直接继续，不强制补考。条件辨别题如C07必须明确它问的是信息能支持什么结论；普通动作题不得偷偷把“缺资料”设成正确选项，更不能把作者缺口算成学生不懂扑克。

## 7. 回到真实执行，仍须补什么

本段只补“输入改变如何影响结论”，没有凭空取得真实对手的t。完整教学还要有：匹配当前位置与历史的起始参考；行动与牌张怎样筛选候选；有何证据支持偏离；没有偏离证据时采用哪份既定基准；基准不覆盖的节点怎样在出版前关闭。

因此现有范围给定题不能直接标为“已会实际读范围”。下一轮撤帮助，应先保留完整匹配的起始参考和前序回应，让用户自己更新到当前；再比较有明确证据支持的变化。只有取得这些参考才能开放对应的独立动作节点。真实陌生整手、完整策略覆盖与NL50能力仍需另证。

## 8. 本轮已经核对的证据

研究脚本`scripts/research-nevir-assumption-boundaries.mjs`读取原价值树，核对4个来源全下节点的当前基点，重算终局跟弃阈值和三种区间；以期末余额差逐点核对14001个t值，并检查单调方向。结果见[条件边界计算](assumption-boundary-evidence.json)。

14001是同一关系的数值核验数量，不是14001种扑克情境，不是教学效果。C01—C08目前为纸面脚本，没有实现交互图、真人首答或迁移测试。该计算不增加48格覆盖，不填补原整手六处精确策略，也不宣称已保证任何人达到NL50。

## 9. 下一档真正撤掉什么：不再直接给最后的范围比例

只撤掉最后一张答案图，不能撤掉计算所必需的依据。本轮把[两条既有历史](25_同牌面怎样带着位置历史与回应继续判断.md)接成四份纸面题：两条历史各有一份带中间操作的练习，以及一份不提供最终比例的动作题。它们是同一来源族的四种作者题面，不是四个陌生机制，也不是软件新增四个模式。

沿用KK对88、QQ、JT模型，初始相对质量1:2:2。两条历史最终都是河牌T♠8♥3♦2♣4♠、池35、双方83、轮到SB。

- 第一条：翻牌双方过，转牌自己打7、对手跟。按给定两次回应概率留下1:4:1。
- 第二条：翻牌自己打7、对手跟，转牌双方过。按给定两次回应概率留下4:4:1。

题目只给起始三手、真实行动顺序、每次所观察动作在对应手牌及此前历史下的条件概率，以及当前过牌／下注17.5的给定回应。最终比例、动作EV和正确按钮不在题面。双方实际发出的新牌对三手都合法，等概率发牌因子在这次比较中抵消；不能把这个特例推广成任何新牌都不用更新。

### 一条顺序路径，分两次收帮助

| 学习时点 | 看得到什么，亲手做什么 | 怎样解释结果 |
|---|---|---|
| 示范后第一次 | 保留初始候选和两次概率，一次只亮一个已发生动作；填三组还剩的相对质量 | 先学习连续筛选，不强迫背公式 |
| 比例提交后 | 立即告诉范围更新对错，错了在当前那次回应解释 | 符合正常即时解析；不改第一次结果 |
| 接着比较 | 保留刚得到的比例，选过牌或下注17.5 | 这是范围帮助下的动作，不记独立整段 |
| 后面的明确练习 | 给另一条完整历史和必要概率，不直接给最终比例；可以自己算或用计算器 | 第一次动作后立即解析，不等整段结束才反馈 |
| 若还想查更新能力 | 另给一个未曝光的范围更新小题，问比例 | 不从上一道正确动作反推已经会更新 |
| 继续回原牌局 | 恢复原历史、参考和已曝光身份 | 不把另一条历史的比例留在主线 |

两条作者历史在材料中都公开过；后一条在组织顺序上是撤帮助练习，不因此成为冻结的陌生试题。真正未曝光检验须另外编制并保持隔离，不能用刚讲过的B路线宣称已实现迁移。

填比例只是纸面计算原型。后来实际交互可以用候选质量带、加减份额或简洁输入，但要经初学者试读，不能把复杂表单做成学习障碍。本轮没有实现输入框或新界面。必要的起始范围和回应随时可回看；回看题设与查看计算后的正确比例是两种不同帮助。

### 为什么正确按钮还不够

在第一条历史中，正确比例1:4:1支持下注。但把它错算成1:4:2，仍会在这两个给定方案里选下注。因此，只统计最后按钮，无法知道他是会更新，还是碰巧选对。

研究评分明确分开两项：更新依据是否正确，动作是否符合本题参考。若更新错误但动作正确，只能报告这两个事实，不能虚构“必定猜的”或“已经懂了”。若更新正确但动作错，才回到给定响应和方案比较；不能让他继续重复数候选。

相对质量1:4:1、2:8:2、20:80:20以及概率1/6、4/6、1/6表示同一分布，均应接受。不会因为教师偏好整数就判其它等价表示错。不能接受全零、负数、漏候选或把未知自动补成均匀。未填完的草稿不是一次完成的错误回答；明确点“我不知道”才按错误解释。

动作仍按原题正确参考评，不跟着学生填错的比例悄悄改答案。若学生选未比较的下注10，当前参考不覆盖，不能由此罚一次策略错，更不能说下注10违反扑克规则。普通题面只开放支持的按钮。

### 这是范围更新，不是实际读懂未知对手

这一步撤的是“教师已算好的后验”，仍保留作者给定的先验和条件回应；它不解决先验是否适合NL50，也不解决真实玩家的回应如何估计。不能拿这个中间能力代替完整实战目标。

更新链下一步应继承有匹配来源的真实基准，逐步收掉已算好的中间结果。缺起始策略或前序回应的实际节点仍不开放；不能拿本例1:2:2与概率表粘到用户的完整翻前图上，冒充从其范围推导到河牌的策略。

程序还核对了两条历史的当前牌钱完全相同，但互换历史就不能沿用原题教师键；完整题面指纹包含历史、概率和给定回应。首个比较题看过范围答案后，后续动作带帮助身份；原位补教不能把它变成未帮助首答。无需增加数据库或长期记录来表达这个教学区别。

### 本段研究产物及限制

运行`node scripts/research-nevir-range-to-action.mjs`生成[四份题面](range-to-action-prompts.json)、[分离教师键](range-to-action-teacher.json)和[17项作者核对](range-to-action-verification.json)。核对包含连续乘法、归一等价、两条河牌EV、历史混用拦截、未知、域外金额、草稿与正确按钮掩盖错误更新的反例。

这17项是作者规定的程序核对，不是17名学生的试读。题面目前是结构数据，仍需中文逐层图形呈现和可读性检验；本脚本不执行下注或结算，也未纳入混合连续执行器。没有新增情境格，没有新取得真实策略来源，没有证实NL50能力。
