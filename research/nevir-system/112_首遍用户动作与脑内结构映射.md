# 112｜首遍用户动作与脑内结构映射

七步标题本身不能保证学习者真的形成结构。每一步必须同时有四个东西：用户看到的输入、用户做的动作、答完后脑中留下的一句话、以及交给下一步的状态。缺少交接状态时，页面看起来有顺序，学习者实际仍然是在每屏重新猜。

## 一手牌第一次怎样被带着走

```text
先摆清楚人、动作和钱
→ 再确认自己现在是什么牌
→ 再看双方可能拿什么
→ 再比较当前能做什么
→ 把动作和金额落到账本
→ 只更新回应或新牌改变的字段
→ 把结果和当时的决策分开
```

这不是八个平铺专题，而是一条状态链。后一层只能接收前一层留下的字段，不能要求用户重新推断已经看过的历史、金额或牌面。

## 每一步结束时用户应该留下什么

| 层 | 用户做的事 | 脑中应留下的一句话 | 下一层收到的状态 |
|---|---|---|---|
| p1 | 指出行动者、历史、底池和待补 | “先把人、动作和钱摆清楚。” | 当前行动者、历史、账本 |
| p2 | 拼最佳五张并找改善牌 | “先确认我现在是什么牌。” | 牌力、最佳五张、改善牌 |
| p3 | 解释组合不可能、变少或留下 | “先看双方可能拿什么。” | 范围视角、固定分母、移除原因 |
| p4 | 比较合法动作、价格和后续 | “动作不能只从牌型跳出来。” | 已选动作、动作身份、后继或停止 |
| p5 | 填金额、更新底池和行动权 | “想做的动作要落到账本里。” | 新历史、底池、后手、下一行动者 |
| p6 | 只更新回应或新牌变化 | “保留旧信息，只重算变化的那一项。” | 新范围、新账本、下一状态 |
| p7 | 回看结果、错误层和迁移目标 | “输赢是结果，不是当时的理由。” | 路线摘要、错误层、单变量迁移 |

## 子层为什么不会把人带乱

子层只解决当前父层缺失的一个事实。例如p3的“看一组组合”只能回答这组牌为什么被公共牌划掉或因行动变少；它不能在同一窗口顺便讲阻挡牌、下注尺寸和河牌计划。关闭子层时必须恢复：

- 原父层的牌面和历史；
- 底池、后手和行动者；
- 父层首次答案；
- 父层的范围视角；
- 下一步要打开的唯一子层。

如果子层没有完整参考或后继，它仍可作为事实或示范存在，但必须在当前父层停住，并把“缺什么”显示出来。不能用相似牌面自动接上下一层。

## 首遍结束的三项结构检查

首遍结束时不问“你记住了多少口诀”，而问：

1. 隐藏步骤名后，能否按正确顺序说出七步；
2. 给一个未见局面，能否指出当前该进入哪一层；
3. 只改一个位置、牌面、价格、回应或新牌，能否指出需要重新检查的层并完成一次判断。

三项都没有真实观察证据时，最多只能说“纸面路线已设计”。即使三项通过，也只证明结构和局部迁移，不自动证明完整策略或NL50能力。
