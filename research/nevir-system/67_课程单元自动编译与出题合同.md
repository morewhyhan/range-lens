# 课程单元自动编译与出题合同

2026年10月21日。本合同说明系统怎样把一个有来源的翻前或翻后能力单元，自动编译成“可看懂、可执行、可回退、可迁移”的练习。它把人工研究得到的资料变成只读课包；答题时不临时求解，不靠随机数猜出GTO，也不从缺失资料推断答案。

## 1. 编译器的输入身份

一个单元必须同时声明下列输入。缺任一身份，编译器只能生成事实题或示范题：

| 输入 | 说明 |
|---|---|
| SourceSpec | 原始课程、笔记、表格或仓库输出的位置、版本和原文条件 |
| ReferenceSpec | 匹配配置下的原始参考策略、引擎版本、收敛、动作和后继 |
| CoursePolicy | 用户真正要练的简化动作、权重、尺寸、删除项和解释 |
| GameFrame | 六人桌背景、活跃玩家、位置、前序、公共牌、底池、后手、抽水 |
| RangeSnapshot | 双方实体组合、类权重、已知牌过滤、撞牌过滤和视角 |
| SuccessorGraph | 行动后、新牌后、回应后的可继续节点和终点 |
| VisualSpec | 桌面、牌、范围矩阵、前后差异、金额账本的显示语义 |

SourceSpec告诉系统“资料说了什么”，ReferenceSpec告诉系统“匹配参考怎么算”，CoursePolicy告诉系统“训练器要求用户执行什么”。三者不能混成一个答案字段。

## 2. 确定性编译链

编译器按固定顺序运行，任一阶段失败就降级或停止：

~~~text
1. 身份检查
   → 位置、历史、牌面、筹码、抽水、版本和哈希一致
2. 事实帧
   → 合法牌、最佳五张、价格、金额、物理移除、撞牌
3. 参考帧
   → 实际动作、逐手频率、EV、到达权重、后继和收敛
4. 课程帧
   → 把允许的动作、权重和尺寸编成可执行政策
5. 差异帧
   → 动作差、范围差、EV差、后继差和适用边界
6. 教学帧
   → 一屏一个问题、帮助梯度、错误层、返回点
7. 题面帧
   → 公开题面、教师答案、解析、前后范围图和下一帧
8. 发布检查
   → 哈希、指纹、题面去答案、未见变体和停止条件
~~~

不能跳过第3步直接从原文动作生成“GTO精确题”。如果课程只给了明确规则而没有匹配参考，最多发布 course_rule 题，并在答案中显示其身份。

## 3. 一个单元的最小记录

每个单元输出一个可审计记录：

~~~text
unitId
parentRouteNode
entryCondition
sourceIdentity
referenceIdentity
coursePolicyIdentity
gameFrame
visibleInputs
factAnswer
policyAnswer
referenceAnswer
answerPrecision
normalization
rangeBefore
rangeAfterByAction
successorIds
question
allowedActions
helpLevels
errorLayer
returnTo
unknownCountsAsError
transferVariants

~~~

answerPrecision必须取 fact、demonstration、course_rule、reference_frequency 或 reference_policy 之一。只有有逐手频率、动作菜单、后继和版本的单元才能使用后两种精度。

## 4. 答案和范围图怎样生成

对于一个动作 a，行动后范围必须由逐手到达权重计算：

~~~text
before(h) = 起始实体组合权重 × 物理合法过滤
after(a,h) = before(h) × P(a | h, 当前节点)
view(a,h) = after(a,h) / Σh after(a,h)
~~~

如果课程政策把动作量化成纯动作或50%，必须单独保存：

~~~text
courseAfter(a,h) = before(h) × CoursePolicy(a | h)
referenceAfter(a,h) = before(h) × ReferencePolicy(a | h)
rangeDelta(a,h) = courseAfter(a,h) - referenceAfter(a,h)
~~~

同一图上不能把课程后验和参考后验叠成一个颜色。图必须标明范围拥有者、观察视角、分母和“物理过滤／行动筛选”身份。抽题时可以提高边缘牌比例，但范围评估和课程差异评估仍按真实实体质量计算。

## 5. 自动出题的四种题型

编译器只从当前父层生成四类题，按固定顺序混合：

1. 定位题：只问轮到谁、前序、表格、行动状态或牌面类别；
2. 关系题：只问牌力、价格、范围、阻挡或新牌改变的一项；
3. 执行题：按已发布的课程政策选择动作、频率或金额；
4. 迁移题：只改变一个明确字段，要求指出改变的层，再完成同一关系。

同一队列默认使用：

~~~text
定位
→ 关系
→ 执行
→ 动作后更新
→ 相邻迁移
→ 回到完整路线
~~~

边缘牌与内部牌的比例只影响题目采样，不改变答案。用户可以设置边缘比例，但题目必须记录采样身份；资料不足或未开放的节点不进入精确动作题。

## 6. 帮助、错误和答案隐藏

公开题面永远不包含答案、来源评语或完整参考频率。帮助分三档：

| 档位 | 保留 | 隐藏 | 记录 |
|---|---|---|---|
| 示范 | 步骤、事实、按钮、解析 | 无 | 不计独立正确 |
| 引导 | 必要输入和一个关系 | 最终结论或颜色 | 计帮助完成 |
| 独立 | 必要输入和合法动作 | 步骤名、答案色和结论 | 计首答独立 |

答错后编译器读取当前单元的 errorLayer，只回到最近缺失层。重答不能覆盖首答；“不知道”按错误处理。没有来源或后继时显示停止原因，不生成默认过牌、随机响应或补全动作。

## 7. 迁移变体的生成规则

迁移题只能从已验证单元生成，分成四类并显式标记：

- surface_isomorphic：只换花色或实体组合，原理不变；
- adjacent_field：只改位置、前序、牌面或价格中的一个字段；
- decision_state：无人下注、面对下注、面对加注或更新状态发生变化；
- successor_transfer：保留历史，换一张合法新牌并进入真实后继。

不能用改按钮顺序、改数字格式或重复原题充当迁移。没有真实后继的牌不能进入 successor_transfer。

## 8. 发布闸门

| 状态 | 自动生成内容 | 允许的判分 |
|---|---|---|
| not_open | 无 | 无 |
| fact | 牌张、金额、合法性 | 事实 |
| demonstration | 一段完整演示 | 不判独立策略 |
| guided | 一项带帮助操作 | 记录帮助完成 |
| independent_candidate | 未见同机制题 | 课程或局部模型 |
| target_reference_ready | 完整匹配策略和后继 | 精确参考策略 |

状态从高到低均可回退。只要输入哈希、动作树、范围、后继或课程政策变化，相关单元及其祖先必须重新编译；不能只替换教师答案。

## 9. 当前工程边界

这份合同可以直接作为课包生成器的输入规范，但目前只有部分单元具备局部事实或有限模型。A72的C2—C5尚未取得完整参考，因此不能生成目标精度的三街练习；QQQ资料只能用于工程管线测试。编译器合同通过不等于任何学习者已经达到NL50。
