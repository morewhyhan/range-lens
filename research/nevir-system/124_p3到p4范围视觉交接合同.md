# 124｜p3 到 p4 的范围视觉交接合同

2026年10月22日。本合同只处理一件事：学习者怎样从“哪些组合在物理上不可能”过渡到“现在比较哪些动作”。它不提供缺失的GTO策略，也不把一张范围图直接变成下注答案。

## 1. R01 必须连续展示的四个画面

`R01` 不能只弹出一个打叉组合。它要按下面的顺序在同一父帧中展开：

```text
动作前坐标图
  ↓ 已知底牌/公共牌的实体冲突
物理过滤后的坐标图
  ↓ 明确显示“行动筛选尚未提供”
行动筛选锁定状态
  ↓ 关闭范围子层，恢复原父题
p4 比较：当前合法动作与待补金额
```

### 画面 A：动作前坐标图

- 左上写清拥有者、视角、完整前序和已知牌；
- 使用固定13×13坐标，不重新排序；
- 分母写在图上；
- 每个格子显示实体质量，不把一个169格颜色当作完整策略。

### 画面 B：物理过滤

- 只删除与自己底牌或公共牌冲突的具体组合；
- 冲突格使用斜线＋“已知牌占用”；
- 仍可能的组合保持原质量；
- 不能因为牌力弱、看起来不像或课程没有举例就删除。

### 画面 C：行动筛选锁定

- 单独放置“根据对手行动筛选”区域；
- 当前候选没有匹配动作参考时显示中性锁定纹理和“资料不足”；
- 不显示0%、弃牌或任何自造频率；
- 解释文字明确：物理过滤回答“能不能拿”，行动筛选回答“在这条行动后还保留多少”。

### 画面 D：回到 p4 比较

- 范围子层缩成一张小缩略图，保留“物理过滤已完成”的标记；
- 恢复原牌面、历史、底池、后手和首答；
- 只显示当前题面允许的比较对象；
- 若缺少策略参考，仍可做流程和事实题，但不能判精确动作后范围。

## 2. 学习者实际回答的四句话

主持者或页面按顺序只问一件事：

1. **这张图是谁的范围？**
2. **哪一组牌是因为已知牌而不可能？**
3. **这次变化有没有用到对手的行动？**
4. **关闭范围层以后，下一步回到哪里？**

如果用户直接回答“所以应该下注”，系统应把它标为跳过范围层，而不是给动作题加分。正确回答是“现在只知道实体冲突；行动后的保留比例还没有资料，下一步回到比较层”。

## 3. 固定数据和视觉语义

| 事件 | 图表变化 | 文字解释 | 不得表达 |
|---|---|---|---|
| 自己持有 A♣ | `A♣K♣` 斜线 | “A♣已被自己占用” | “对手不会拿AK” |
| 公共牌出现 A♥ | 含 A♥ 的具体组合斜线 | “公共牌占用这张实体牌” | “所有Ax都被弃掉” |
| 对手行动筛选有数据 | 同坐标格子权重减少 | “按这次行动留下的质量” | “物理上不可能” |
| 对手行动筛选无数据 | 图不改变，锁定区显示未知 | “资料不足，不能画成弃牌” | 0%、弃牌或默认一半 |

所有前后图使用同一坐标、同一尺度、同一分母。占比上升必须同时显示总质量是否下降，避免用户把“其他牌减少”误认为“强牌增加”。

## 4. p3→p4 必须交接的字段

```text
rangeOwner
viewpoint
knownCards
fullHistory
board
rangeBefore
physicalFilter
actionFilterStatus
normalizationDenominator
parentSnapshot
firstAnswer
returnTo
```

`actionFilterStatus` 只有在有匹配参考或明确课程政策时才允许变为 `available`。否则必须是 `unknown_reference`，并阻止精确策略题继续开放。

## 5. 练习顺序

第一次只让用户点出一组物理冲突牌；第二次让用户区分“物理删除”和“行动筛选”；第三次才让用户在关闭范围子层后指出 p4 的比较对象。这样练的是三种不同关系，不把169格背诵、阻挡牌和下注按钮压成一个答案。

答错时：

- 把物理冲突当弃牌 → 回到 p3 并只重放画面 B/C；
- 把占比上升当组合增加 → 回到固定分母说明；
- 直接跳动作 → 回到 p3 的第四句话；
- 资料不足仍要求精确范围 → 停止本题，不能把错误归给学习者。
