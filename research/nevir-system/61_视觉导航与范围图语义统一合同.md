# 视觉导航与范围图语义统一合同

2026年10月21日。本合同统一翻前、翻后和范围变化的视觉语言。目标不是增加装饰，而是让低基础用户在任何阶段都能看见同一张牌局、当前一步和下一步变化。它接[单一路径总装合同](53_单一路径总装与首次全图导航合同.md)、[界面与图表语义](05_界面递进与图表语义.md)及[一页慢想运行卡](58_学习者一页慢想运行卡.md)。

## 1. 只有一个视觉中心

每一屏只保留四个区域，位置固定：

~~~text
顶部：当前路线位置 + 当前街次 + 返回位置
中央：一张桌面、一个牌面或一张范围图
下方：一个问题 + 当前可用按钮／格子
侧边：一句解析或一个可选子层
~~~

顶部不做仪表盘，不显示长期统计、多个模式卡片或全部课程目录。中央视觉中心随当前父层变化：

- 翻前定位和执行：中央是小桌与对应169格；
- 翻后读牌：中央是桌面、最佳五张和改善牌；
- 翻后范围：中央是固定坐标的范围图；
- 比较与执行：中央是当前合法按钮、金额和相关候选；
- 更新：中央保留上一状态缩略图，并突出一项变化；
- 结算：中央是终局、账本和错误层。

同一屏不同时放完整范围矩阵、所有动作尺寸、所有公式和所有来源。

## 2. 顶部导航只表达路线，不表达成绩

顶部使用一条短路径：

~~~text
翻前定位 → 读格 → 动作 → 起始范围 → 翻牌定位 → 比较 → 执行 → 更新 → 结算
~~~

当前节点高亮，已经走过的节点可以回看，尚未开放的节点只显示轮廓，不显示可点击答案。顶部不显示“正确率”“等级”或“NL50进度”，因为这些数字会把结构学习误读成成绩竞赛。

进入子层时，顶部变成：

~~~text
当前父层 / 当前子层 / 返回父层
~~~

关闭子层后恢复父层标题和当前问题，不改变主线进度。

## 3. 桌面、牌和范围图的固定语义

### 3.1 桌面

小桌始终显示六个座位、行动指针、弃牌状态、底池、各人已投、本街投入和后手。未参与当前牌局的座位弱化但不消失；已弃牌座位从行动顺序中移除。轮到谁用指针和文字双重表达。

### 3.2 牌面

牌张必须同时显示点数与花色符号。花色颜色保留牌张语义，不能与答对／答错的红绿颜色混用。最佳五张使用边框和标签，公共牌、自己的底牌、可见对手牌和未知牌有不同的视觉身份。

新牌出现时，上一街牌面缩小保留，当前街最大；不播放会隐藏行动顺序的动画。需要回看前序时，使用同一桌面停住，不切换成一张脱离历史的牌型卡。

### 3.3 范围图

范围图永远保持13×13方向和同一格子坐标：

- 行列方向和对子／同花／不同花的定义固定；
- 当前题格使用粗边框，邻近对照格使用第二种纹理；
- pure、mixed、source_boundary、unknown有文字图例和纹理，不仅靠色块；
- 行动前、行动后和重新归一化图保持同一尺度，并写出分母；
- 物理冲突、行动筛选和未知资料使用三种不同标记；
- 显示具体组合时，格子可展开花色，但关闭后回到原格子与原父帧。

范围图展示的是当前声明身份下的质量和动作，不把灰色空格直接解释成现实中绝不可能，也不把整体节点比例染到每个具体底牌。

## 4. 颜色、形状和文字必须共同表达

所有重要状态至少使用两种视觉通道：颜色＋文字、边框＋纹理、指针＋标签或动画＋停顿。最低语义表如下：

| 状态 | 主要表达 | 辅助表达 | 禁止误读 |
|---|---|---|---|
| 当前格／当前步骤 | 高亮边框 | “现在回答”文字 | 不能只用微弱色差 |
| 正确 | 绿色小标 | “正确，进入下一题” | 不能让绿色代表动作类型 |
| 错误 | 红色小标 | 错在哪一层的文字 | 不能把红色当花色 |
| 混合动作 | 双条纹或分段条 | 明示两个动作及权重 | 不能显示成一个按钮 |
| 未知资料 | 中性灰纹理 | “资料不足”文字 | 不能显示成弃牌 |
| 物理冲突 | 斜线 | “被已知牌占用” | 不能显示成行动筛选 |
| 行动筛选 | 实线减弱 | “因这次行动降低” | 不能显示成物理不可能 |

## 5. 变化必须按时间顺序显示

范围和桌面变化遵循同一个三步动画／静态切换：

~~~text
上一状态（保留）
→ 当前动作或新牌（只突出一项变化）
→ 下一状态（显示后手、范围和下一行动者）
~~~

动作后范围图至少可在“前、后、差异”之间切换，但默认只显示当前一步的差异。新公共牌先突出物理移除，再按需显示行动条件筛选；不能把两种变化同时染成同一种颜色。

动画可暂停、单步和回看。用户需要判断时不自动跳过关键金额、行动者或范围变化。动画结束必须停在可回答的问题上，而不是停在一个漂亮但无法操作的结果画面。

## 6. 当前按钮与解析的位置

按钮只显示当前父层合法动作，使用动作＋金额的具体文本：例如“过牌”“下注 5BB”“跟注 4BB”“加注到 18BB”。不只写“Bet”“Raise”，不把下注尺寸和频率写成同一个数字。

答错时，按钮区保留当前选择和正确动作的差异；解释区先说“错在位置／牌力／范围／价格／按钮／金额／更新哪一层”，再提供一个局部对照。正确时立即进入下一题，不把解释弹窗变成另一个首页。

“我不知道”与其它按钮同级显示，判分按错但进入当前解析；它不改变父帧、路线或长期记录。

## 7. 范围图和慢想卡怎样互相呼应

慢想卡的七格固定映射到视觉中心：

| 慢想卡 | 默认中央视觉 | 用户操作 |
|---|---|---|
| 现在发生什么 | 小桌、指针、历史、金额 | 点行动者或历史片段 |
| 牌面和自己的牌 | 五张组合、牌型标签、改善牌 | 点最佳五张或补牌 |
| 谁的范围留下什么 | 前后范围图和差异图 | 点具体格或组合 |
| 合法选择 | 当前按钮和待补 | 点按钮或金额 |
| 比较当前动作 | 候选分支与价格 | 点比较对象 |
| 执行并交接 | 筹码移动和行动指针 | 确认金额 |
| 更新以后再来 | 新牌、后范围、下一行动者 | 点变化并回到第一格 |

用户从任一视觉区域都能看见当前属于哪一格；视觉变化不能把慢想顺序改成另一套流程。

## 8. 视觉验收问题

每个新课包和页面版本发布前检查：

- 不看标题，用户能否从桌面和问题判断当前父层？
- 中央是否只有一个主要视觉对象？
- 当前行动者、底池、待补和后手是否无需猜测？
- 范围图是否保持同坐标、同尺度并写出分母？
- 物理移除、行动筛选和未知资料是否能区分？
- 混合动作是否同时显示动作和权重？
- 子层关闭后，父帧和主线是否完全恢复？
- 牌花色、对错颜色和动作颜色是否互不混淆？
- 动画停住时，用户是否知道下一步要回答什么？
- 页面是否避免仪表盘、长期成绩和全部课程平铺？

设计者觉得“舒服”不等于通过；仍需按[学习者试读闭环](59_低基础学习者试读与课程修订闭环合同.md)观察真实用户。
