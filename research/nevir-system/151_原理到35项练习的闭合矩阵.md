## 为什么还要做这张表

一条路线可能走得很顺，但学习者仍然没有真正学会原理；反过来，35项题目也可能全部出现，却只是记住了按钮。闭合矩阵把“原理第一次出现”“原理在哪些子题被反复使用”“原理怎样进入迁移”分开记录。

原理第一次出现永远在主线父步骤：先定位行动者和价格，再读牌面和牌力，再看范围，然后比较动作、执行金额、更新状态，最后结算和定位错误。35项子题只负责把已经出现的原理放进不同的具体问题中，不能在首次讲解之前提前使用，也不能倒过来用子题数量代替主线教学。结算、错误层和下一手属于 p7 的回看父层，不提前塞进 p4 或 p6 的动作题。

## 12个原理怎样闭合

| 原理 | 首次讲清 | 后续子题中的作用 | 最终迁移 |
|---|---|---|---|
| 定位与行动者 | L1 / p1 | 账本与行动顺序更新 | 只改行动者或历史 |
| 价格与账本起点 | L1 / p1 | 新价格、金额和后手变化 | 只改下注尺寸 |
| 牌面结构 | p2 | 新牌、配对、高牌和相对空白 | 只改一张公共牌 |
| 手牌、牌力与改善牌 | p2 | 自己改善、听牌完成、重新拼五张 | 只改底牌或牌面 |
| 行动前范围 | p3 | 对手回应、历史路线、下注后范围 | 只改起始范围 |
| 物理过滤与行动过滤 | p3 | 回应筛选、自己的范围、新牌移除 | 只改一张实体冲突牌 |
| 动作目的与比较维度 | p4 | 未下注、面对下注、面对加注 | 只改对手回应 |
| 价格、尺寸与阈值 | p4 | 同目的不同尺寸、新价格、听牌价格 | 只改价格 |
| 执行动作与账本更新 | p5 | 下注、加注、全下和行动重开 | 只改后手或合法动作 |
| 行动后范围变化 | p6 | 对手跟注、自己的下注范围、历史路线 | 只改动作 |
| 新牌效果与后继 | p6 | 新牌改善、完成、配对、移除、河牌关闭未来 | 只改新牌 |
| 结算、错误层与下一手 | p7 | 结果与决策分离、河牌收束 | 只改结果或反馈 |

## 练习如何从原理进入动作

每个子题都用同一份输出格式：动作、金额、目的、范围前后或停止原因、账本和后继。这样不同牌型的表面变化不会改变脑中的主结构。题目改变的是牌、位置、价格、回应或新牌中的一个字段；学习者必须先指出变化字段，再沿对应原理返回检查。

练习队列也按固定顺序运行：同机制重复 → 相邻单变量对照 → 延迟回忆 → 连续整合。连续整合前，必须已经在各自原理上通过前面的三种练习。答错时回到原理所在的父层，不把整套35项重新铺开。

## 这张矩阵能证明什么，不能证明什么

它能证明所有12个原理已经被挂到主路线，并且35项都有至少一个原理归属；它不能证明策略数字已经取得、不能证明范围图已经正确、不能证明学习者已经掌握，更不能证明达到NL50。策略、范围、后继和学习者证据仍然要按各自发布闸门单独闭合。
