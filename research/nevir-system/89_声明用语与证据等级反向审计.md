## 1. 审计目的

当前研究文档数量已经很多，最危险的错误不再只是漏写一项，而是把“有材料”“代码通过”“纸面路线”和“学习者学会”写成同一个完成状态。本审计固定公开文档的声明用语，防止局部进展制造目标完成感。

## 2. 允许使用的证据等级

| 等级 | 可以说什么 | 不能说什么 |
|---|---|---|
| `source_read` | 已定位并读取资料片段 | 资料片段已经是真实策略 |
| `fact_verified` | 牌力、组合、金额或公式由独立方法复核 | 动作最优、GTO或学习有效 |
| `finite_model` | 给定有限模型中的局部比较可复算 | 该模型代表完整范围或现实策略 |
| `course_policy` | 课程资料在声明条件下规定了简化动作 | 简化动作就是原始GTO频率 |
| `reference_ready` | 固定配置下有原始参考、版本、收敛和后继 | 参考已经证明教学或NL50 |
| `route_paper_ready` | 纸面路线、父子层和返回点完整 | 页面已经可用或低基础用户已学会 |
| `learner_trial` | 真实学习者在冻结版本上完成了指定试读证据 | 可以直接推断NL50盈利或稳定性 |
| `target_benchmark` | 目标配置、独立迁移和外部对标按预先规则通过 | 永久达到NL50或不需要继续复习 |

## 3. 必须避免的替换

以下替换一律禁止：

- 文档链接数 → 课程完整度；
- 题目数量 → 能力覆盖；
- 事实正确 → 策略正确；
- 有限模型EV → 完整GTO策略；
- 求解器收敛 → 课程简化无损；
- QQQ工程候选 → A72课程参考；
- 首遍路线走通 → 陌生三街执行；
- 解析后重答正确 → 首答独立通过；
- 低基础试读通过 → NL50目标对标；
- 短期牌局输赢 → 软件教学有效。

## 4. 本次反向审计范围

本次检查了`research/nevir-system`下的研究合同、路线、35项审计、A72准入、仓库审查、试读合同、学习科学合同和判分合同，重点搜索以下容易过度宣称的词：完成策略、完整策略、已验证、可以发布、已学会、达到NL50、完整三街、精确策略。

审计结论：现有文档主线仍把以下状态分开保存：

- 35项有局部模型或事实，但完整目标策略为0；
- A72输入和全树预检已建立，但C2—C5原始策略仍缺；
- QQQ有工程运行和重载证据，但不替代A72课程；
- 纸面路线和机器验证通过，不等于页面实现；
- 低基础试读、连续迁移和NL50目标对标均未取得。

这次反向审计本身只证明声明边界没有被机器状态覆盖，不提升任何课程或学习证据等级。

## 5. 以后每份新增文档的末尾要求

新增研究文档必须写清楚：

1. 本文证据等级；
2. 本文没有证明的结论；
3. 对应的下一道发布闸门；
4. 是否改变了原始输入、课程政策或应用；
5. 机器验证和真实学习试读是否已发生。

若一篇文档不能回答这五项，不能接入主纲，也不能作为目标完成的依据。

当前目标总状态仍必须是`goalCompletionVerified=false`。本审计没有发现可把局部证据升级为NL50的合法路径；下一步仍应补匹配策略、连续后继、真实试读和目标对标，而不是继续堆积“已完成”字样。
