# 低基础学习者试读与课程修订闭环合同

2026年10月21日。本合同规定怎样真正检查“低扑克基础、阅读慢、工作记忆有限的人能否沿路线学习”，以及发现问题后如何修订。它是研究和发布流程，不是已经取得的学习者结果；软件仍不保存长期成绩或建立用户数据库。

## 1. 试读要回答的四个问题

一次试读必须分别回答：

1. 用户能不能知道当前发生了什么，以及下一步该打开哪一层；
2. 用户能不能在不计时的情况下完成当前的牌、范围、价格、金额或更新操作；
3. 用户能不能把同一结构带到一个未见但只改变一个条件的局面；
4. 用户卡住是因为页面组织、扑克事实、策略资料不足，还是题目本身把多个负担混在了一起。

“答对按钮”只能回答其中一小部分，不能替代四项检查。

## 2. 主持方式

主持者先给用户一张桌面和当前任务，不预讲术语，不暗示当前考哪条规则，不在用户停顿时替他补答案。允许暂停、回看和点击“我不知道”，但记录每一次帮助。主持者只能解释已经准入的事实或课程政策；如果节点缺参考，要明确说资料不足，不用临时猜一个动作。

一次试读分为四段：

| 段落 | 用户看到什么 | 主要观察 |
|---|---|---|
| A 进入主线 | L0—L4翻前与起始范围 | 能否找对场景、读格和理解范围不是一张实际底牌 |
| B 走翻后循环 | 规范路线中的 `p1—p7` 一手完整结构示范（作者侧对应L5—L8） | 能否跟住定位、牌力、范围、比较、执行、更新、结算 |
| C 收起帮助 | 收起步骤名和答案色，保留必要输入 | 能否指出下一层并完成一个局部动作 |
| D 相邻迁移 | 换一个位置、牌面或前序字段 | 能否指出改变的关系，不把任何变化都当成换按钮 |

正式主持者不应把A—D变成问卷；用户顺着主线操作，主持者在预定观察点记录事实。

## 3. 参与者与伦理边界

“小学生或老奶奶”是低理解门槛的产品标准，不是抽样标签。第一轮应优先找没有系统扑克训练的成年读者，记录其阅读与操作条件；不能把一名熟悉扑克的作者、程序员或设计者走通当作普通用户证据。

参与者应知道这是产品试读，不是牌技考试；不记录真实资金或用短期输赢评价教学。研究日志可以在项目外单独保存，应用本身不增加账号、数据库或长期成绩机制。发布报告应去除可识别信息，只保留任务、帮助、错误层和路线结果。

## 4. 记录格式

每个观察点至少记录：

```text
sessionId（研究日志，不写入应用）
routeNode / parentFrame
visibleAssistance
firstAnswer
retryAnswer
helpUsed
timeToAction（只作观察，不作达标阈值）
errorLayer
verbalizedNextStep
unpromptedReturnToCard
exitOrPause
hostIntervention
```

首答、解析后的重答和主持者代答必须分开。用户如果点对按钮但说不出下一步，记录为动作正确、结构未证；用户如果牌力说错但最后按钮碰巧正确，记录为牌力层错误，不用按钮掩盖。

## 5. 错误分类与修订方向

| 观察到的现象 | 优先怀疑 | 修订动作 |
|---|---|---|
| 不知道轮到谁 | 桌面、指针或历史文字不清 | 改视觉层级和行动历史，不先增加理论 |
| 最佳五张反复错 | 牌力输入或牌面表达不足 | 加一张最小对照，暂不讲策略 |
| 看见阻挡就直接下注 | 事实与动作原因混在一起 | 把物理移除、行动筛选和策略答案分成子层 |
| 每次新牌都重置前序 | 父帧没有继承 | 修复快照和返回关系，不增加新菜单 |
| 资料不足时被迫猜 | 释放闸门失效 | 降级为事实／示范并显示缺项 |
| 会跟着点但找不到下一层 | 主线不明显或帮助撤除过快 | 保留返回标签，逐项撤除一种帮助 |
| 同一条件换位置就乱点 | 对照同时改变太多字段 | 先做单字段变化，再做组合变化 |
| 解释后变对但陌生题仍不会 | 重答污染了独立证据 | 独立换题，保留首答和帮助状态 |

修订必须写明改变的是页面、题面、课程政策、参考数据还是验证脚本。不能用增加题量掩盖同一个父层的组织问题。

## 6. 发布前的迭代循环

```text
纸面走查
  ↓
低基础成人逐帧试读
  ↓
按错误层修改一个变量
  ↓
用未见但同构的任务复测
  ↓
冻结题面、帮助、答案和版本
  ↓
再做独立迁移与连续路线测试
```

同一参与者看过解析后再次正确，不可以用来冻结通过线；修订后的材料必须保留一组未曝光题。若修改了参考、课程政策、动作菜单或范围图，已有学习结果只对旧版本有效，不能沿用到新版本。

## 7. 何时只能说“结构可用”

试读可以支持的结论应分层写：

- **路线可理解**：用户能在未提示步骤名时指出下一层，并能说出返回位置；
- **局部可执行**：用户在必要输入完整的单步题中完成动作和金额；
- **相邻可迁移**：用户指出一个改变字段，再处理局部动作；
- **连续可执行**：用户在未见整手中保留历史、回应、新牌和账本；
- **目标对标**：匹配参考和独立外部测试达到预先校准的误差要求。

前四层的试读结果不能直接标为NL50。没有完整策略参考或后继闭合时，试读只能评价路线与事实教学，不能评价目标动作正确性。

## 8. 当前状态

当前已有纸面试读分镜、错误回退、帮助撤除和覆盖合同，但没有真实低基础成年参与者结果，也没有冻结的独立迁移样本。下一次试读应优先使用规范L0—L4→p1—p7单一路线和一处相邻迁移；作者侧L0—L8只作覆盖索引，记录是否能在不提示步骤名时回到正确层；不增加新牌型或新的首页入口来逃避试读。
