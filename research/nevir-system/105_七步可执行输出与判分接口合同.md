# 七步可执行输出与判分接口合同

## 1. 目的

路线图只能告诉学习者先后顺序；真实牌局还要求他在每一步产出一个可以检查的结果。本合同把“我看懂了”改成八个固定输出，供页面、题面、解析和验证脚本共用。

```text
状态 → 牌面 → 手牌 → 范围 → 比较 → 执行 → 更新 → 结算
```

学习者不需要一次说出所有后台字段。屏幕只显示当前步骤所需的输入，学习者只完成当前步骤的输出；系统在答后再显示本步骤的原因和下一步。缺少资料时，输出身份降级为事实或示范，不能伪造动作答案。

## 2. 八个固定输出

| 输出 | 屏幕必须提供 | 学习者必须产出 | 判分身份 | 视觉对象 | 错误回退 |
|---|---|---|---|---|---|
| O1 状态 | 小桌、街、行动历史、底池、投入、后手 | `street`、`actor`、`facingAction`、`potBB`、`toCallBB`、`effectiveStackBB` | 事实 | 六人桌和账本 | 回到桌面／历史 |
| O2 牌面 | 公共牌、牌面关系提示 | `boardClass`、成对／连接／同花关系、最近新牌改变 | 事实 | 横排公共牌 | 回到牌面 |
| O3 手牌 | 自己底牌、公共牌、牌堆余量 | `bestFive`、`handClass`、直接听牌、后门、改善牌、阻挡事实 | 事实 | 底牌＋最佳五张＋补牌 | 回到最佳五张 |
| O4 范围 | 翻前来源、行动前后13×13图、视角和分母 | `rangeOwner`、物理移除、行动筛选、前后变化位置 | 事实／关系 | 固定分母双范围图 | 回到范围 |
| O5 比较 | 合法动作、价格、已声明后继 | `legalActions`、`price`、各动作目的、关键继续／退出组合、未来分支 | 课程规则／参考策略 | 动作按钮和分支条 | 回到范围或价格 |
| O6 执行 | 当前选定动作、金额输入、账本预览 | `action`、`amountBB`、`potAfterBB`、`stackAfterBB`、下一行动者 | 账本事实＋课程政策 | 金额变化动画 | 回到金额 |
| O7 更新 | 新历史、新牌、动作后范围、合法后继 | `changedField`、新范围快照、新牌影响、下一行动者、后继或终局 | 事实／参考后继 | 单字段高亮的更新图 | 回到状态 |
| O8 结算 | 终局牌面、摊牌／弃牌、父帧快照 | `settlement`、结果与决策分离、下一轮要回到的层 | 账本事实＋结构回忆 | 结算和路线回放 | 回到最近缺失层 |

## 3. 数值输出的统一规则

只有O1、O5、O6、O7需要金额或范围质量时，才显示相应数值；单位固定为BB，显示值与判分值分离。

```text
pot_after = pot_before + matched_contributions + uncalled_return_adjustment
stack_after = stack_before - actual_contribution
to_call = amount_required_to_match_current_bet
range_after(a) = range_before × p(a | hand,node) / mass(a)
```

物理移除、行动筛选和未知资料必须用不同字段记录。一个组合从图上消失，不能仅凭消失位置推出它弃牌；必须有行动过滤证据才能标成动作后变化。

## 4. 题面与判分接口

每道题必须声明：

```text
stepId
parentFrame
visibleInputs
learnerOutput
allowedIdentities
precision
sourceIdentity
successorState
errorLayer
returnTo
```

`allowedIdentities`只能从 `fact`、`ledger`、`course_rule`、`reference_policy`、`demonstration` 中取值；每道题可以声明多个允许身份，但实际判分时只能选择其中一个。`precision`必须说明是实体牌、集合、整数金额、课程动作还是逐手频率；没有匹配参考时，`reference_policy`不可使用。

答错后只显示当前输出缺少的字段。例如：

- O3把后门说成直接听牌，只补“需要几张未来牌”，不提前显示下注答案；
- O4把物理移除说成弃牌，只补“谁拿走了这张牌”，不改写行动历史；
- O5不会跟注，只先显示`toCall`和跟后底池，不直接给动作；
- O6金额错误，只重放账本，不重新讲牌面原理；
- O7漏掉新牌影响，只高亮变化字段，再回到O1。

## 5. 缺资料时的停止规则

| 缺失 | 允许显示 | 禁止显示 |
|---|---|---|
| 只有牌张和最佳五张 | O1—O3事实题 | 唯一下注动作 |
| 有物理范围但无行动后范围 | O4物理过滤或示范 | “这次行动删掉了某组合” |
| 有课程规则但无完整后继 | O5课程动作和局部解释 | 连续三街最优策略 |
| 有匹配参考但后继未闭合 | 当前节点参考 | 自动生成下一街答案 |
| 有完整后继但未做学习试读 | 作者侧课包候选 | “低基础学习者已学会” |

停止原因必须在当前父帧显示，关闭子层后仍回到原题；未知按错误或停止合同处理，不凭空补默认动作。

## 6. 首遍和后续练习如何使用

首遍依次完成O1—O8，每步只展示一个输出。第二遍把同一输出放进五组后台单元，仍按父帧返回；第三遍撤掉步骤标题，只保留必要输入和输出栏；连续练习把O7的后继接回O1，直到O8结算。

“做完一遍”只有在学习者能在未见题上按顺序产出这些输出，且错误能回到对应层时，才算结构证据。填满八个界面或看完八段解析本身不算学会。

## 7. 当前状态

本合同把路线转成可检查的学习者输出和判分接口，仍是纸面规格；页面组件、完整策略参考、35项后继和真实低基础试读尚未通过。它不会凭自身生成新的GTO动作。
