# NL50目标结果边界与验收合同

2026年10月21日。本合同保留“训练完成后应具备进入NL50所需能力”作为最高目标，同时把“课程结构清楚”“策略参考正确”“学习者会做”“真实牌局达到目标”分成四种证据。这样既不降低目标，也不把尚未证明的结果写成保证。

## 1. 四种不同的结果

| 结果层 | 说明 | 需要什么证据 |
|---|---|---|
| T1 结构学会 | 跟一遍后知道下一步和回退层 | 首遍顺序恢复、下一层定位、一处迁移 |
| T2 策略会做 | 在未见题中能读牌、看范围、比较和更新 | 匹配参考课包、独立首答、连续后继 |
| T3 目标配置迁移 | 换位置、前序、牌面和回应仍能正确执行 | 未曝光连续路线、延迟回忆、交错样本 |
| T4 NL50实战准备 | 在目标条件下长期做出稳定、可复核的决策 | 完整参考、外部对标、真实牌局样本和风险管理 |

T1、T2或T3不能自动推出T4。训练器可以把T4作为设计目标，但不能仅凭文档、题目数量或一次答题率承诺结果。

## 2. NL50验收配置必须先冻结

在任何结果判断前，必须固定：

- 六人现金桌还是其它桌型；
- 有效筹码；
- 抽水和平台规则；
- 位置、前序和下注尺寸；
- 对手模型或参考策略；
- 允许的动作菜单；
- 样本的街次、角色和牌面分布；
- 错误、帮助和重答如何计分；
- 真实牌局样本的时间、桌数和排除规则。

只在零抽水研究树或固定单一对手模型中表现良好，不能直接叫NL50实战表现。

## 3. 课程本身必须先过的门

目标结果研究只能在以下条件都通过后开始：

1. 翻前图表覆盖和来源身份冻结；
2. 至少一条翻后三街配置有完整匹配参考；
3. 课程简化和参考策略的差异已评估；
4. 动作后范围、金额和所有正支持后继可重放；
5. 规范L0—L4→p1—p7→回放首课能运行，作者侧L0—L8映射可审计；
6. 低基础首遍试读通过；
7. 未见连续迁移和延迟回忆已经冻结；
8. 题面、帮助和教师答案可复现。

缺任一项，只能说课程仍在建设或局部验证，不能把用户表现外推到NL50。

## 4. 学习者证据怎样分级

| 级别 | 必须完成 | 可以说什么 |
|---|---|---|
| R1 | 有帮助完成一条主线 | 看过路线 |
| R2 | 无标题完成未见单步 | 能调用一层关系 |
| R3 | 连续走完未见三街路线 | 开始保留历史和更新 |
| R4 | 交错、延迟后仍能迁移 | 结构有一定内化 |
| R5 | 多角色、多前序、多牌面连续执行 | 具备目标课程中的稳定能力 |
| R6 | 目标配置外部对标和真实表现均通过 | 才能讨论NL50准备度 |

每一级都要保留首答、帮助、重答、错误层和未见样本身份。解析后答对不算独立通过。

## 5. 真实牌局证据不能只看输赢

真实样本至少同时记录：

- 决策是否处在已覆盖配置；
- 当前动作和金额；
- 当时可见的范围和后继；
- 是否使用了帮助或复盘；
- 牌局结果和实际收益；
- 错误属于状态、牌力、范围、价格、动作还是更新；
- 是否存在超出课包的未知分支。

短期输赢受牌局方差影响，不能单独证明策略正确；短期赢钱也不能替代长期样本和决策级审查。

## 6. 训练器能承诺什么

在证据完整前，训练器可以承诺：

- 训练路线按一条嵌套主线组织；
- 每一步都有明确输入、问题、动作和返回点；
- 已发布的课程规则或参考策略会标明身份；
- 范围、金额和后继按代码和公式复核；
- 资料缺口会停止，不用猜测填补；
- 用户可以在当前会话中反复练习，不需要长期数据库。

它不能承诺：

- 任何人完成课程后必然盈利；
- 任何单一课程简化就是所有牌局的GTO；
- 题目正确率直接等于NL50胜率；
- 零抽水、固定树或局部切片等于真实平台环境。
