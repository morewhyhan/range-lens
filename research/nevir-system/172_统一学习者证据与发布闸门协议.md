## 这份协议的作用

122号规定了怎样主持一次首遍，132号规定了怎样区分页面、资料和学习者问题，167号规定了怎样检查路线结构，169号规定了最终目标边界，171号规定了陌生牌迁移阶梯。它们如果各自使用，仍可能出现一个问题：作者不知道现在究竟能开放哪一级训练，也不知道一次试读结束后应该把用户放回哪里。

172号只做一件事：把这些合同压成一条发布闸门。它不是新的课程专题，也不是新的首页菜单。任何版本都必须按下面顺序走，前一闸门没有证据，就不能打开后一闸门。

```text
V0 纸面闭合
→ V1 首遍跟练
→ V2 隐藏路线回放
→ V3 单变量迁移
→ V4 资料充分的陌生单步
→ V5 连续三街与目标级复核
```

## 一、用户实际经历的验证顺序

### V0：先确认这条路在纸面上没有断点

这一步由作者和独立复核者完成，不让学习者替课包找结构错误。必须检查：

- 学习者外层 `L0→L4` 后进入同一父帧内的翻后 `p1→p7`，再进入回放；旧 `L5→L8` 只作作者宏观审计别名；
- 每一屏只有一个问题、一个主要动作和一个返回点；
- 普通话解释先于技术术语，速度不作为通过条件；
- 牌面、手牌、范围、金额、行动权和后继身份齐全；
- 缺少参考或后继时有停止卡，不用默认动作填空；
- 精确策略题标明课程政策或匹配参考；
- 范围前后图使用同一坐标和分母。

任何一项不成立，停止发布，先修数据或父帧，不把问题推给用户。

### V1：用户只跟一条完整首课路线

主持者只说：“跟着这一手牌往下走，每一步先告诉我现在发生了什么、下一步看哪里。”主持者不能说“这是范围题”或“这里应该下注”。

用户沿黄金路径完成：桌面与行动权 → 翻前图 → 范围交接 → `p1`局面 → `p2`牌力 → `p3`范围 → `p4`比较 → `p5`执行 → `p6`更新 → `p7`收口。每一帧首答后才允许打开解析。

V1只检查用户有没有跟上状态交接，不把策略结果当作首遍通过。资料不足的节点，用户选择“停止并说明缺口”就是正确交付。

### V2：收起标题后，用户重新找回结构

首遍结束后收起步骤名称、答案颜色和技术术语，只留下空路线图与状态卡。用户需要完成：

1. 用普通语言说出外层九个停点：桌面、局面、翻前图、范围交接、翻后进入、比较、更新、结算、迁移；
2. 在翻后进入后，说出七个父步骤及其顺序；
3. 说出每一步交给下一步的最小结果；
4. 在三个未见父帧中指出当前层和唯一下一层；
5. 在两个故意注入的错误中回到最近缺失层，并保留父帧；
6. 说出一次“为什么这一变化要回到这一层”。

这里验收的是“先走哪条外层路、进入翻后后再走哪七层”的关系，不要求用户记住`L0`到`L8`或`p1`到`p7`这些内部编号。说出“先看局面，再看牌面和范围，然后比较、执行、更新、收口”即可作为普通语言结构回答。

主持者可以重复题面，但不能代替用户说出下一层。看完完整解析再重答，不算独立结构证据。

### V3：只改变一个变量，检查迁移

训练器从同一个父帧生成相邻对照。每道题只允许改变一个字段：位置、公共牌、价格、对手回应或一张范围状态。用户必须先说出改变字段和受影响层，然后才做事实或动作判断。

页面使用同坐标三联图：

```text
动作前范围 → 物理排除后范围 → 动作筛选后范围
```

如果没有匹配策略参考，只能问“哪些组合物理上不可能”“资料缺什么”，不能判精确下注。相同题重做、同花色同构或看了解析后的重答，都不算独立迁移。

### V4：在资料充分的陌生单步中慢速执行

用户不再看到步骤标题，但仍保留必要输入。执行顺序固定：

```text
定位当前层 → 读事实 → 看范围 → 比较合法选择 → 执行动作
→ 更新账本/范围/行动权 → 进入真实后继或停止
```

每一题分别检查事实、动作、金额、理由、动作后范围和下一行动者。答错时只修一个层，不用整手牌解析覆盖错误。只有匹配参考和课程政策都冻结的节点，才允许判精确策略；未知资料必须按未知处理。

### V5：最后才验证连续三街与目标级别

只有V4在未曝光题上稳定，才允许串接翻牌、转牌、河牌。连续路线必须保留：

- 历史与行动权；
- 每街范围分母和动作后范围；
- 底池、有效筹码和金额守恒；
- 新牌与真实回应的合法后继；
- 摊牌与当时决策的分离。

V5通过也只代表在冻结配置和覆盖范围内具有训练证据。要讨论NL50，还需要独立复核、外部目标基准和真实决策审计；不能用页面完成、题目数量或短期盈利替代。

## 二、每一次尝试必须留下什么

当前会话只保留以下字段，不建立训练器数据库：

```text
courseVersion
gate
caseId
seenOrHeldout
currentParentStep
firstAnswer
helpLevel
hostIntervention
requiredOutput
changedField
errorLayer
returnTo
retryAnswer
nextStepVerbalized
rangeDeltaOrStopReason
ledgerAndActionRightCheck
successorCheck
```

首答、帮助后答和重答分开。主持者代答后继续，只记为“没有独立证据”，不把它算成失败的策略能力，也不把它算成通过。

## 三、错误应怎样推动下一次练习

| 观察到的结果 | 先检查什么 | 下一次只改变什么 | 不能做什么 |
|---|---|---|---|
| 多人找不到行动者或返回点 | 页面和父帧 | 一个文案或一个视觉箭头 | 增加题量 |
| 事实题反复错 | 牌力、最佳五张、牌面图 | 一种牌力视觉 | 讲完整策略 |
| 把物理排除当成行动弃牌 | 范围三联图 | 一个组合和一个箭头 | 直接告诉下注答案 |
| 资料不足时被迫猜动作 | 来源、政策或后继 | 停止卡和来源标签 | 把错误算给用户 |
| 能答动作但不会交接 | 父帧和输出字段 | 一个后继或一个金额 | 直接开放连续三街 |
| 同一单变量迁移反复失败 | 当前父层和帮助等级 | 一个相邻对照 | 换成随机混练 |

修订顺序永远是：来源与事实 → 父帧与输入 → 问题和视觉 → 帮助撤除 → 题量。题量不能修复路线断裂。

## 四、发布闸门的明确含义

| 闸门 | 可以说什么 | 还不能说什么 |
|---|---|---|
| V0 | 课包纸面字段闭合 | 用户看得懂 |
| V1 | 用户能跟一条首课路线 | 已建立结构 |
| V2 | 用户能回放路线、定位层和恢复错误 | 会做陌生牌 |
| V3 | 用户能处理单变量相邻变化 | 会处理任意新局面 |
| V4 | 用户能在资料充分的陌生单步慢速执行 | 连续三街稳定 |
| V5 | 冻结配置下有连续路线证据 | 已达到NL50 |
| 目标级复核 | 有外部对标和真实决策审计 | 永久盈利保证 |

## 五、当前状态

这份协议把“最终要让低基础用户顺着一条嵌套路线学会，并逐步接近NL50”变成了唯一的证据顺序，避免用某一个局部通过替代整体目标。目前V0的纸面合同已大量具备，V1—V5尚未由运行时和真实学习者完成；匹配参考、完整后继、未曝光连续题和外部NL50对标仍是开放缺口。
