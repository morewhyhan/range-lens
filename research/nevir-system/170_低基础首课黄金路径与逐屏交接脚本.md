## 这份脚本解决什么

现有材料已经分别写了外层路线、七个父步骤、19帧首手候选和逐屏覆盖矩阵，但实现时很容易把它们重新拆成四个菜单。170号把它们压成一条唯一首课路径：用户只看到当前父帧，后台字段只在需要时打开，答完后把一个结果交给下一帧。

它不是新的课程内容，也不是35项列表。它是以后页面和低基础试读必须共同遵守的“黄金路径”。如果页面不能按这条路径走完，先修路径，不增加题量。

## 一、用户看到的固定画面

每个画面都只有四个区域：

1. 顶部短路线：只显示上一步、当前一步、下一步；
2. 中间主视觉：六人桌、牌面、最佳五张、范围图或账本中的一个；
3. 底部一句普通话问题和一个主要动作；
4. 右侧按需抽屉：解析、技术词、来源和原始资料。

主视觉只高亮本帧的一个变化。上一帧交接结果以小型固定快照保留在边缘，用户始终知道它为什么出现在这里。35项、求解器参数、全部尺寸和资料目录不出现在首页。`p2`的牌力顺序只作为[横向短练习](174_牌力顺序横向短练习合同.md)从当前牌面子层打开，完成后回到原来的最佳五张问题。

## 二、黄金路径的实际顺序

### 1. 先让用户知道“这是什么局面”

开场只显示六人桌、有效筹码和训练目标。用户先确认桌型和训练目标，再看位置、弃牌、行动者、历史、底池和待补金额。此时不显示下注策略，避免用户还没知道谁行动就开始猜按钮。

### 2. 再让用户知道“翻前怎样进入这里”

用户在一张固定坐标翻前图上找到自己的牌。系统只展示当前命名图和该格动作身份，完成后把“这手牌是否进入翻后”交给范围桥接。大盲才出现下注尺度选择；其他位置不额外增加金额设置。

### 3. 范围桥接先教“不可能”，再教“留下”

范围桥接显示三种状态：

```text
行动前范围 → 已知牌造成的物理排除 → 有行动参考时的动作筛选
```

如果只有前两层，第三层明确显示“资料不足”。阻挡牌在这里先只表示实体组合数量和可达性变化；它是否更适合下注，等进入比较层再判断。这样用户不会把“我拿了A”直接记成“我应该下注”。

### 4. 翻牌后每一街都回到同一个七步顺序

进入翻牌、转牌或河牌，用户都回到同一骨架：

```text
p1 局面 → p2 牌力 → p3 范围 → p4 比较 → p5 执行 → p6 更新 → p7 收口
```

区别只在当前街的输入不同。转牌增加一张新牌和前序范围；河牌关闭未来改善，改看价值、诈唬、摊牌和价格。页面不把转牌和河牌改成新的平铺专题。

### 5. 比较层只允许回答当前问题

在资料充分的节点，用户比较当前合法动作、价格和目的；在资料不足的节点，用户选择停止并看到缺口。解析先用白话解释“让差牌付钱、让好牌弃掉、保护领先、实现改善或价格不够”，答后才显示`EV`、`极化`、`阻挡牌`等术语。

动作层必须同时确认动作、金额和下一行动者。只点“下注”而金额不对，仍然是执行错误；金额正确但把行动权交错，也不能进入下一帧。

### 6. 更新层只突出一个变化

对手跟注、加注、弃牌或发出新牌后，页面保留原历史，只高亮一个变化字段：对手范围、自己的牌力、底池价格、行动权或后继。用户回答“哪一项变了”，再进入真实后继；没有真实后继就停在当前父帧，不默认生成下一街。

### 7. 结算层把结果和决定分开

最后显示账本、最佳五张和摊牌结果，但把“当时可见信息下的决定”与“后来发牌结果”分成两块。用户若答错，系统只指出错误层和返回点，不用结果证明上一动作一定正确或错误。

## 三、首遍结束后的结构检查

首遍隐藏步骤标题、答案颜色和技术标签，只保留空的双层路线图。先让用户回放规范外层 `L0—L4`，再让用户回放翻后内层；旧作者侧 `L5—L8` 只留在覆盖账本中。检查六件事：

1. 用户能用普通语言说出外层五个停点；
2. 用户能说出翻后七个父步骤和六条连接；
3. 用户能说明外层“翻后进入”怎样套住内层七步；
4. 给3个未见父帧，能指出当前层和下一层；
5. 给2个交接错误，能回到最近缺失层；
6. 只改变一个位置、牌面、价格、回应或新牌字段，能指出应该重查的层。

这些检查只证明结构开始形成。通过后才解锁同父层的陌生单步；仍然不能直接宣称策略掌握或NL50准备度。每个黄金路径帧还必须有独立的停止条件：缺输入、缺范围分母、缺政策/参考、金额不守恒、缺真实后继或无法回放时，原位停住并指出返回层，不能用默认答案继续。

## 四、实现和试读的硬停止条件

- 没有输入身份，停在局面层；
- 没有范围分母，停在范围层；
- 没有课程政策或匹配参考，停在比较层；
- 没有金额或行动权，停在执行层；
- 没有真实回应或新牌后继，停在更新层；
- 没有低基础首答和未见迁移证据，不开放连续路线；
- 没有匹配目标参考和外部对标，不显示“已达到NL50”。
