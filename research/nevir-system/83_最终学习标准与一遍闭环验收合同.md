## 1. 这份合同把“跟着练完就懂”变成什么

目标不是让学习者看完很多牌面、记住很多术语，或者在某个页面上点完所有按钮。目标是：一个没有专业基础的人沿着唯一主线走完一次后，脑中已经有一张可以复述的路线图；随后遇到陌生但同类的局面，即使速度很慢，也能按同一顺序找到下一步，而不是靠猜牌型口诀。

“小学生或老奶奶”在这里表示低认知负荷标准，不是对真实年龄的保证。是否达到这个标准必须由低基础成人试读、未见题迁移和延迟回忆证据证明，不能由设计者自读、文档数量或题目总数代替。

## 2. 学习者第一次只走一条闭合路线

第一次训练不展示35项平铺菜单，也不要求学习者先选择“阻挡牌、尺寸、价值、听牌”等专题。所有细节都挂在当前父层，只有当前问题需要时才打开一个子层，完成后回到原处。

主线固定为：

```text
定位桌面与行动
→ 读公共牌
→ 看自己的牌力
→ 形成对手可能范围
→ 比较当前可行动作
→ 执行动作并记账
→ 新牌或新行动后更新
→ 结算并回看迁移
```

翻前和翻后共用同一条慢想骨架。翻前的169格、位置和范围动作是前置输入；翻后不是重新打开一个新菜单，而是从“已形成的起始范围”继续沿父帧运行。

## 3. 每个屏幕必须交付的最小闭环

每个屏幕最多有一个主要问题和一个主要动作，并同时保留完成该问题所必需的输入。学习者回答后，系统必须产生以下五件事：

1. **判分**：明确对、错或“资料不足不能精确判分”。未知不默认为弃牌。
2. **因果**：只解释这一层改变了哪个事实，不能把后面五层一次性塞进当前页面。
3. **范围图**：必要时显示行动前、按行动筛选后和新牌排除后的同一坐标范围。
4. **返回点**：关闭子层后回到原父题，父题的牌面、行动、投入和首次答案不能被覆盖。
5. **下一格**：只打开当前路线的下一个节点；后继缺失就停止，而不是猜测默认政策。

因此，“看过解析”不等于完成；必须能在同一父帧重新回答，并在一个只改变单一变量的相邻题上复用该步骤。

## 4. 全覆盖不等于全平铺

“每个地方都不落下”要按覆盖矩阵验收，不靠增加首页按钮：

| 维度 | 必须登记 |
|---|---|
| 街次 | 翻牌、转牌、河牌、结算 |
| 角色 | 翻前最后加注者、翻前跟注者、盲位防守者、回应者 |
| 位置 | 有位置、无位置 |
| 当前状态 | 无人下注、面对下注、面对加注、全下、终局 |
| 当前问题 | 牌面、牌力、范围、动作、金额、更新 |
| 后继 | 对手回应、新公共牌、结算 |

每个格子必须有以下状态之一：已核对事实、课程示范、课程规则、匹配参考、学习者已验证、未开放。未开放格不能通过相邻格或相似牌面自动填满。一个角色或一条街的题量再多，也不能替代另一个角色或另一条街。

## 5. 一遍结束时必须观察到什么

第一次完整跟练结束后，不要求速度，也不要求全部答案独立正确，但必须观察到四项结构证据：

1. **顺序回忆**：不看标题，能按“定位→牌面→手牌→范围→比较→执行→更新”的顺序说出每一步。
2. **位置定位**：给出一个当前父题，能指出自己处在第几层、下一步要打开哪一个子层。
3. **错误回退**：答错时能回到最近缺失层，而不是从首页重新乱点或直接看完整答案。
4. **一处迁移**：在只改变一个因素的未见题上，能沿同一骨架完成至少一次判断；允许慢，但不能由主持者代答。

四项中任意一项没有证据，首遍只能标为“看过路线”，不能标为“建立结构”。

## 6. 从结构到可执行的递进

同一父子结构按以下顺序撤除帮助，不能用新专题替代内化：

| 阶段 | 学习者看到的帮助 | 通过含义 |
|---|---|---|
| 地图 | 步骤标题、当前位置、必需输入 | 能跟着走完，不跳层 |
| 引导 | 当前层提示和一个对照 | 能完成单步并解释变化 |
| 独立 | 不显示步骤标题，只保留输入 | 能找到当前问题和动作 |
| 相邻 | 同机制但换一个牌面/位置/历史 | 能迁移而不是背例子 |
| 延迟 | 间隔后无提示回忆 | 路线能从记忆恢复 |
| 连续 | 多街陌生牌局直到结算 | 能把每次更新接回下一步 |

帮助只改变可见提示，不改变正确答案、父帧或后继。重答不覆盖首次答案；首次答案、提示后答案和最终答案分开记录在当前会话中，不建立长期学习者数据库。

## 7. “达到NL50”必须怎样才有资格谈

训练器不能从一次首遍、题目正确率或文档通过推出NL50能力。至少要依次取得：

1. **资料准入**：翻前范围、课程规则、匹配参考和每个后继有来源与版本指纹。
2. **完整课包**：主线中所有开放节点有题面、答案、解析、范围前后图和可回放后继。
3. **结构证据**：低基础试读通过首遍四项结构证据。
4. **策略证据**：独立题和相邻迁移在固定参考条件下通过，错误能定位到事实、动作、范围或账本层。
5. **连续证据**：未见三街路线能够完成，金额、范围和公共牌更新一致。
6. **目标对标**：在冻结配置下通过独立策略基准，再经过真实牌局决策审计；这仍只能说明达到预设准备度，不能承诺盈利或永久稳定。

任何一级缺失，状态都只能停在对应级别。尤其“看得懂路线”和“做出课程动作”不能替代真实NL50对标。

## 8. 失败时优先修哪里

当低基础学习者卡住时，修复顺序固定为：

1. 先检查当前屏幕是否同时问了两个问题。
2. 再检查必要输入是否被隐藏、牌面或行动是否需要反推。
3. 再检查父帧是否在子层打开后被覆盖。
4. 再检查解析是否越过当前层直接给动作口诀。
5. 最后才增加例题；增加题量不能修复路线断裂。

如果同一错误在未见题中重复，应该退回最近的父层并重做单变量对照，而不是把更多相似牌面加入队列。

## 9. 当前状态

本合同已经把最终标准、唯一主线、覆盖矩阵、首遍证据、帮助撤除、NL50闸门和失败修复顺序写成可执行约束。当前仍缺：完整35项逐题参考绑定、完整连续课包、实际低基础试读、陌生迁移结果和NL50对标证据。因此它是验收标准，不是已达成声明。
