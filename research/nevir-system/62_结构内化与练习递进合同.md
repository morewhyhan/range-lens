# 结构内化与练习递进合同

2026年10月21日。本合同解决“第一次跟完知道路线，之后怎样慢慢内化”的问题。它把同一条单一路线重复使用，但每一轮只撤除一种帮助、只增加一种变化，不把复习变成新的平铺课程。它是教学设计和试读规格，不声称当前已经证明哪种间隔或题量能让任何人达到NL50。

## 1. 六轮递进，不新增六套课程

| 轮次 | 用户看到什么 | 用户要完成什么 | 允许的帮助 | 这轮证明什么 |
|---|---|---|---|---|
| R1 示范地图 | 完整规范路线 `L0—L4 → p1—p7 → 回放`，步骤名和关键变化可见；L0—L8只作作者侧覆盖 | 跟着走完，指出下一步在哪里 | 全部必要提示 | 看见整套结构 |
| R2 引导单步 | 同一父层，收起一个结论 | 完成牌力、范围、价格或金额中的一项 | 保留当前层提示 | 能在当前层操作 |
| R3 无标题单步 | 收起步骤名和答案色 | 先找层，再完成一个未见同机制题 | 保留必要事实 | 会调用结构 |
| R4 相邻交错 | 同一机制换位置、牌面或前序一个字段 | 指出改变字段，再答局部动作 | 不提示考点 | 能处理相邻变化 |
| R5 延迟回忆 | 经过另一段题后再回到原机制 | 不看原解析，恢复步骤和关键关系 | 只给必要输入 | 能稍后重新找回 |
| R6 连续陌生路线 | 新历史、新回应和新牌组成一手牌 | 保留范围、金额、行动顺序走到结算 | 允许事实工具，不给答案 | 开始接近实战迁移 |

六轮都沿同一条父子路线；用户可以在任何一轮退出，不需要账户或长期保存。R1—R3重点是结构和单步，R4—R6才逐渐引入迁移与连续性。

## 2. 每轮只撤一种帮助

帮助撤除的顺序固定：

1. 先收起正确颜色，但保留步骤名；
2. 再收起步骤名，但保留必要桌面和问题；
3. 再收起一个已经练过的范围或价格结论；
4. 再让用户自己指出需要打开哪张图；
5. 最后才隐藏“这题考什么”，保留真实完成判断所需输入。

不能同时撤掉位置、牌力、范围、价格和按钮提示。用户失败时只恢复最近被撤掉的帮助，完成后继续同一轮；不把整手退回R1。

## 3. 复习如何避免记住答案位置

同一机制的复习题要改变实体牌、花色、位置或一个历史字段，同时保留真正需要调用的关系。以下变化分开登记：

- **表面变化**：花色同构且不改变阻挡或牌力；用于确认用户不会因颜色换按钮；
- **相邻变化**：只改变一个明确字段；用于确认用户能指出改变来源；
- **机制变化**：从无人下注进入面对下注，或从翻牌进入转牌更新；用于确认用户回到父层；
- **策略变化**：动作菜单、范围回应或后续改变；只有匹配参考后才开放精确比较。

不使用同一题的换选项顺序充当迁移。公开演示、解析后重答和同构近邻都排除出最终未见样本。

## 4. 不保存数据库也能复习

应用只需在当前练习会话中保留父帧、首答、帮助和重答；关闭后不保存长期成绩。下一次练习由确定的课程版本、模式和会话种子生成新的题目队列，研究者若要进行试读则在项目外记录版本和观察结果。

因此：

- 不需要用户账户、排行榜或长期错题本；
- 不根据历史分数自动改变策略答案；
- 不把一次错题永久标成用户能力；
- 不把随机发牌当作覆盖保证，题目仍来自已开放的确定数据集；
- 需要延迟回忆时，由研究脚本或主持者安排版本，不由应用猜测用户记忆状态。

## 5. 每轮的通过证据

| 轮次 | 最低观察点 | 不能由此宣称 |
|---|---|---|
| R1 | 能说出走过的外层顺序 | 不代表会独立动作 |
| R2 | 在帮助下完成当前局部操作 | 不代表无提示掌握 |
| R3 | 无标题完成未见同机制题 | 不代表连续路线 |
| R4 | 指出单字段变化且不乱换按钮 | 不代表陌生策略 |
| R5 | 延迟后恢复关系和下一层 | 不代表长期记忆稳定 |
| R6 | 未见路线中金额、范围、回应、结算连续 | 不代表NL50目标对标 |

每轮都分开记录首答、重答、帮助、事实正确、动作正确和范围更新正确。解析后正确只记为帮助完成；要进入下一轮，必须换未曝光实例。

## 6. 练习队列的组成

一个复习队列不按章节平铺，而是沿当前父层混合四类题：

```text
一题当前机制
→ 一题动作保持的相邻对照
→ 一题动作改变的相邻对照
→ 一题回到完整路线的连续题
```

边缘牌、内部牌、明显纯动作和未知／资料不足题都按各自身份进入队列。资料不足题用于练“停在哪里”，不能混入精确动作得分。大盲尺度、位置切换和翻后新牌都必须在题面写清改变字段。

## 7. 什么时候可以从慢想到熟练

速度不是第一目标。只有当用户在未见、无答案色、必要输入完整的题中，能够：

1. 自己指出当前父层；
2. 正确读牌、范围和价格；
3. 选合法动作并执行金额；
4. 观察回应或新牌后更新；
5. 在稍后新题中复现同一关系；

才可以观察是否能减少停顿。没有校准的秒数不能作为NL50门槛，也不能用快点按钮代替范围和后续正确。

## 8. 当前状态

现有文档已有示范、引导、去帮助和迁移片段，但没有真实学习者的R1—R6连续结果，也没有校准复习间隔或目标级通过线。该合同补的是课程组织与验收顺序，不把题量、脚本回放或一次练习结果称为内化证据。
