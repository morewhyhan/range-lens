# 115｜参考策略可信度与误差分层

“求解器给了一个结果”不是一个单一证据。要让训练器答案尽可能接近可靠参考，至少要区分配置身份、物理事实、原始政策完整性、求解质量、课程简化影响和学习发布六层。

## 六层证据不能互相替代

| 层 | 它证明什么 | 它不能证明什么 |
|---|---|---|
| RQ0 配置身份 | 结果来自哪个范围、牌面、行动树、抽水和提交 | 牌力或策略正确 |
| RQ1 物理与账本 | 牌张、组合、权益、金额能独立复算 | 下注策略 |
| RQ2 原始政策完整性 | 保存、重载和索引没有改变逐手策略 | 求解器已收敛到高质量 |
| RQ3 求解质量 | 有收敛定义和开放偏离的有限树质量证据 | 未加入行动树的尺寸、课程损失 |
| RQ4 课程简化影响 | 简化相对参考改变了哪些牌、动作、EV、后继 | 简化一定优于参考、可以泛化到所有牌面 |
| RQ5 学习发布 | 课包有后继、迁移和低基础试读证据 | 永久盈利或自动达到NL50 |

例如，RQ2通过只说明文件没有损坏；如果某些动作被锁定，锁定模型里的“误差0”仍不能替代RQ3。RQ4必须在同一输入和同一行动树上比较课程政策和参考政策，不能把课程删掉动作后的新解当成“原始GTO证明”。

## 参考结果什么时候能进入哪种题

- 只有RQ0—RQ1：可以做牌力、合法组合、金额和权益事实题；
- 到RQ2：可以做原始结果的示范和文件一致性检查；
- 到RQ3：才有资格讨论有限行动树里的参考策略；
- 到RQ4：才可以把课程简化作为有边界的课程规则练习；
- 到RQ5：才可以进入未见迁移和连续路线的学习者验证。

每层都允许状态为`pass`、`candidate`、`blocked`或`not_comparable`。没有校准过的统一百分比时，不能写“误差小于某个数字所以全部正确”。阈值应在同一目标配置的一组匹配节点上校准，并分别报告动作差、EV差、范围差和后继缺口。

## 必须保留的独立检查

1. **牌张和最佳五张**：用独立牌力代码交叉核对求解器终局；
2. **范围和撞牌**：逐实体检查公共牌、底牌和双方联合相容质量；
3. **文件重载**：保留原始浮点值、动作索引、零到达行和后继索引；
4. **金额账本**：独立重放下注、弃牌未跟款返还、发牌和摊牌；
5. **开放偏离**：固定被评估政策，对偏离者开放原行动树动作，不能继续锁死被测动作；
6. **课程影响**：重新计算受影响祖先，检查当前最佳动作、范围和后继是否改变；
7. **学习迁移**：用未曝光、只改变一个字段的题检查学习者是否能回到正确层。

## 当前A72状态

A72已经有RQ0输入候选和RQ1物理事实候选，但RQ2的引擎重载、RQ3的求解质量、RQ4的课程简化影响和RQ5的学习发布都没有完成。因此即使以后收到一个可打开的求解文件，也要继续按这六层检查，不能直接生成精确判题。
