## 这条路线怎样让低基础学习者学会

软件里只有一条主路线。学习者先按 `L0 → L4` 完成翻前定位、查表、读格子、确定动作和范围交接，再按 `p1 → p7` 完成翻后的一手牌。每一屏只问一个问题，屏幕只保留一个主要动作；回答后，状态沿着同一条链传给下一步。

35项能力不作为首页上的35个按钮出现。它们被嵌在两个父步骤中：`1.1—3.6` 在 `p4_compare` 内按组顺序打开，`4.1—5.8` 在 `p6_update` 内按组顺序打开。完成一个子题后回到原来的父步骤，保留已经交接的牌面、范围、底池和行动权，再决定是否进入下一个子题。

机器路线现在明确保存一份用户可见的七步内层，而不是只保存内部编号：确认局面 → 看牌面和自己的牌 → 看双方范围 → 比较选择 → 执行动作 → 更新状态 → 收口迁移。每一步都有普通话问题、交接字段和可打开的子组；`p2`只打开牌面六类与牌力顺序事实子层，`p4`只打开比较组，`p6`只打开回应／新牌更新组。这样后台35项仍然完整，前台始终沿一条可以复述的父层路线前进。

## 首遍和完整熟练不是两套系统

首遍先打开五个组的代表题：`1.5、2.1、3.1、4.5、5.7`。这五题的作用是让学习者看懂五种“子题如何进入父步骤、怎样回答、怎样返回”的结构。首遍结束时，学习者应能说出整个顺序，但不能把代表题记忆误认为35项已经掌握。

后续熟练路线沿用同一条父帧链，只把每个组的其余子题逐项打开。它不是另一个菜单，也不是把35题平铺出来，而是同一条路线在深度上的展开：

```text
p4_compare
  → compare.unopened: 1.1 → 1.2 → … → 1.8
  → compare.bet:     2.1 → 2.2 → … → 2.7
  → compare.raise:   3.1 → 3.2 → … → 3.6
  → 返回 p4_compare

p6_update
  → update.response: 4.1 → 4.2 → … → 4.6
  → update.card:     5.1 → 5.2 → … → 5.8
  → 返回 p6_update
```

## 每个子题都必须交付什么

每个子题只有一个主问题，但回答必须落到实际操作上。最小输出固定为：

1. 当前动作或不动作；
2. 金额或价格（如果当前节点涉及下注）；
3. 一句说明当前比较的目的；
4. 同一分母下的行动前后范围图，或明确的停止原因；
5. 更新后的账本、行动者和后继，或明确说明后继资料未提供。

这样，学习者不会只记住“这类牌按钮是什么”，而是会把牌面、范围、价格、动作、范围变化和下一步连成一条可复述链。

## 帮助如何逐步撤掉

每个子题依次经历六个阶段：先看路线和核心视觉，再在必要事实上做引导，随后独立回答，再做只改一个字段的相邻对照，之后延迟回忆，最后放进连续整手牌。答错时回到最近缺失的父层，保留第一次答案，不能直接显示最终答案后继续前进。

连续整合只有在三个条件同时满足时才开放：同机制题通过、相邻对照通过、延迟回忆通过。连续题还要检查金额守恒、范围链或停止原因、后继或终止，以及决策和结果分离。

## 证据身份和停止边界

本合同只规定学习路线，不凭现有局部材料制造策略答案。每个子题必须标明它是事实、账本、课程政策还是匹配参考；缺完整范围、动作后范围或真实后继时，题目可以作为事实或结构练习存在，但精确策略判分和连续路线必须停止。

因此，路线完整不等于策略完整，35项都挂上父帧也不等于达到NL50。要开放精确练习，还必须为每个节点补齐固定输入、匹配参考、课程简化差异、范围变化和后继，并经过低基础学习者试读与陌生迁移验收。
