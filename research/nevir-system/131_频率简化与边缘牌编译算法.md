# 131｜频率简化与边缘牌编译算法

这份文档定义“拿到匹配求解结果以后，怎样压成可以像翻前图表一样练的0/50/100简化”。它解决的是编译问题，不是凭经验给每手牌贴标签。核心原则是：**课程图可以简化显示和动作，但不能把简化后的数字冒充原始GTO频率；边缘牌可以多抽题，但不能改变策略计算权重。**

## 一、先把三个数字分开

对节点`n`、实体组合`h`和实际动作`a`，原始参考至少有三种不同数字：

```text
w_before(h,n)       该组合在动作前的实体质量和到达质量
p_ref(a|h,n)        求解器给出的原始动作频率
q_course(a|h,n)     课程压缩后采用的0/50/100课程权重
```

`p_ref`是参考资料，`q_course`是教学政策，二者不能共用字段。训练抽题可以按`edgeScore`提高边缘牌出现次数，但评分和范围更新仍使用`w_before`以及声明的`q_course`；抽题比例不进入EV或策略差异公式。

## 二、允许的简化策略空间

课程只允许在声明的动作菜单上选择以下量化向量：

```text
Q(A) = { q | q_a ∈ {0, 0.5, 1}, Σ q_a = 1 }
```

因此只有一个动作可以是100%；两个动作可以是50/50；三个或更多动作同时有明显支持时，不能偷偷把其中一个涂成50。此时要么扩展课程显示的混合方式，要么把该组合标为`edge_unresolved`并停止精确课程判分。

对每个实体组合选择课程向量时，先枚举`Q(A)`，再按以下顺序选择：

1. 保留原始参考仍支持的关键动作，不能因显示方便删掉唯一的回应；
2. 最小化动作频率误差：

   ```text
   L_freq(h,q) = Σ_a |p_ref(a|h,n) − q_a|
   ```

3. 若有多个向量并列，再最小化局部EV损失：

   ```text
   L_ev(h,q) = EV_ref(h,n) − Σ_a q_a × EV_ref(a|h,n)
   ```

4. 若仍然无法区分，保留为混合边界并交给作者复核，不强制生成唯一答案。

这套选择只产生候选课程政策。是否接受，要看同一节点的加权动作差、动作支持变化、范围变化、祖先EV和后继变化；没有匹配参考时不运行量化。

## 三、什么时候可以显示100、50、0

“100/50/0”是课程政策的显示单位，不是自动从颜色或牌型推断出的事实。一个组合只有在以下条件下才可以进入相应桶：

- **100桶**：量化向量是单一动作100%，且参考与课程的支持动作没有被删除；若原始频率接近均分或动作差异不稳，不能仅凭最大频率硬选100。
- **50桶**：量化向量是两个动作各50%，并且这是`Q(A)`中达到最小误差的候选；显示时必须注明“课程权重50/50”，不能说原始GTO就是50%。
- **0桶**：该动作在课程向量中为0，且差异报告记录它相对参考的变化；0不是“这手牌永远不能做”，只是在当前课程配置和动作菜单中不开放。

如果最小量化仍然造成未校准的动作支持改变、明显的EV损失或后继断裂，状态为`edge_unresolved`。系统应显示“这手牌仍是混合边界，当前课程不强行压缩”，而不是给学习者一个看似精确的按钮。

## 四、边缘牌怎样定义和抽题

边缘牌不是“看起来难”的主观标签。至少由以下可计算字段组成：

```text
top1 = 最大动作频率
top2 = 第二大动作频率
margin = top1 − top2
supportCount = 频率高于δ的动作数
localEvGap = 最优与次优动作EV差
quantizationLoss = min_q L_freq(h,q)
```

`edgeScore`可以按配置归一化为：

```text
edgeScore = f(1−margin, supportCount, 1−normalized(localEvGap), quantizationLoss)
```

具体函数和阈值必须写在课程版本中，并用匹配节点校准；在校准前只能把它当排序分数，不能当正确/错误阈值。边缘题抽样概率和策略权重分开：

```text
P_draw(h) ∝ λ_edge × edgeScore(h) + λ_core × (1−edgeScore(h))
```

这里的`λ_edge`可以由用户设置为更关注边缘牌，也可以恢复均衡抽样；无论怎样抽题，评分、范围图和EV报告都使用原始`w_before`，不能因为边缘牌多出现就把它们的策略权重放大。

## 五、范围图怎样跟着简化更新

参考和课程必须分别计算动作后范围：

```text
w_ref_after(h,a)    = w_before(h) × p_ref(a|h,n)
w_course_after(h,a) = w_before(h) × q_course(a|h,n)
```

显示相对范围时使用同一父节点、同一固定分母；课程图额外显示逐组合差异：

```text
Δrange(h,a) = w_course_after(h,a) − w_ref_after(h,a)
```

物理排除先于动作筛选。自己拿走的牌、公共牌或死牌造成的零质量不能计入课程量化损失；只有参考策略或课程政策改变的质量才进入`Δrange`。动作菜单一旦删减，必须重新计算受影响的祖先和后继，不能只改变前端颜色。

## 六、一个单元怎样从算法进入练习

编译后的单元依次经过：

1. 显示动作前13×13范围和固定分母；
2. 显示当前组合的原始动作向量和课程量化向量（答后才看原始值）；
3. 让学习者选择课程动作或课程权重；
4. 显示动作后课程范围、参考范围和差异，不把未知格涂成0；
5. 显示祖先EV、后继和停止原因是否受影响；
6. 在同一父帧中给一个只改变单字段的边缘或内部迁移题。

若参考策略、范围后验或后继缺失，单元降级为事实/示范，不生成0/50/100精确题。用户可以练“哪些牌不可能”“哪个字段会变化”，但不能被迫猜一个未经参考支持的动作。
