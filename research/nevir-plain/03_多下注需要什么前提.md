# 第三篇：为什么课程一会儿要选牌，一会儿又说可以全打？

对应原笔记2.3。前一篇先学基准打法；这一篇讨论对手反应偏离基准以后如何调整。两篇没有先分层，读者就会感觉前面刚学会的东西又被推翻了。

## 先把同一块牌面分成两个版本

桌面832彩虹。你是有位置的3bet方。

| 版本 | 题目告诉你的对手反应 | 本课讨论的方向 |
|---|---|---|
| 基准版本 | 不额外假定对手有漏洞 | 保留原本的选牌与过牌 |
| 调整版本 | 在相应节点，对手加注明显不足、弃牌又偏多 | 可以研究扩大下注范围 |

变的是题设里的回应，不是牌面突然换了一套物理规律。不能在同一道题里偷偷切换版本。

## 少被加注为什么会影响选择

你拿一手没有击中的高张。你下注，对手若加注，你可能被迫弃掉仍有改善机会的牌。

如果相应对手较少这样反击，你就更容易保留看到下一张牌的机会。若他还会过多弃牌，你下注直接拿下底池的机会也增多。课程用这两种影响，解释为何可以把原本过牌的一些手牌加入下注端。

先让用户比较同一手牌的两棵小树：一棵有较多“被加注后弃牌”，另一棵这条分支较少。再说“权益实现”这个词：意思是你原本有的赢牌机会，有多少能真正保留下来。

但少被加注并不单独证明任意牌都能盈利下注。如果对手很少弃牌，而且跟注后特别强，仍需要完整比较。原课的调整结论来自特定假设与求解例，不是普适定理。

## 对手跟注以后，不能把这句话继续复制

翻牌下注是为了利用他可能弃太多。现在他没有弃，反而跟了。

你必须重新看留下来的牌。不能想：“翻牌我决定积极，所以转牌也继续积极。”这正是下一课转牌的起点。

## 逐节核对

| 原笔记小节 | 需要理解的事 | 训练方式 |
|---|---|---|
| 3.1 | 弃牌、跟注、加注三种回应要一起看；不同下注尺寸的统计不能混用 | 固定同一节点，看三条回应数量怎样变化 |
| 3.2 | T22例是在改变对手反应后扩大范围 | 基准与调整并列，前提亮出后再选版本 |
| 3.3 | 832原本选择性下注，可以在给定漏洞下扩大 | 先辨认“有证据/未给证据”，再练方向 |
| 3.4 | 973例中少加注让高张更容易继续 | 让用户指出哪条反击分支减少 |
| 3.5 | 小注高频局面也要保留场景与反应前提 | 不能把“高频”自动改成精确100% |
| 3.6 | J97两同花未必靠大量弃牌获利，少加注也重要 | 将过弃与少加注分开改变，检查解释 |
| 3.7 | 翻牌扩大范围后必须接后续计划 | 跟注后重新摆出双方留下的牌 |

笔记3.5中AK2“90%过牌加注”这个数字需要回原视频或求解设置复核；笔记末尾适用级别的概括也不完全一致。当前不把这些数字或宽泛人群描述变成精确标准题。笔记报告了当时的数据，不证明任何现实玩家现在必然如此。

## 怎样练，才不会学成无条件乱打

练习先只让你选“现在有理由用调整版，还是应该保留基准”。题干明确给出对手在哪条线路、面对多大下注的反应。没有证据的题，答案不能默认为对手有漏洞。

下一组只改其中一个条件。有的变化足够支持原课的调整方向，有的并不足以推出全范围下注。对于资料没给阈值的变化，只判“依据是否齐全”，不编一个临界百分比。

最后才让你在支持的课程实例里点实际动作。不能从“可扩大下注”跳到随机发任意手牌，要求唯一精确答案。扩大多少、哪些牌加入，原课没列全的就保持未定。

本篇学会的标志：你能同时记住基准和调整的触发条件；撤掉触发条件以后，不会继续无条件使用调整版。
