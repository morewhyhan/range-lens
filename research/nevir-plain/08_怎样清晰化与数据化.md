# 怎样把翻后整理得像翻前一样清楚

本篇面向内容整理和软件实现。前七篇面向学习者。这里提出新数据规格，不是说当前软件已经完成本轮研究提出的改造。

## 从理论上，究竟在求什么

眼前的一手牌是隐藏信息游戏中的一个状态。自己的牌知道，对手的牌只能按已有信息给出可能性。行动会改变当前分支、未来信息、双方投入和最终收益。新公共牌则改变各组合的实际牌力。严格的决策对象是带这些信息的完整状态，不是“湿牌面”“有A阻挡”这样的单个标签。

完整均衡策略还要考虑对手会怎样针对自己的整套行动，不能只为某手牌固定一个不会调整的回应表后，称其最优动作就是GTO。给定对手策略后的最优响应，与双方互相调整后的均衡，是不同问题。

Nevir笔记把均衡求解例当参照，把人能记住的行动菜单当执行简化，再在节点中加入特定对手反应研究调整。表格化时，这三种版本必须有不同身份；不能拿一版的频率、一版的尺寸、另一版的选牌拼成新策略。

“所有强牌都下注、所有弱牌都过牌”也不普遍成立。先过牌以后还可能面对下注，策略需要在不同分支保留能继续的牌；有些对手的过度攻击又可能使强牌过牌获利。原课没有完整给出的分配，不能靠一句“保护过牌范围”填百分比。

可执行的简化策略是在足够明确的条件下，选用有限的动作与选牌规则。它降低执行负担，不保证每个局部数字都是完整游戏唯一最优。正确性应分别检查牌张数学正确、课程处方一致、对手假设有依据和实际执行匹配。

## 一、为什么翻前一格够，翻后一格经常不够

翻前简化图已经固定了局面，并给每个手牌类别标了动作比例。翻后笔记通常只给局面中的一部分结论。把部分结论伪装成完整策略，是之前混乱的重要来源。

当前导入层含58个策略节点，另有13个牌面对照。58条标签为：课程24、条件剥削12、教学归纳12、资料待补5、原理补充5。这是工作簿条目标记的分布，不是58个独立完整求解。

当前40个翻牌节点里，仅6个节点有显式的结构化逐手示例，共17条；4个有显式结构化范围频率。这些数字是在检查当前导入字段，不代表原笔记仅有这些选牌文字。原笔记还有可进一步提取的内容，必须逐条核对后补入，不能从字段为空推断资料没写。

此前称“53个可执行节点”不够准确。应改成：**53个非待补策略条目，各自只开放其证据实际支持的任务。** 有些只支持尺寸，有些只支持方向，不能都随机发手牌问唯一动作。

## 二、资料单位改为一条明确的结论

同一个节点至少可能包含这些不同结论：

| 结论 | 需要什么条件 | 能判什么 |
|---|---|---|
| 本例主要尺寸67% | 场景、牌面、所选策略版本匹配 | 主尺寸识别 |
| AA用该尺寸下注 | 再匹配具体手牌与前序 | 对应课程动作 |
| 77更多过牌 | 同样的局面与手牌 | 倾向方向，不是精确频率 |
| 某范围约40%下注 | 该范围、节点、尺寸菜单 | 整体频率，不是每手40% |
| 对手过弃时可扩大 | 该线路、对手反应证据 | 调整前提与方向；范围未给全则不判逐手 |

每条结论单独存来源、精度、适用范围和缺项。“节点开放/关闭”还要细分到具体任务。某节点缺选牌表，不妨碍练它明确写出的主尺寸。

## 三、把一手牌当前状态存全

静态JSON文件即可，不引入用户数据库。状态应包含：

- 六人桌、初始有效筹码、翻后实际人数；双方座位；谁是翻前最后加注者。
- 完整已知公共牌、自己的实体底牌、街次、当前行动者。
- 依序保存动作、尺寸、下注前底池、这一街已投入金额；当前底池、双方后手、待补金额。
- 该题采用基准、课程简化还是有条件调整；使用的行动菜单。
- 对手范围及权重来自何处；每个行动分支的响应是否给齐。未知时显式未知。

“范围”必须带组合与权重，不只带一个“紧/松”名字。“对手过弃”必须带线路和下注尺寸，不是附在玩家身上的永久开关。

169格可以作为浏览入口，但不能默认把同一格的所有花色视为同一动作。翻后A♠Q♠与A♥Q♥可能有不同听牌和移除效应。数据以实体组合为基础，只有经过关系核对的等价组合才能合并显示。

## 五、把答案精度直接写进判分

答案类型至少分成：精确事实、完整模型可计算答案、课程纯动作、课程主尺寸、课程范围频率、倾向、候选、条件方向、未确定。

倾向题显示“更多过牌”，让用户选课程方向。不能只给“下注/过牌”并把下注说成数学上错误。候选题问“是否在资料明确列出的候选中”，不能偷换成“当前必须下注”。

纯动作也应描述为符合该课程处方，不冒充全游戏唯一最优。完整模型出现收益并列时接受并列动作，并说明条件。原例频率写“约”，就保留近似身份。

范围频率是所有组合动作概率的加权平均。例如整体40%，可以来自一些牌必打、另一些牌不打，也可以来自不同的混合分配。仅知道平均数，不能唯一还原每手牌。因此不能由S09的约40%下注给77、88都硬填40%。

## 六、原理怎样数据化

先存能计算的东西，再存有证据的解释。不能只存“范围优势”“阻挡好”这些口号。

| 项目 | 需要存/算的事实 | 不允许的跳跃 |
|---|---|---|
| 牌力 | 最佳五张、与具体候选的比较 | 顶对就应该价值下注 |
| 听牌 | 补成牌的实体牌、重叠、面对给定范围的实际结果 | 所有成花补张都赢 |
| 范围更新 | 先验权重×对应行动概率，再归一 | 跟注删除全部强牌 |
| 阻挡 | 由于已知牌删除的组合、被删组合原回应、重新归一 | 只看价值组合少几手，不看诈唬或弃牌同步少多少 |
| 跟注价格 | 待补/跟后总池，平分与后续分支条件 | 价格好就一定跟 |
| 下注收益 | 每组弃/跟/加分支与后续、成本、计量终点 | 用被跟后权益代替完整收益 |
| 策略解释 | 改一个条件后收益或课程分工如何变 | 从一手牌权益推出整块牌面尺寸 |

完整河牌实验无加注、无未来行动时，可从当前决策点写：

`EV(下注B) = 各组权重 × [弃牌概率×P + 跟注概率×(权益×(P+B) − (1−权益)×B)] 的总和。`

`EV(过牌) = 各组权重 × 权益 × P 的总和。`

其中P为自己行动前底池，权益包含平分份额。此模型不能直接用于翻牌或转牌，因为后面仍能发牌、下注和加注；不能拿原始权益直接填进去假装已求解未来。

未来有加注的模型，要完整写出加注后自己的响应和终局收益。缺哪条就标未定，不为了生成题目默认所有加注都弃或都跟。

## 七、出题分三路，别混成一个裁判

1. **事实题：** 随机合法发牌，由牌张规则判。可以有大量新结构，练真正读牌。
2. **课程题：** 从已支持的命题及其条件生成。数量有限也接受，不能为凑题随机换牌面沿用答案。
3. **条件实验：** 给齐模型，用代码算答案。可以系统改变回应、权重和价格，但明确它是实验，不是新增课程策略。

同时生成“变了以后答案改变”和“变了以后不足以改变”的题。新题去重至少看点数关系、花色关系、决策条件与目标命题，不能只比图片文件名。课程原例复现标复习；不同实体牌但完全同构的题不能独自证明迁移。

## 八、界面上怎样呈现，才能像翻前一样清楚

先选一张具体局面的练习页，顶部只留位置、底池和前序。中央放当前牌；准备下注时显示本页主尺寸。旁边是这页已经明确的手牌分工：下注、更多过牌、候选、未说明。

颜色只编码这四种资料状态，不凭空给未说明格涂“弃牌”或“过牌”。点一个格，看具体牌和依据；错题在同一位置亮出差异。原理讲解由需要时展开，不让用户同时看58个节点和18个概念目录。

翻牌练习页接“被跟后”的转牌分支；对手加注另开分支。前序、牌、底池和后手持续继承。未支持分支显示本资料到此为止，不装成一条完整求解路线。

这是把翻后做清楚的条件：**固定局面，显示已知动作，露出未知范围，让原理解释眼前差异。**
