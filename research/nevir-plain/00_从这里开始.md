**先记住一个画面：你每做一个动作，对手可能拿着的那一堆牌，就会分流。有人弃，有人跟，有人加。下一张牌发出以后，留下来的牌又会变。翻后就在反复处理这件事。**

## 先把画面上的字认清

每人手里两张牌。桌面先发三张，叫翻牌；再发第四张，叫转牌；最后发第五张，叫河牌。每到一轮，都可能重新下注。到摊牌时，从自己两张和桌面五张里选最好的五张比较。

| 字或符号 | 白话意思 |
|---|---|
| 底池 | 大家已经放到中间、正在争的筹码 |
| BB | 一个大盲注的筹码量；100BB表示初始有100个这样的单位 |
| BTN、CO、SB、BB | 六人桌上的座位名；各篇会画清谁先行动，不靠背缩写才能学 |
| 3bet底池 | 翻前有人加注，另一人再加注，后来有人跟；不是三个人的底池 |
| 过牌 | 当前没有待跟下注时，暂时不下注，把行动交出去 |
| 跟注 | 补齐眼前需要跟的钱；弃牌就是退出这手牌 |
| 加注 | 有人下注以后，提高这一轮要付的总额 |
| 后手 | 还留在自己面前、没有投入的筹码 |

座位名BB与金额单位BB要靠上下文区分。正式牌局还涉及盲注与下注合法性，本组重点解释用户已有翻前基础以后的翻后决策。

翻前容易练，因为你已经给了完整的简化图。选好位置和情境，一格就能告诉你动作比例。

翻后也能做成清楚的表，但先要固定更多东西。比如：

> CO开池，你在BTN再加注，CO跟注；翻牌8♠4♥2♦，CO过牌；100BB初始有效筹码，你拿A♣A♥。

在这个课程例里，可以练下注约2/3底池。把你的牌换成77，课程方向变成更多过牌。

这两题能查到明确依据，就可以做成两格。但若随机发给你另一手牌，原资料没给它的动作，就不能为了画满表格给它涂上颜色。

所以，清晰化的第一步是：**把“这手牌的动作”“整块牌面的主尺寸”“整体下注频率”分开存、分开教，再在有依据时合起来。**

## 翻后到底在做什么

你看不到对手的两张牌，但知道他不是随便哪两张都一样可能。翻前如何入池、刚才怎样行动，都会改变判断。

你要选择一个动作，让它在这些可能情况里，平均结果尽量好。

钱最终通过两种结局到你这里：对手弃牌，你拿下底池；或者摊牌，你赢得相应份额。下注、过牌、加注，会改变到达这两种结局的机会，也会改变你赢时收到多少、输时付出多少。前街还要考虑以后发牌和下注的机会。

听牌、阻挡、位置、范围优势，都在解释这些机会怎样变。先把它们连接到具体牌，再讲名字，才容易懂。

一次动作正确，不保证这一次赢。一次赢了，也不能反过来证明动作正确。训练应检查条件、依据、操作和计算，而不是拿这次发牌结果当裁判。

## 你在桌上只需要反复看这四件事

| 顺序 | 屏幕上看什么 | 心里说一句什么 |
|---|---|---|
| 先定位 | 座位、牌面、之前的动作、待补金额 | “现在是哪一段，轮到谁？” |
| 看自己的牌 | 最佳五张、听牌、可能改善 | “我现在有什么？” |
| 看对手的可能牌 | 哪些会弃、跟、加，信息来自哪里 | “这个动作想改变谁？” |
| 行动后更新 | 实际回应、新公共牌、底池和后手 | “刚才那套判断还成立吗？” |

这是练熟后的短流程。学习时可以把某一格展开练；熟练后不用每题回答四次。

## 学习不应该从52节目录开始

初学界面只选一个具体局面。例如先选“有位置3bet，842彩虹”。整个短单元尽量让桌面留在原位。

1. **先看。** 发AA，亮出少量明确给定的对手候选。指出你赢谁、输谁。这里先不算三个尺寸。
2. **猜一下。** 准备下注，先让你点谁会用较差牌付款；回应由题设明确规定，不能要求你猜真实对手。
3. **看变化。** 对应牌下面筹码移动。你能逐一看到多赢、多输或直接拿池。显示它是教学实验。
4. **接课程。** 说明原课程在842把AA/KK放进67%下注端；这一步是课程处方，不是假称刚才几手牌推导出67%。
5. **换一件事。** 只把AA换成77，展示课程为何不让中等牌一起照搬；再做一次不影响核心判断的变化，防止“换牌就换答案”。
6. **自己做。** 收起讲解，发有来源支持的手牌，直接点动作和金额；答错只展开卡住的那一步。
7. **再往前。** 有完整相容来源时才接转牌。只要没有后续依据，就停在边界，不伪造完整路线。

842单元的数值计算实验可以采用完整合成题设；它与原课的精确战略答案始终标清。没有资料的牌不硬塞进正式行动题。

界面需要真的画牌和筹码。学范围时，弃掉的牌从候选区移开；学听牌时，能补成的牌直接亮出；学阻挡时，被自己占用的组合变灰。初学不用同时看所有可能组合和长公式。视力、记忆或操作慢时，所有变化可以停住、回看，也不靠倒计时施压。

## “肌肉记忆”应该练成什么

自动化的是“看见关键条件，采取对应动作”，同时能在条件不匹配时停下来。不能只练到看见T高就按大注，看见A就按诈唬。

过程是先理解一小段，再反复提取这一小段；先固定场景，随后混入容易认错的相邻场景；最后收掉提示。题序和按钮位置不能成为答案线索。

错误分别处理：看错牌就亮五张，算错金额就摆筹码，认错线路就回放前序，用错对手假设就指出题目没有给那条证据。只看到最后动作错，不能假定错误原因。

先预测再看变化，是从演示研究得到的设计启发；要做未展示的新问题，是从提取与迁移研究得到的启发。这些研究不是扑克训练器效果保证。[Crouch等，2004](https://mazur.harvard.edu/publications/classroom-demonstrations-learning-tools-or-entertainment)，[Butler，2010](https://andymatuschak.org/files/papers/Butler%20-%202010%20-%20Repeated%20Testing%20Produces%20Superior%20Transfer%20of%20Learning%20Relative%20to%20Repeated.pdf)。

## 怎么知道真的会了

不能只看原例刚讲完有没有答对。要检查：换具体牌张仍能看懂；改重要条件会调整；无关变化时不乱改；在短片段里能直接操作；过一段时间收起提示仍能完成。

分别记录本轮的动作正确、金额正确、条件识别和是否用了帮助。可以只保存在内存，用户退出就清空。答对次数不直接等于掌握，反应快也不等于理由正确。速度在准确稳定以后再作为观察项，暂不设科学上并无依据的“几秒毕业”门槛。

要真正验证“零基础读者看得懂”，还需要实际试读：让人看牌、指牌、做动作，观察卡在哪里。这里完成的是可检查的研究与教学设计，不宣称所有年龄、所有基础的人读后必然能正确执行。
