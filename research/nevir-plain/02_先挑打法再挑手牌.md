# 第二篇：为什么有的牌面小注，有的牌面大注？

对应原笔记2.2。有利位置3bet底池，例子主要是CO开池、BTN再加注、CO跟注。翻后CO先行动，你后行动。所有尺寸只在这个课程场景下讨论。

[查看本篇原笔记](<C:/Users/why/Desktop/笔记 Nevir/2.2-有利位置3bet底池—第一部分_中文笔记.md>)。

## 把一个决定拆成两件事

桌面8♠4♥2♦，对手过牌。

课程先说：“这个局面主要采用约67%底池的下注尺寸。”

然后才说：“AA、KK进入价值下注端，66、77更多过牌。”

这两句话合起来，才是能用的内容：

| 同一局面 | 你拿AA | 你拿77 |
|---|---|---|
| 当前牌力 | 超过所有桌面点数的对子 | 小于桌面8的对子 |
| 原例课程安排 | 用约67%底池下注 | 更多过牌 |
| 要理解的问题 | 哪些较差牌仍愿意付款？ | 下注是否主要赶走了本来就落后的牌？ |

“更多过牌”没有被改写成100%过牌。原资料没有给77完整频率，训练也不能把“下注”一概判成数学错误。

底池15BB时，2/3约10BB。用户要能直接点动作和金额。但这个金额并没有告诉我们遇到任意加注以后应怎么处理。

## 从中间那一档牌理解两种打法

你可以把自己的可能手牌先摊开看。

一种局面里，不仅很强的牌愿意下注，中间强度的牌也能用小注得到较差牌跟注，或让有机会反超的牌退出。这为较宽的小注打法提供理由。

另一种局面里，很强的牌能下大注取值，普通中等牌却不适合一起把底池做大。下注端主要放强牌和合适诈唬，中间牌更多过牌。这叫极化。先看见三堆牌的分工，再出现“极化”这个名字。

这是理解课程的框架，不是见到某种对子就能自动推出整个范围策略的公式。

## 为什么“危险就下大”会误导

你拿AA。下注大以后，若对手仍会拿许多较差对子跟，你容易多收钱。

换一块更连贯的牌面，大注也可能让原本很弱的牌全部退出，留下顺子、两对和强听牌。你需要比较留下来的牌、退出的收益、投入和未来风险。

**留下来的牌变强，不能单独证明大注不好。** 赶走较好牌也可能赚钱。课程里的“被跟高不高兴”是帮助观察的一问，不是完整收益判定。

## 把课程对照做成可看见的变化

固定位置和底池，牌依次摆成：

| 课程翻牌例 | 主要尺寸 | 本次观察重点 |
|---|---:|---|
| T♠7♥2♦ | 约67% | 较疏的T高面 |
| T♠7♥2♠ | 约40% | 只改花色，直接花听出现 |
| T♠8♥2♦ | 约40% | 改一个点数，部分顺听变化 |
| T♠9♥8♦ | 约25% | 连贯结构、已成顺与强听牌更多 |

尺寸是课程各例的记录。软件不能只数出“有花听”，就宣称从数学上推导出40%；也不能把“所有T高两同花都40%”当成课程完整结论。

正确的教学画面：先点出哪些实际手牌从后门变成直接听牌，或者从卡顺变成两头顺听，再显示课程在相应节点采用的尺寸。最后给另一组条件明确的新题，检查你是否看见了相同关系。

## 逐节消化

| 原笔记小节 | 应练的关系 | 需要保留的边界 |
|---|---|---|
| 3.1 | 小注不能无条件铺到全部牌面 | 不是所有小注范围都弱 |
| 3.2 | 保护不能独自决定大注 | 拒绝权益仍可能是下注的一部分作用 |
| 3.3 | 高牌面中间牌能否一起小注 | 各高牌例频率不同，不统一全打 |
| 3.4 | T高例中连接、花色与尺寸的对照 | 不能从一个标签外推任意新面 |
| 3.5 | 超对取值与中等对子保留摊牌 | 超对不是绝对坚果，仍可能遇三条 |
| 3.6 | 低连张面对反击时，过牌保留机会 | 整体过牌只按相应原例执行 |
| 3.7 | 中间手牌能否下注；大注改变哪些回应 | 两个自问问题不是求解器 |
| 3.8 | 按具体牌面快速选课程主尺寸 | 只检验尺寸，不冒充完整选牌表 |

## 怎样练成不混乱的动作

先只练842这一块。牌面不动，轮流发AA、KK、77、66。先展示课程分工，再让你把牌放到相应位置。到这里暂不考所有诈唬牌，因为原资料没有列全。

然后只练T72彩虹与两同花。你先点变化的牌，再点出现的听牌，最后选各自课程尺寸。之后把两个局面混合，要求先认局面再作答。

计分必须说明在考哪件事。尺寸题可以精确判67与40；“77更多过牌”考方向，不能擅自要求精确0%下注。没有给逐手动作的牌，不能为了题量随便发来判错。

本篇学会的标志：拿到课程支持的例子，能分别回答“准备下注时用多大”和“我这手是否属于下注端”。
