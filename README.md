# 扑克练习器 1.1

> **2026-11-01文档入口更新：** 后续软件改型统一依据[最终设计文档](最终设计文档/00_从这里开始.md)。本README以下内容只说明当前v1.1实现；其中旧阶段编号和旧研究链接均属历史记录，不再决定新版设计。

> **当前实现：** 翻后采用通用局面生成与原生独立求解，支持全部22,100种实体翻牌输入、20种有原图依据的单加注情境及攻守双方。15种合法3bet位置组合可在明确双方范围后求解，已配置情境加入自动轮换。预计算仅为加速缓存，不限制可生成牌面。计算完成并通过核验后才训练；不声称已预存全部均衡、穷举无限下注尺度或补齐缺失的翻前范围。详见[实施状态](最终设计文档/04_界面与软件/03_求解工作区实施状态.md)。

React + Vite + Electron，本地离线训练器。六人现金桌背景、100BB、两人翻后，支持练任一方。

## 仓库内容

本仓库保存应用源码、求解器源码、设计文档、测试与构建脚本。原生可执行文件、求解策略二进制缓存、运行临时目录及 Electron 发布包不提交到 Git。首次克隆后需要安装依赖、编译原生引擎，并依据求解请求重新生成所需策略数据；仓库本身不包含可直接双击的 EXE。第三方代码来源和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 使用

当前主交付为求解工作区目录版 `release/postflop-solver-v7/win-unpacked/扑克练习器.exe`，文件哈希和构建时间以 `research/nevir-system/desktop-package-verification-current.json` 为准。旧目录与旧单文件EXE保留为历史包。运行需保留同目录Electron文件，不需要Node.js或网页服务器。成绩仅存本次内存。

直接双击根目录的 `启动训练器.cmd` 会启动当前目录版桌面 EXE。开发运行 `npm run dev`。构建运行 `npm run build`。生成当前目录版运行 `npm run package:win:dir:current`，生成旧路径目录版运行 `npm run package:win:dir`，生成单文件便携版运行 `npm run package:win`。打包配置使用 electron-builder 的 NSIS 1.2.1 工具链，并把工具缓存放在用户本地缓存目录，避免 Windows 文档目录的临时重命名锁冲突。

## 翻后怎样学

进入翻后自动生成新牌面并独立求解；达到精度并核验后进入训练，可取消并暂练已有数据。上方“自动换翻牌”重新生成，“练另一方”切换攻守角色，“换个决策点”在当前树中练不同街与行动历史。任意翻牌、位置及各街下注／加注尺度可在生成窗口调整，新的模型不会套用旧答案。首次计算需等待，速度取决于范围、动作数和电脑资源。

训练沿三步操作：①看我在和谁打：矩阵与具体底牌同步突出；②比较我的选择：看真实收益及回应后的范围；③收起提示自己打。高级图层默认收起。

进入「翻后」默认先观察、不计分。点动作，再看“谁会支付我／能赶走谁／继续面对谁”，关系直接高亮在对手图内；点具体组合可枚举后续摊牌结果。切换“自己作答”才计分。底部“换手牌，练这里”保持当前决策点，“继续这手牌”保留实际底牌并走真实后继。点击翻前历史查看双方起始图。

3bet首次仍需明确跟注范围；可指定全部15种合法位置组合及尺度，自动抽取相容翻牌求解。结果是给定输入下的翻后参考，不代表翻前均衡；网站范围资料尚未补齐。已配置情境在本次运行中参加轮换，应用关闭后清除，不保存成绩或范围设置。

以下为旧课程教学实现记录；当前主入口以求解工作区为准。

每项学习包含：手动示范、动手补一步、成对条件对照、收起引导的独立判断、与课程或具体牌局衔接。示范不计分，独立提交才计一次。完成示范只代表看完，可以继续单练，不宣告已经掌握。

- 直接点公共牌与底牌组成最佳五张；同值的等价组合都接受。
- 点击顺子补牌点数，区分直接花听、后门、重复补张与真正获胜的补牌。
- 比较13组原表牌面变化，另有随机合法读牌与分类题。
- 用明确给定的候选、权重、回应和行动分支，观察范围筛选与下注收益。可切换原条件/改变条件，以及过牌/不同下注额。
- 只改回应、权重、踢脚或行动顺序，检查结论改变或不改变；不把换花色算成新知识。
- 数学结果在作答后揭示；课程尺寸、频率、手牌候选与动作方向分开练，不补造逐手混合频率。
- 当前单项可进一步只练某个环节；课程练习可按位置情境、翻牌类别、节点和任务筛选。无有效题时明确提示，不偷偷取消筛选。
- 可选择几个已练过的单项混合练。连续片段是次级选项，不要求每手完成18道分析表。

所有作答都有「我不知道」，按错误处理。自己练答对自动下一题；答错停留解析；跟着学答后手动继续。数字键选择，0表示不知道，Enter提交多选或继续。牌型排序需完成整轮才记一次成绩。

当前单项、模式、环节、节点和课程筛选各自计分，只在本次运行的内存中保留。新的具体实例按整个会话去重，重复时显示巩固复习，不把重新配色包装成未见题。

## 连续片段

1. KT5小注前序 → T01转牌主尺寸，到资料边界结束。
2. T07条件超池 → R07河牌重估，保留条件，不补造最终河牌动作。
3. O07过牌加注 → T08先更多过牌；不把过牌解释为面对后续下注必须弃牌。
4. 完整给定模型：翻牌跟注筛选 → 转牌哪些候选改善 → 河牌按继承的范围和明确回应行动。牌张、候选身份、权重、底池和后手连续传递。

课程片段中的金额是账本演示，未给出的加注额不宣称最优；模型片段不作为新增GTO处方。

## 来源与精度

以桌面「笔记 Nevir」2.1—2.7及原工作簿为主。来源索引含13个牌面对照、40个翻牌、10个转牌、8个河牌记录，共71条。58个策略节点中53个可执行，按任务和具体手牌细分为75个课程案例身份。

O01、O02、S06、P01、P07资料待补，不开放精确策略。原理示例、课程规则、训练取值、条件调整、牌张事实和完整给定模型分别标注。候选不变成必下；更多过牌不变成100%；范围近似频率保留「约」的身份。

`src/golden-path.js`负责首遍 G0—G12、T01 转牌后继、答案身份、错误回退和父子短练；`src/golden-path.jsx`负责统一教学界面。`src/curriculum.js`和`src/learning-ui.jsx`保留18项专项、条件对照、程序出题与原表快练兼容入口。`src/learning.js`保留可复用的有限模型计算、课程适配与回归夹具。

牌张与概率通过代码枚举或公式计算；完整模型的权重与响应明确给定。没有完整范围和响应树时，不假装推导出课程精确尺寸或真实对手策略。

## 翻前与原有读牌

保留15张简化范围图、2535个手牌格和20个BB尺度映射。翻前只练简化图的0/50/100等动作分布，不要求掷随机数执行；没有新增跟注、挤压、4bet范围。

边缘抽样滑条控制边缘池比例，勾选项定义池的并集；全范围模式忽略边缘参数。错题放大原SVG并用双层描边定位手牌格。九种牌型排序、随机读牌和原表快练仍可独立使用。

修正了D01对照的左侧牌面：A72 → AK2，避免原说明“高张配到K”与画面不一致。六人桌按每个动作的实际主体标记，避免把同一句中BB跟注显示到BTN身上。

## 验证与交付

`npm test`覆盖范围回归、牌力、听牌、课程规则、有限模型、18项教学任务、真实条件对照、等价五张、范围更新、完整来源入口、待补关闭、连续片段筹码与范围继承、实例去重和计分隔离。

`npm run verify:matched-package`验证匹配课包的配置指纹、求解器身份、五层图表、逐组合策略和后继；当前默认校准包只用于作者侧预览，不进入用户课程题池。

`npm run verify:a72-c0`验证首个用户100BB A72参考请求的输入指纹、实际根动作、无需大内存分配的代表性历史菜单、物理组合解析和 EV 校准；它目前停在 C2 之前，不生成策略答案。

`npm run verify:golden-path`验证首遍 G0—G12 与纸面黄金路径对齐、T01 后继段可重放、每帧答案身份完整、答错停留、未知计错、父子短练返回和会话计分隔离；报告写入 `research/nevir-system/first-pass-runtime-verification-current.json`。当前报告仍把多尺寸人工视觉验收列为待做。

`npm run verify:desktop-package`复核单文件、目录版 EXE 和 `app.asar` 的存在、大小与 SHA-256，并区分当前目录版与旧便携版；报告写入 `research/nevir-system/desktop-package-verification-current.json`。当前执行环境启动 Electron 45.0.0 二进制会触发系统 DLL 重定位错误，已在报告中单独标记，不能替代另一台 Windows 机器上的首屏人工验收。

`node scripts/verify-cards.mjs`可枚举全部2,598,960种五张牌，校对九类牌型组合数量。`node .build-cache/verify_steps_document.mjs`复核关键手册算例与71条原表文字索引，并校验原工作簿未被改动。

版本的具体运行与打包证据见 `design/翻后18项教学_实现与验收.md`。技术验证支持计算和操作按设计工作，不冒称已经测得真实玩家的长期学习效果。
